* **WandB Logging**: The Boolq GRPO training callbacks also support logging training metrics to WandB, which fire on the `on_step_end` callback. To enable, simply add the `--wandb` flag when calling `boolq_training_example.py`, specify a WandB project name by passing in a name to the `--wandb_project` flag, specify a run name by passing in a name to the `--wandb_run_name` flag, and set the `--wandb_mode` to `""online"` for real-time logging to your WandB dashboard.
