/goal Use $diffusion-full-pipeline, $diffusion-qualitative-check, and $tt-device-usage for the $DIFFUSION_MODEL end-to-end pipeline under the $diffusion-model-bringup contract in the current tt-metal checkout.

As the user, I explicitly authorize you to use subagents when a selected skill requests or recommends them.

This goal creates the pipeline state for the repo-local tt_dit diffusion pipeline. Start from the completed DiT, text encoder, VAE(s), and scheduler; wire them end-to-end on ONE persistent device under models/tt_dit/pipelines/<model>/pipeline_<model>.py plus a generate script and a smoke test; do not begin multichip, optimize, or datatype-sweep work in this goal.

Goal completion requirements:
- pipeline_<model>.py implements __call__(prompt, height, width, num_frames/…, num_inference_steps, seed): tokenize -> encode -> init seeded-noise latents -> per step build the host layout (position_ids/timestep_indices/adaln_indices/rope) and run the DiT once -> step the scheduler on the GENERATED rows only -> unpatchify + un-normalize (per-channel latents_mean/std) -> VAE decode -> save frames/mp4 (+ wav + mux if audio). No CFG if the model is guidance-distilled.
- MESH LIFECYCLE: run every stage on ONE persistent parent mesh — do NOT create+close a submesh per stage (repeated create_submesh + close_mesh_device on a FABRIC_1D mesh deadlocks the next collective and needs tt-smi -r). Single-device VAEs run replicated on the full mesh (read back from device 0). Free only model WEIGHTS between stages, never the mesh; build heavy device models inside __call__ so exactly one is resident (log peak DRAM/ASIC).
- Guard degenerate configs before running: validate the VAE frame-count geometry (e.g. num_frames = 17n+5, n>=1) so decode has non-empty chunks; duplicate a lone step-0 timestep to 2 (numerically identical) so a size-1 timestep dim can't wedge a matmul/CCL. Per-step host prep only; the device forward stays free of torch/from_torch/to_torch. Instrument the loop (log before/after each forward + sync + decode) and use a hard timeout on every device run.
- A saved, NON-DEGENERATE artifact is produced and its stats recorded: frames not black/NaN/frozen (mean per-pixel abs diff between consecutive frames > threshold), audio not silent/NaN (rms > floor, |x|<=1), no NaN/Inf, value range sane. A small scripts/ helper ingests frames+wav and prints stats + pass/fail. Separate degeneracy (hard fail) from low fidelity (expected at tiny res/steps — report, don't fail).
- A few-step latent-trajectory (or final-latent) PCC vs a diffusers CPU reference at a tiny config where feasible (else document why and rely on degeneracy + eyeball). A wall-clock breakdown (encode / DiT-load / denoise / decode) is recorded and the dominant cost flagged for $optimize.
- The stage's runner check gate passes. capability_contract.json is reconciled with the config actually run (resolution, frames, fps, audio rate, latent shapes, steps) and any hard-limit reduction has evidence. doc/pipeline/DESIGN.md and work_log.md record configs, timings, artifact paths, stats + pass/fail, mesh/staging decisions, and exact artifacts.
- $stage-review returns `clean-pass`; findings fixed/rereviewed. Local commit stage-owned touched-repo changes; never push; log SHAs.

Unmet requirements, review findings, failed gates: work. Stop only after `$autofix` fails.
