0. BATCH + ORDER. Everything runs at decode batch DECODE_BATCH. In incumbent.json record decode_batch,
   requested_decode_batch (both = DECODE_BATCH) and measured_at; in each report.json record capture_batch
   and captured_at. The gate asserts the three batches agree and that captured_at is AFTER measured_at --
   the incumbent must be frozen before the advisor runs. Advice judged at another batch can flip sign.

1. FREEZE THE INCUMBENT FIRST, before running the advisor. Its own perf harness at DECODE_BATCH, >=3
   repeats, into doc/advisor_challenger/incumbent.json. incumbent_ms = the BEST repeat;
   noise_floor_ms = the spread. Record shipped_policy, shipped_weight_dtypes and shipped_policy_source
   naming the artifact they came from (final tt-perf-report CSV or selected candidate JSON). NEVER
   resolved_policy.constructor_defaults — those are class defaults, not what executed.

2. CAPTURE ONCE PER LAYER KIND, AT THE SHIPPED PRECISION, constructing the target with the shipped policy
   (template: scripts/capture_template.py; advise_qwen.py is the only correct example). Pass
   --pipeline-options allow-bf16-dram-sharded-matmul=true if any traced weight is bf16. Record traced_weight_dtypes and dram_sharded_considered; if considered is 0 set
   dram_sharded_zero_cause to wrong_precision_capture or bf16_eligibility_default. Note any uncapturable
   layer kind (sparse_matmul and SSM/gated-delta ops are terminal in the tracer) and its share of layers.

3. RECONCILE THEN MEASURE, IN CHAINS. Run scripts/reconcile.py. It groups
   advised ops into chains and thresholds on the chain's SUMMED window share. MEASURE EACH MATERIAL CHAIN

   only the whole L1-resident chain pays off (OPT-003). Every chain ends with a measured number or
   below_threshold plus its summed share. No prose-only rejections.

4. ONE VARIABLE PER MEASUREMENT. Every kept change re-runs the incumbent's own test suite at its own PCC
   bar; record the oracle. Prefer a real-weight oracle where one exists and say so when only synthetic do.

5. THE INVARIANT: final_ms <= incumbent_ms. Ties inside the noise floor go to the INCUMBENT.

6. ITERATION IS BOUNDED: re-capture only after a topology rewrite changing an op's shape (a dtype change
   is not one), max 3 captures per layer kind, each with a recorded trigger.
