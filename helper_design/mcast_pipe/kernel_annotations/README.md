# Kernel annotations

These files are dated protocol-analysis records, not current rollout state.
They preserve the source shape and hazards observed when each kernel was
audited. Use `../migration/ledger.json` for the current status and API stamp.

Where an annotation names an older API as "current", interpret that statement
only at the recorded audit checkpoint. The 2026-08-23 cleanup labels those
snapshots explicitly; it does not rewrite their historical line references or
validation evidence.
