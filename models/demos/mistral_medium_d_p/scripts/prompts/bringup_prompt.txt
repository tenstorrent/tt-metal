Tenstorrent's Blackhole processors are built around a grid of Tensix cores, each pairing five RISC-V baby cores with a matrix engine and a vector engine, so a kernel can overlap data movement with compute inside one core. Prefill and decode place very different demands on that grid: prefill is a long sequence of large matrix multiplications that saturates the matrix engines, while decode is latency bound and dominated by weight bandwidth. Chunked prefill splits a long prompt into fixed-size pieces so the key-value cache grows incrementally, which keeps activation memory bounded and lets a scheduler interleave prefill chunks with decode steps for other requests.
