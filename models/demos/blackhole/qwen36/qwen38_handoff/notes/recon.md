## Q2. Weight cache

- Naming: modules pass `cache_file_name = <dir>/<stem>`; `ttnn.as_tensor` appends `_dtype_<DTYPE>_layout_<LAYOUT>.tensorbin` (ttnn/ttnn/operations/core.py:897). So dtype IS in the filename: a dtype change never loads a stale BFP8 file; it writes a NEW file next to the old one (old file stays, unused). Memory config/mapper are NOT in the name: a cache hit returns the stored layout (hence the `.il`, `.dramshard`, `.dsh2`, `.vshard`, `.colpar` stems; any new layout (DRAM-sharded copy) MUST get a new stem).
- Dir: `args.weight_cache_path()` (model_config.py:343-358) = `<TT_CACHE_PATH>/<device_name>/tensor_cache_bfp8[_mesh1x4]` regardless of per-group dtype.
