# Known issues: deepseek_v41_flash_d_p

Model-specific lessons. Shared lessons: `models/demos/common/bringup/knowledge/known_issues.md`.

- **[DS41-1] fp8 / fp4 quantizers turn last-bit GEMM differences into whole quantization steps.** Symptom: oracle vs reference, inputs equal to 3e-8, attention out rel 1e-4 at layer 1 and 1e-2 at layer 2 (first fp4 compressed-KV layer); 6 / 300 tokens re-routed. Cause: different GEMM tiling (M) flips fp8 / e2m1 roundings. Fix: one tiled GEMM routine for both (`reference/kernels.py` "GEMM tiling", installed as model.py's `F.linear` / `torch.einsum`); then bit-exact. Applies to: reference/kernels.py, reference/hf_oracle.py. Seen at: d8b010327de. Found: deepseek_v41_flash_d_p R.2.
- **[DS41-2] Per-chunk results a reader layer needs are kept per position, not per chunk.** Symptom: top-k / candidate pool kept as "this chunk's rows" would be [4096, 512] one-shot vs [2048, 512] chunked. Cause: check_reference's state pcc (`core/metrics.py:pcc`, flatten + dot) needs equal sizes. Fix: topk_idx [length, 512] and candidates [length, 2048] grow with the sequence; readers slice [start, end) (`reference/ds41_ref.py:State`). Applies to: reference/ds41_ref.py, core/metrics.py. Seen at: d8b010327de. Found: deepseek_v41_flash_d_p R.2.
- **[DS41-3] Single-pass mHC: a sublayer collapses with the PREVIOUS sublayer's pre.** Symptom: the block output streams alone cannot feed the next block. Cause: attention uses the previous layer's FFN pre (layer 0: one-hot), the FFN this layer's attention pre (inference `Block.forward`). Fix: block boundary [S, 4H + 4] = streams + pending pre (`ds41_ref.py:pack`); the oracle taps pack the same way. Applies to: reference/ds41_ref.py. Seen at: d8b010327de. Found: deepseek_v41_flash_d_p R.2.
- **[DS41-4] Reset fixed state per step, not per layer, at chunk start 0.** Symptom: chunked != one-shot from layer 14 on (hidden pcc 0.984; first diff: rows 1024-1026 of engram_rows). Cause: layer 14 has two stateful steps (engram tail, compressor partial); a layer-wide reset in the compressor erased the tail the engram step had just written. Fix: each step resets only its own state (`ds41_ref.py:_compressor`, `_engram_rows`, `_attention`). Applies to: reference/ds41_ref.py. Seen at: d8b010327de. Found: deepseek_v41_flash_d_p R.2 (R.3 pre-check).

Applies to: bringup/serving_contract.md. Seen at: d8b010327de. Found: deepseek_v41_flash_d_p SC.1.
