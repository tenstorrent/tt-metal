# Packed prefill (continuous batching), galaxy 8x4: results of the night 2026-11-19/20

Branch `dnijemcevic/model_bringup_batching` (not pushed). Up to 4 requests x <= 2048 new tokens in one 8192-row chunk:
token-wise work (projections, norms, mHC, engram, shared expert, router, routed MoE) once over all rows; attention once
a layer with per-chip lane arguments (each 2048-row lane = 8 whole chips); every chunk each segment's history gathered
from its own slot's served cache (slots at one capacity, 1,048,576). Accepted path: `PACKED`, `PACKED_ATTN_ONECALL`,
`PACKED_MOE`, `PACKED_GATHER_HIDE`, `PACKED_HOST_FAST`, `PACKED_LANE_BALANCE` = on (all call-time, default off).

Measured: layers 0-20 + DECODER_SKIP=decode, agentic_cc text (each lane a different session at its real position),
shipped resident engram table, serving-equivalent wall (engine device input -> ids readback -> last layer synced),
median of warm runs. Sources: PB.5 gate (results/PB.5.json) and PB.5C (results/PB.5C_packed_walls.md).
