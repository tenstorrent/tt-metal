# Fresh walls (PB.MB5: WALLS_FRESH=1, every timed chunk at new positions and slots)

Fresh = every timed chunk at NEW positions (AgentX history draws, seeds logged) in NEW serving slots (the engine-owned KV caches; warm-up and timed draws use disjoint slot pools), program-cache misses allowed and counted. Warm-repeated = the same chunks run again right after their fresh run (positions and slots seen before: a best case). Wall (single request, path 'adapter') = runtime.prefill_chunk (the engine's device input already on the device -> ids readback -> note_tokens / begin_chunk -> every served layer, layers 0-20, DECODER_SKIP=decode) -> sync; packed walls: the engine's device input -> ids readback -> sync after the last layer. Host = wall - device (the slowest chip, real-time profiler, profiled repeats). Ops: extra fresh draws (untimed) with every ttnn call wrapped; a build is charged to the innermost call that made it and its arguments diffed against the previous call at that site.
