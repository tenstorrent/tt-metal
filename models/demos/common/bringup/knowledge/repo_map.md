# Repo map

Pointers every agent reads before it searches the repo, one row per need, best starting point first. Rows here are
general; pointers into one model's code are in that model's `bringup/repo_map.md`. Agents do not edit this file: they
add rows to their model's `bringup/repo_map.md`, and the overseer promotes general ones here when a run ends.
