# E9.4 SDPA search tables (12 x 10, batch 1, in the full model)

Every candidate of the in-model SDPA search, per bucket and round. Script:
`tt-ops/runs/embeddinggemma-2/e9/04-attention/scripts/sdpa_sweep.py` (candidate sets `sdpa_cands.py`),
records `search/<round>_<buckets>.jsonl`, tables generated by `scripts/search_table_compact.py` (this file)
and `scripts/search_table.py` (`analysis/search_tables_full.md`: one row per layer kind with q / k, grid,
units, cores, units per core). Method: the real model and the harness input (3/4-valid real input padded into
the bucket), the selected precision `sdpa_nofp32acc`, one device session per round; per candidate an eager
forward (compile; an error is recorded verbatim and the candidate skipped), trace capture, 3 warm replays,
burst = median of 5 windows of n back-to-back replays (n = 200 ms / forward, 3..20) after 2 s idle; last
hidden of the replay vs the control's (PCC, bitwise). The control (the stage-3 calls) runs at the start and
end of each bucket; "vs ctl" is against their mean, "drift" is their spread.

Candidate names: `hd256_*` = the 20 sliding layers' SDPA call (head_dim 256, 4 Q / 2 KV heads, band +
padding mask), `hd512_*` = the 4 full layers' call (head_dim 512, 4 Q / 1 KV head, padding mask);
`q<q>_k<k>_<grid>` (`full` = 12 x 10); `map` = sliding band block map on (default from 4096 only);
`padmap` / `band+pad_map` = band map with the key chunks that hold only padding cleared (host-built from the
input's valid length: the probe for the per-forward device map that was kept). Units = 4 heads x ceil(S / q).
Rounds: `r1` one knob at a time per layer kind; `wave` / `r2_*` / `r3_*` non power-of-two q chunks that fill
120 cores in whole waves, smaller grids, block maps and combinations of the winners. Code identity (log
headers): `r1_128-...-1024` ran on `05a8aa15d7` + the uncommitted commit-1 files (= `441e57eb47`); `r1_2048-...`,
`wave`, `r1_16384` on clean `441e57eb47`; `r1_32768` with only the `band_block_map` ceil fix in the tree
(identical maps for power-of-two chunks); from `r1_65536` on with the block-map policy hook present but empty
(identical calls); `r3_long` with the final table present and `EG2_SDPA_TUNED=0`. The control issues the
stage-3 calls in every round.

Illegal candidates: static circular buffers over the 1572864 B L1 (`program.cpp:2533`), static CBs clashing
with live L1 buffers (`program.cpp:2590`), q chunks that are not tile multiples (112, 144: my arithmetic slip,
`sdpa_device_operation.cpp:120`), and three 4096 sliding candidates in `wave` whose block map had the wrong
shape (`sdpa_device_operation.cpp:210`): `band_block_map` then used floor(S / q) for q chunks that do not
divide S; fixed in `tt/masks.py` (ceil, clipped last block) and the same chunks re-measured legal in `r2_mid`.
head_dim 512 is L1-bound: q 256 (any k), k 256 / 512 (q 64-128) and q 192 at 4096 (activations in L1) do not
fit; head_dim 256 fails at k 512.
