# Known issues: xing40_a4b_d_p

Model-specific lessons moved from the shared file. Shared lessons: `models/demos/common/bringup/knowledge/known_issues.md`.

- **The auto checks' mistake sweep lets 1 % noise through on mHC coefficients.** Symptom: on Xing4.0 layer-0 attn_hc, noise1e-2 SLIPPED (rel 0.007 < limit 0.0148). Cause: bf16 comb logits push the limit to the cap; noise hides in comb. Fix: keep checks="auto", add per-part rel L2 (pre 0.006, post 0.03, comb 0.012), comb column sums within 0.01 of 1, value ranges (`xing40_a4b_d_p/tests/bringup/test_c_dense_attn_hc.py`). Detail: known_issues_detail.md. Found: xing40_a4b_d_p C.dense.attn_hc test.
- **A correct attention device is noisier than the sweep's 1 % noise mutation.** Symptom: layer-2 device rel 0.0108, noise1e-2 0.0100. Cause: sharp scores. Fix: cap the error off the CPU's top 1024 SVs at 0.006. Detail: known_issues_detail.md. Applies to: models/demos/xing40_a4b_d_p/tests/bringup/test_c_moe_attention.py, ttnn/ttnn/bringup/sdpa. Seen at: 744ed21d97f. Check: on the 4x2 LoudBox (8 x p150b), run test_c_moe_attention.py on the device (fork ring_mla, HiFi4 + fp32 DEST); compare whole and off-subspace rel. Unverified since: 864ec8b0891. Found: xing40_a4b_d_p C.moe.attention test.
