# Known issues: hy4_preview_d_p

Model-specific lessons moved from the shared file. Shared lessons: `models/demos/common/bringup/knowledge/known_issues.md`.

- **transformers' hy_v4 port uses the wrong RoPE style.** Symptom: HF sanity top-1 accuracy 0.237 (floor 0.4), yet the CPU reference matched the oracle at PCC 1.0 (same code). Cause: transformers 5.17 `modeling_hy_v4.py` uses rotate-half RoPE in MLA and indexer; SGLang serves interleaved (`rope_interleave = True`). Fix: interleaved RoPE in the vendored oracle (`reference/hf_hy_v4/`) and `hy4_ref.py:apply_rope`; keep the accuracy floor; check a new HF port against the serving code. Detail: known_issues_detail.md. Found: hy4_preview_d_p R.2.
- **Vendored newer modeling code calls create_causal_mask with allow_is_causal_skip.** Symptom: `TypeError: ... unexpected keyword argument 'allow_is_causal_skip'` running transformers 5.17's hy_v4 code on 5.12.1. Cause: the argument is new in 5.17; 5.12 never skips the mask for eager attention, so dropping it changes nothing. Fix: a shim drops it and asserts a mask came back (`hy4_preview_d_p/reference/hf_oracle.py:_mask_shim`). Found: hy4_preview_d_p R.2.
- **check_hf needs the block output in HF's per-layer shape.** Symptom: check_hf crashed with `The size of tensor a (4) must match the size of tensor b (1024)`. Cause: HF reshapes hook output to [-1, H] ([4S, H] for 4 iHC streams); [S, 4, H] does not broadcast. Fix: flat [S, 4H] block boundary (`flatten(2)` order); `hooks.hf_layers` taps get `streams.flatten(2)`. Detail: known_issues_detail.md. Applies to: models/demos/hy4_preview_d_p/bringup/hooks.py, models/demos/common/bringup/reference/check_hf.py. Seen at: 864ec8b0891. Found: hy4_preview_d_p R.2.
- **Whole-matrix PCC cannot gate the iHC gates.** Symptom: on the layer-0 attn_hc golden, post = 1 * sigmoid (not 2 *) scores PCC 0.991; every gate bug tried passes 0.99. Cause: column means differ (pre ~1, post 0.11-0.34) and dominate; layer-0 streams are identical. Fix: also gate rel L2 <= 0.01 and per-column max abs <= 0.015 (`tests/bringup/test_c_dense_full_attn_hc.py`); stream order is for swap tests and later layers. Detail: known_issues_detail.md. Found: hy4_preview_d_p C.dense_full.attn_hc test.
- **iHC pre gates are invisible downstream at layer 0.** Symptom: with attn_hc swapped, pre-gate bugs leave h_mid and out bit-identical; post-gate bugs pass the 0.98 out gate. Cause: identical streams make attn_x a row scale of the embedding, which attn_norm removes; the residual dominates. Fix: also assert gates vs golden (rel L2 <= 0.01, column max abs <= 0.015) and attn_x, h_mid, out rel L2 <= 0.01 (`tests/bringup/test_swap_dense_full_01_attn_hc.py`). Detail: known_issues_detail.md. Found: hy4_preview_d_p S.dense_full.01 test.
- **A layer-0 iHC pre-mix test sees only the sum of the pre gates.** Symptom: on the layer-0 attn_hc_pre golden, no gating and pre x 1.02 pass PCC 0.99; stream-order bugs change nothing. Cause: identical streams make every bug a per-row scale. Fix: gate rel L2 <= 0.004, row ratio [0.995, 1.005], worst row <= 0.01; rerun on synthetic distinct streams vs the CPU step (rel <= 0.008, row <= 0.02) (`tests/bringup/test_c_dense_full_attn_hc_pre.py`). Detail: known_issues_detail.md. Found: hy4_preview_d_p C.dense_full.attn_hc_pre test.
- **A wrong RMSNorm eps is invisible on a golden with large row RMS.** Symptom: on the layer-0 attn_norm golden (mean(x^2) >= 70x eps), eps 1e-6 for 1e-5 scores rel L2 0.0031, like a bf16 device norm. Cause: eps only moves rows whose mean square is near it.
