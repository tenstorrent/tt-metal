# Known issues: glm53_flash_d_p

Model-specific lessons moved from the shared file. Shared lessons: `models/demos/common/bringup/knowledge/known_issues.md`.

- **[GLM-1] Vendored newer HF modeling code on an older transformers cache.** Symptom: a transformers-5.12 `DynamicCache` feeds the vendored 5.17 KDA conv its state, not the input; the forward raises KeyError `deepseek_sparse_attention`. Cause: 5.12's `update_conv_state` returns the state (5.17: [state | input]); config.json and the mask table name DSA layers differently. Fix: oracle with `use_cache=False`, a minimal 5.17-semantics cache, layer types renamed on the config (`reference/hf_oracle.py:GlmCache`). Detail: known_issues_detail.md. Found: glm53_flash_d_p R.2.
- **[GLM-2] Whole-output PCC hides mHC coefficient bugs.** Symptom: on the layer-0 attn_hc golden, a transposed comb, wrong softmax axis or 10 Sinkhorn iterations pass PCC 0.99. Cause: pre / post / comb scales differ; between-column variance dominates. Fix: rel L2 and max abs per part (pre/post 0.03, comb 0.02), comb column sums = 1 (`tests/bringup/test_c_kda_dense_attn_hc.py`). Detail: known_issues_detail.md. Found: glm53_flash_d_p C.kda_dense.attn_hc test.
- **[GLM-3] Block-out PCC is blind to mHC coefficient bugs.** Symptom: a transposed comb, post x1.05 or a zeroed row keep layer-0 block-out PCC >= 0.9985. Cause: the comb mix dominates out; PCC ignores per-stream scale. Fix: block-out rel L2 <= 0.01, per-row ratio [0.97, 1.03], plus per-part attn_hc checks (`tests/bringup/test_swap_kda_dense_01_attn_hc.py`). Detail: known_issues_detail.md. Found: glm53_flash_d_p S.kda_dense.01 test.
- **[GLM-4] Layer-0 mHC streams are identical, so layer-0 goldens cannot check stream order.** Symptom: pre columns reversed or stream-major rows score the correct PCC at layer 0. Cause: all 4 streams are the embedding: sum_n pre_n x_n = (sum_n pre_n) x. Fix: also run the weightless module on layer 1's golden; assert rel L2 and per-token ratio. Detail: known_issues_detail.md. Applies to: models/demos/glm53_flash_d_p/tests/bringup/test_c_kda_dense_attn_collapse.py. Seen at: 864ec8b0891. Found: glm53_flash_d_p C.kda_dense.attn_collapse test.
- **[GLM-5] A norm after the mHC collapse hides collapse bugs from the block out.** Symptom: a layer-0 collapse x1.02 passes block-out PCC and rel L2 0.01; only the per-row ratio sees it. Cause: attn_norm removes row scale. Fix: check the collapse vs golden and vs the same-input CPU collapse (rel <= 0.01, ratio [0.985, 1.015]), and on layer 1 (`tests/bringup/test_swap_kda_dense_02_attn_collapse.py`). Detail: known_issues_detail.md. Found: glm53_flash_d_p S.kda_dense.02 test.
- **[GLM-6] Small-RMS inputs make an RMSNorm's eps visible, and rel L2 0.03 misses eps bugs.** Symptom: on layer-0 attn_norm, eps 1.2e-5 for 1e-5 scores rel L2 0.027. Cause: row RMS 0.0023..0.0155, so mean(x^2) is the order of eps. Fix: measure eps mutations; rel L2 <= 0.01, ratio [0.98, 1.02], worst row <= 0.03. Detail: known_issues_detail.md. Applies to: models/demos/glm53_flash_d_p/tests/bringup/test_c_kda_dense_attn_norm.py. Seen at: 864ec8b0891. Found: glm53_flash_d_p C.kda_dense.attn_norm.test.
- **[GLM-7] KDA output metrics miss prefix-state bugs, and the gated o_norm is effectively a fixed scale.** Symptom: on layer-0 KDA, zeroed prefix state or conv tail, a transposed state or a wrong SP carry pass PCC 0.99, most rel L2 0.03. Cause: state error sits on a segment's first rows; core RMS << sqrt(eps), so eps sets o_norm's scale. Fix: rel L2 per 128-row block <= 0.03, worst token <= 0.1, check `dctx.extra["state_out"]`, o_norm eps exactly 1e-5 (`tests/bringup/test_c_kda_dense_attention.py`). Detail: known_issues_detail.md. Found: glm53_flash_d_p C.kda_dense.attention test.
- **[GLM-8] At an mHC layer 0 the block out follows the attention error, unlike a sink-dominated attention.** Symptom: on layer 0, block-out rel L2 is ~0.9x the attention's own (MiMo: a zeroed attention moved it 0.014). Fix: size limits from these runs (rel <= 0.01, ratio [0.97, 1.03]); check attention and state vs same-input CPU KDA (`tests/bringup/test_swap_kda_dense_04_attention.py`). Detail: known_issues_detail.md. Found: glm53_flash_d_p S.kda_dense.04 test.
