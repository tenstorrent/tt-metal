8K chunked prefill vs full 8K ragged batches

The existing chunked path is faster in all 11 measured full-8K cases.

Every ragged batch contains exactly 8,192 useful tokens. Both methods process the same requests. Chunked prefill handles each request separately with an 8K chunk; ragged attention handles them in one packed batch. A 2K or 4K label describes a request's contribution to the batch, not a different configured chunk size.
