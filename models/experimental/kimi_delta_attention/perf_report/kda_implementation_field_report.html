Matmul + reduce-scatter

The row-parallel output GEMM overlaps a Ring reduce-scatter. An 8×8 matmul grid leaves rows 8–9 available; four sender workers begin at (0,8).

→ [1,T,288] / chiplayer.py:398

The grouped scan composes the guide’s recurrence

Vnew = T⁻¹ · (vβ − kd · Sin) O = qd · Sin + Aqk · Vnew Sout = Diag(dl) · Sin + kdecᵀ · Vnew

Each eight-chunk group evaluates this exact recurrence; affine prefix composition supplies the correct incoming state without changing token order inside a group.

Five guide-to-source corrections

Projection: retained prefill uses one fused GEMM, not independent Q/K/V linears.
Layout: aligned Q/K/V stay flat; the prep reader addresses heads and chunks directly.
β dtype: sigmoid emits BF16; chunk_kda converts it to FP32 at the recurrence boundary.
Prepared storage: arithmetic stays FP32, but the selected prep→scan boundary stores kd, q_decay, and dl in BF16. Sensitive v_beta, k_dec_t, intra, t_inv, state, and outputs remain FP32.
Gate storage: aligned chunk prefill stores the transformed decay gate in BF16; recurrent/decode and all gate-consuming arithmetic remain FP32.
Routing: there is no automatic T threshold. The caller selects mode; fused recurrent accepts exactly T=1.

05 · roofline diagnosis

Grouped prefix removes the serial wall; compute remains far away and CCL is essentially there

Blackhole HiFi4 peak is 152.064 TFLOP/s per chip; DRAM is 512 GB/s, giving a 297 FLOP/byte ridge. The whole-layer compute percentage uses the 8-chip mesh peak and executed FLOPs. CCL uses the effective two-link payload roofline.

Kernel arithmetic-intensity roofline

Prep and scan sit far left of the ridge: more matrix-FPU peak does not move their roof. The useful levers are bytes, layout programs, state traffic, and parallel scheduling.

Fresh whole-layer target utilization

Interpretation. At T=5,120, CCL is 39.67% against the 40% aspiration—within 0.33 percentage points. Compute is 14.15% against 60%, but that does not mean the layer is simply an inefficient GEMM: recurrence remains memory/synchronization sensitive, output is communication-bound, and the grouped prefix adds useful work to shorten dependency depth.
Distribution consequence. Preserve the 8×8 output matmul grid and two RS rows. Attempts to donate matmul cores to CCL made the fused boundary slower. At long sequence, retain the 80 whole-V group owners; static prep/scan partitioning and both grouped-RMS fusion topologies regressed.

Compute target

Executed work grows from 67.594 to about 547.765 GFLOP, including affine summaries and prefix, while wall grows 5.14×. Utilization rises from 8.97% to 14.15%, so longer sequence amortizes fixed/layout overhead but does not change the memory-bound recurrence roof.

CCL target

Effective two-link utilization rises from 34.90% to 39.67%. The T=5,120 output boundary is the closest part of the layer to its aspirational target.

Serial axis

Prep grows from 80 independent items to 640 and fills all 110 cores. The long path replaces sixteen 160-chunk walkers with 80 eight-chunk owners plus a four-stage affine prefix.
