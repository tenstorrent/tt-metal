## Context

The op takes `attn` as `(N, Q, P)`, so BEVFormer permutes it head-major and spells `(num_levels, num_points)` out as real dimensions before every call. That spelled-out form is most of the cost: a `(4, 4)` trailing pair pads to a full 32x32 tile — **64x** — which is what a 3.61 ms untilize was paying for and what a 4.46 ms tiled reshape was building.

Profiling branch, N150: −17.9 ms kernel. Four SCA attn ops disappeared — a 4.99 ms permute, a 4.46 ms reshape, a 3.61 ms untilize and 2.41 ms of level slices. The op paid nothing: its read is 32 bytes where it was 8, one transaction either way, and attn is 3.8 MB against value's 92. Evidence, not a Blackhole result.

## Problem

- `attn`'s level and point axes exist as real dimensions only because the op names them; at `L = 4, P = 4` that costs a 64x tile padding.
- The head-major permute exists for the same reason.
- Slicing the padded `(4, 4)` tail per level forces an untilize/slice/re-tilize round trip.

## Proposed direction

- Accept `attn` as `(B, Q, num_heads*stride)` — every head's every level in one row — with `num_points` and `point_offset` naming the run this call wants. The reader reaches head `h`'s run at `(h*stride + point_offset)*2` bytes of the query's row.
- Select the packed form by row width: `attn` is packed exactly when its last dimension differs from `P`. `num_heads == 1` makes `N` and `B` the same number, so the batch dimension cannot tell the forms apart.
- Handle the alignment rule from #55232: at `P = 4, L = 4` the offsets for levels 1–3 are 8, 16 and 24, none 32-byte aligned. The reader rounds down to the boundary, indexes from there, carries the worst-case 30-byte lead-in in scratch, and clamps at the page end.
- Leave the softmax normalizing over each head's run unchanged; only the layout it is stored in changes.

## Acceptance criteria

- [ ] The packed form is selected by row width; the existing `(N, Q, P)` form is bit-identical.
- [ ] A run that would walk into the next head is rejected with a clear error.
- [ ] Unit tests cover the misaligned offsets explicitly — at `P = 4, L = 4` that is levels 2 and 3 — against the head-major slice of the same data.
- [ ] `models/experimental/vadv2` is unaffected, verified by running its tests.
- [ ] The profile shows the attn permute, reshape, untilize and level slices gone, and reports what the op paid.
- [ ] BEVFormer MSDA/TSA/SCA/layer/encoder PCC suites pass at their configured thresholds, including PCC >= 0.997 for the base encoder.
