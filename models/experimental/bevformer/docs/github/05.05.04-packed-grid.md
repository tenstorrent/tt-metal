## Context

After #55233 folds the point axis into the grid's page, the grid still carries head and level as real axes, so BEVFormer permutes heads ahead of queries and slices each level before the call. Packing both the way `value` and `attn` are packed deletes the last of that.

Profiling branch, N150: −4.6 ms kernel. The four grid level slices and the head permute went; `sampling_grids` leaves MSDA forward as one untilize and one reshape and is passed to all four calls untouched. The op paid 0.46 ms. Layout plumbing reached 15.4 ms with nothing in it above 1.9 ms. Evidence, not a Blackhole result.

## Problem

- The grid's head and level axes exist as real dimensions only because the op names them; materializing them costs a per-call permute plus one slice per level.
- As the third packed operand this carries the highest risk of interacting with the other forms — the grid would have three accepted shapes.

## Proposed direction

- Accept a rank-3 grid `(B, Q, num_heads*stride*2)` packing every head and level. The reader reaches a run at `(h*stride + point_offset)*4` bytes — four per point rather than attn's two, since a point is `(x, y)`.
- Select it by rank, so `(N, Q, 1, P*2)` and `(N, Q*P, 1, 2)` continue to work unchanged.
- Apply `point_offset` **only to an operand that is actually packed.** On the profiling branch applying it unconditionally read past the page end of an already-sliced grid, leaving the clamped read length at zero and the corner indices undefined. That did not fail a test: it hung the kernel and took the chip off the PCIe bus, needing an out-of-band `tt-smi -r`. The same latent bug existed for attn and never fired only because BEVFormer used the packed form exclusively.

## Acceptance criteria

- [ ] The rank-3 form is selected by rank; both existing rank-4 forms are bit-identical.
- [ ] `point_offset` applies only to packed operands, with a test covering the unpacked-with-offset case that hung the device.
- [ ] A run that would walk into the next head is rejected with a clear error.
- [ ] Unit tests cover `num_heads` 1 and 4 against level indices including the misaligned ones.
- [ ] `models/experimental/vadv2` is unaffected, verified by running its tests.
- [ ] The profile shows the grid head permute and per-level slices gone, and reports what the op paid.
- [ ] BEVFormer MSDA/TSA/SCA/layer/encoder PCC suites pass at their configured thresholds, including PCC >= 0.997 for the base encoder.
