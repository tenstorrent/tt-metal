## Context

SCA attends over four feature-pyramid levels. The available fused MSDA operation accepts one level, so a fused integration must launch it once per level and accumulate the four outputs.

A multi-level contract could remove repeated launch and packing work, repeated per-level preparation, and three output accumulations. Its value must be measured against four single-level calls before extending the operation.

## Problem

- [The current decomposed implementation iterates over every feature level](https://github.com/tenstorrent/tt-metal/blob/main/models/experimental/bevformer/tt/tt_ms_deformable_attention.py#L70-L106) and combines all sampled values afterward.
- [The fused operation's contract accepts one `(N,H,W,D)` value tensor and one grid](https://github.com/tenstorrent/tt-metal/blob/main/ttnn/cpp/ttnn/operations/experimental/multi_scale_deformable_attn/device/multi_scale_deformable_attn_device_operation.cpp#L27-L55), with no spatial-shape or level-start inputs.
- Calling the fused operation once per level repeats launch and operand-preparation work and requires separate output accumulation.

## Proposed direction

- Extend the benchmark in ticket `05.01` to compare four single-level calls with one call over the same total sampled points.
- If the benchmark shows a meaningful win, define a compatible multi-level contract using flattened values plus `spatial_shapes` and `level_start_index`.
- Keep attention weights jointly normalized over all level-and-point pairs.
- Coordinate native-layout support with ticket `05.02` so layout and level contracts are reviewed together.
- Preserve the existing single-level API for current callers.

## Acceptance criteria

- [ ] A benchmark isolates the percentage benefit of one multi-level call from unrelated model changes.
- [ ] The multi-level path samples the same points and applies the same jointly normalized attention weights as four single-level calls.
- [ ] Existing single-level callers continue to use the current contract without changes.
- [ ] The profile reports launch count, preparation time, accumulation time, and total device-time percentage change.
- [ ] Fused-op, VADv2, and BEVFormer MSDA/SCA/layer/encoder tests pass, including PCC >= 0.997 for the base encoder.
