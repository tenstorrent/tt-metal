## Context

The fused op splits work over `N = B*num_heads` and expects `value` head-major, so BEVFormer permutes heads ahead of the spatial axis and splits `embed_dims` into `(num_heads, head_dim)` before every call. On the profiling branch these were the two largest ops in the layer: a 10.01 ms head permute and the 4.83 ms split feeding it.

Addressing the head by offset means nobody ever produces that tensor. Profiling branch, N150: −20.5 ms kernel, `Permute` 25.9 to 11.9 ms, the level slice down 3.64 to 1.3 ms once it moved onto a 512-byte page. The op paid 0.94 ms. Evidence, not a Blackhole result.

## Problem

- `value` is materialized head-major purely so the op can name a head axis.
- The permute is bandwidth-bound on a 64-byte page, so it is not reachable by reducing call count — an earlier attempt to hoist it out of the level loop measured as a wash.
- The head split also breaks `value`'s 512-byte page from the projection into a 64-byte one, slowing everything downstream.
- The obvious alternative — a deformable member of the `nlp_create_qkv_heads` family — still has to write 92.6 MB and read it back, so it removes per-call overhead, which is not the cost.

## Proposed direction

- Add a `num_heads` argument. Above 1, `value` arrives as `(B, h_in, w_in, num_heads*D)` and the reader picks head `n % num_heads` out of the stick:

```
n_off    = (n / num_heads) * h_in * w_in      page:  batch picks it
head_off = (n % num_heads) * D * 2            bytes: head picks a range inside it
```

- Default `num_heads` to 1 so the existing contract and its callers are untouched.
- Leave everything else alone: work still splits over `N = B*num_heads`, and `grid`, `attn` and the output keep their shapes.
- `D % 16 == 0` is already required, which keeps `head_off` NoC-aligned — this is the one packed operand where the 32-byte alignment rule is satisfied for free.

## Acceptance criteria

- [ ] `num_heads` defaults to 1 and the existing single-head path is bit-identical.
- [ ] `num_heads` not dividing the channel count is rejected with a clear error.
- [ ] Unit tests cover `num_heads` 1, 2 and 4 against at least two `head_dim` values, comparing packed `value` against the head-major permutation of the same data.
- [ ] `models/experimental/vadv2` is unaffected, verified by running its tests.
- [ ] The profile shows the head permute and split gone, and reports what the op paid for offset reads.
- [ ] BEVFormer MSDA/TSA/SCA/layer/encoder PCC suites pass at their configured thresholds, including PCC >= 0.997 for the base encoder.
