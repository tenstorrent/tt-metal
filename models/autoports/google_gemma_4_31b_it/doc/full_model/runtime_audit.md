# Runtime audit

Model forward methods execute TTNN operations only. HF config, weights, tokenizer and full-context rotary tables are loaded during construction at revision842da3794eaa0b77d5f08bae87a17459d91ff475. The selected decoder is MultichipDecoder; no stock Gemma adapter or host decoder is imported. The two-layer probe uses the same wrapper, real shapes, dtypes and terminal path, but is explicitly reduced scope.

Decode traces consume persistent token storage, signed positions, KV tensors and page tables. Sampling is a separate trace and writes directly to the token storage read by decode. RoPE conversion/lookup and plus_one position advance execute on device. High-level autoregressive replay has no host token feedback or position rebuild. Explicit teacher forcing overrides token input, as required by readiness; host_sampling is a separate compatibility path and must never supply headline performance.

PreparedPrefill uses runtime tensor offsets, fixed page views and device last-row selection. Normal prefill computes only the selected row's logits and invokes the sampling trace; full-logits readback is confined to the explicit prefill_logits readiness API and host-sampling compatibility path. Cache reset and all32 physical tail signatures are warmed before capture. No corruptible allocation scope or allocation-tracker exemption is used. B1/8/16/32 repeated replay gates pass with program-cache allocations included; `generator_state_b*.json` records feedback, positions, changed/unchanged maps and stable trace/program counts.

External cache/page-table handles bind at construction and remain identical for the trace lifetime. Ownership maps must be identical within each attention kind, as required by the shared prepared prefill views; invalid block indices or differing maps are rejected. The scheduler changes mapping contents through refresh_page_tables(revision=...), which skips unchanged revisions. Internal standalone ownership allocates disjoint rounded128-token request windows from a pooled full-attention cache; sliding caches retain64 cyclic32-token pages per slot. No cache copying or host attention occurs.

All-layer top-k, six HF/TT qualitative controls, mixed/inactive slots and all configured batches pass. Full batch8 includes holes before and between active slots; inactive−1 cache readers skip before page access. `check_pool_admission.py` verifies exact-context pool admission and rejection of invalid decode token/position state before device execution. Final repaired-source full maximum-context execution passed at 262143/262144, including the last legal decode position. Explicit host compatibility also passed with one full-logit read for each of eight tokens, including the first. Final tracked reduced B1/8/16/32 gates pass per-active-slot seeded sampling, repeated-seed equality, changed-seed output changes, greedy recovery and1023/1024/1025 tails on the same two traces. Direct full-stack full-vocabulary logits are bitwise equal across all 32 slots and both repeated requests after four generated tokens (logit_determinism.json).

`ttnn.CONFIG.throw_exception_on_fallback=True` is enabled in final batch and watcher runners. The representative watcher gate passed with14 complete dumps and no fault; its inherited Ethernet instrumentation setting and raw log path are in watcher.json. No reset, process-owner termination or hidden hardware recovery occurs in the model/generator. Kernel-cache/program allocation warnings and fixed fabric packet-size efficiency warnings are retained; they are not host fallback. The selected fabric/CCL policy is inherited from the optimized decoder.

reset currently zeroes retained cache buffers without replacing weights/traces. Its BFP8 zeroing program needs warmup before capture. Mesh teardown belongs to the caller; no automatic reset or device-owner termination is implemented.

The wrapper embedding gather now uses the same device barrier contract as decoder prefill collectives. A controlled reduced probe without this barrier showed changing logits even with sampling/decode disabled; adding only the barrier produced11 bitwise-identical comparisons. No host synchronization was retained. See AUTODEBUG_REPEAT.md, AUTOFIX.md and prefill_repeat_probe_barrier.json.

Sampling parameters are normalized for every configured slot before shared formatting. Stochastic top_k outside1..32 is rejected rather than clamped; top_p applies within that candidate set. This is not HF-default stochastic-distribution parity. Greedy defaults remain on-device. The explicit host compatibility mode is greedy and reads logits only when requested; normal token-out measurements never take that branch.

Mesh reopen belongs to the harness: Metal teardown clears fabric configuration. The clean multi-batch runner now reapplies Ring before each mesh open. Its B32 row passed before this harness repair; B16 and B8 subsequently passed in one process, directly validating repeated mesh setup. No model fallback, reset or recovery was added.
