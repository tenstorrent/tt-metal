# Final profile analysis

The eight `tracy_final/{sliding_attention,full_attention}/batch{1,8,16,32}` directories contain advice-enabled prefill/decode text tables, CSVs, complete-window performance JSON and provenance. Whole-layer device time spans the first through last operation on each participating device, including gaps, then takes the maximum device window. Decode averages 128 advancing complete replays. `performance.md` compares identical workload profiles before/after. Profiler overhead and host input copies are not mislabeled device time. Runtime projection precision is verified as BFP4/LoFi.

The report's missing-program-config advice for prefill reflects unsupported parsing of `MinimalMatmulConfig`; the runtime explicitly selects M4/K8/N16, subblock 1x8, grid 11x10. Larger K, changed grid and padded-width controls from stage04 remain applicable. Stage05 tests L1 input advice at every meaningful larger-batch role or establishes an exact capacity bound, then tests streamed families that remove the bound. See `input_l1_trials.md`, `input_l1_failures.json` and `input_l1_capacity.json`. Failures were adapted rather than used as first-error rejections. The selected configuration remains faster.

Decode projections already use DRAM-sharded weights, L1 working activations and explicit geometry. `dominant_matmul_search.md` records larger legal K/grid controls under BFP4/LoFi. No selected material projection has K block <=2 or output subblock <2. `readers/*/performance.json` compares one/two readers with real captured operands, fixed geometry, alternating trial order and identical PCC; two readers wins every role. Full QK's legal three-reader variant also loses. These isolated operation times supplement, and do not replace, the whole-layer comparison or roofline denominator.

Topology, residual layout, fused CCL, packed projections, activation precision and persistent buffers are compared in `optimization_audit.md` and `ccl_report.md`. The selected 46-operation decode capture removes avoidable movement while retaining the measured faster replicated residual contract. No gather, reshard or all-reduce is required between decoder layers.

Prefill tracing was explicitly tested on both real 4096-token default paths. Excluding the first warm timing outlier, eager median versus eight-replay trace median is 10909.50 -> 10666.33 us for sliding and 13312.98 -> 13356.23 us for full attention. Capture costs are 13605.61 and 13991.55 us respectively. The mixed benefit does not justify an internal trace wrapper; both default layers already compose into caller-owned prefill traces. The headline preserves comparable warmed eager prefill and traced decode. JSONs retain all samples and capture costs.

The B8 full-attention capture encountered an unmatched device-profiler marker after completing numerical work. The identical bounded rerun passed with no reset; only that complete rerun supplies final numbers. `profiler_anomaly.json` records the scope. Worker watcher acceptance was separate from profiler collection. Ethernet watcher instrumentation is disabled because its kernel configuration exceeds the available buffer by 2640 bytes; this is a scoped instrumentation limitation, not an assertion of Ethernet watcher coverage.

Roofline calculations use useful projection and causal-attention FLOPs, physical operand/cache transfer estimates with tile headers/padding, and the theoretical peak of four participating Blackhole devices. Elementwise FLOPs are omitted from the useful-work estimate, not from the denominator. Bandwidth is an estimate, not hardware counter traffic. Each performance JSON states precision and assumptions. These are dense layer results; MoE, sampling, text quality, vLLM and full-model accuracy do not apply to this stage.
