# Actual branch logits diagnostic candidate

This candidate compares full-vocabulary logits on the exact 2048-ID Requests-5414 call-11 suffix. It captures seven rows on each of two forced histories, including the decisive row after shared history `[1390, 107]`. The source fixture is copied byte-for-byte; each branch is bound by hash and host validation to the exact first six tokens of its observed seed-44 TT or pinned-HF result. No third branch is added.

`tools/actual_branch_logits.py` is inert by default. `--validate-only --mock-tests` imports no torch, Transformers, TTNN or model code. Execution requires explicit `--execute` and a mode. HF runs use the pinned revision on CPU BF16 with the same P[:-1] chunk-512 prefill semantics as the existing HF diagnostic, followed by one-token decode calls. TT selected/full use existing build kwargs and the generator callback with `host_sampling=True`, `buffered=False`, preserving the original P prefill.

Each capture saves canonical full-vocabulary logits to a private local `.pt` file and writes a JSON summary of top32, target ranks/raw softmax, the top-k20-only distribution, and two nucleus reconstructions: nominal HF `p=0.95` and `p=0.94921875`, the BF16-rounded scalar. Strict top-k20/nucleus supports are deterministic host proxies: HF may keep every tie at kth logit and device support is not exposed. These reconstructions do not simulate device probability quantization; raw logits and ranks are primary evidence. The comparison utility reports PCC/error, raw-softmax TV, top20 support overlap, and separate top-k20, nominal top-p, and BF16-scalar top-p TVs. The TT prefill still performs its usual sample operation, whose sampled token is ignored; later logits are read to host and the callback forces the branch.

Host-only mock tests exercise callback step/index and forced-history values, captured row count, cleanup failures while preserving an original generation error, comparison artifact validation and metrics, distinct top-k versus nucleus distributions, and import inertness. They do not instantiate a model or device.

The run plan is HF, selected TT, full TT, then three saved-artifact comparisons, serialized. Forecasts are planning estimates from already completed matched 2048 sources, not performance claims. No inference output exists, this candidate is not admitted, and the results can only diagnose branch-conditioned logits; they do not establish native incidence or a causal implementation bug.
