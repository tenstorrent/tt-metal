# Selected default precision propagation

The installed default is **`combined_shared4_mixed`**. A CPU-only audit compared the measured winning sweep result (`combined_shared4_mixed_v1.json:runtime_precision`) and the post-selection normal-builder benchmark (`post_selection_token_out_v1.json:performance.runtime_precision`) against the actual default returned by `tt/precision.py:load_policy(model_root)`. **4,258 equality checks passed, with zero mismatches**, including 96 additional default/cache/token-out assertions and 10 final-validation checks. Exact counts and evidence roots are in `selected_precision_propagation_audit.json`. No TTNN import or device execution occurred in this audit.

This report supersedes the selected-artifact-absent statement in `precision_propagation_audit.md`. That earlier report's field-by-field consumer mapping and fixed-numerics interpretation remain applicable.

The normal benchmark constructed without an explicit precision override. Its `performance.selected_default_snapshot.policy_equals_runtime=true`, `passed=true`, and selected-file SHA256 `68dbcc6ca583ac3a97770654f95a81222dc186e269fa32d04dbc6be3e015105d` match the installed artifact. The public planner consumes the same default and the persistent-weight delta **−579,624,960 bytes/rank**. It records 28,030,559,232 bytes/rank of known resident memory, 2 GiB reserve and room for 10,174 pool blocks. Public requested context remains **262144/B1**; `public_max_tokens_all_users=262176` includes the extra null page rather than increasing model context. This planning proof and real full-size allocation do not alone assert a fresh maximum-length execution; the selected KV dtype/layout are unchanged and the final 32K–64K smoke is separate evidence.

Observed candidate loaded allocator savings are **579,723,264 bytes/rank**, 98,304 more than the exact persistent-weight prediction. The planner credits only the derived weight savings. The residual is small constructor allocation accounting and its precise owner has not been isolated; no extra capacity is inferred from it.

The post-selection optimized comparator has **9.801183224429764 t/s/u**, and the public resident decode path has **9.80396029254529 t/s/u**. Both use batch 1, 128 prompt tokens, 128 generated tokens and 127 measured decode steps, with 127 model/sampling trace replays, zero per-token reads/refreshes/captures, and final readback outside timing. All 48 QSA rank/layer positions equal 255, persistent input identities remain unchanged, and first/final tokens match caller-read control. The accompanying public generate TTFT is **4711.342390161008 ms**, including reset/setup, complete prefill, first sampling and caller read. Ordinary caller-read token-out is separately 9.793710473440115 t/s/u; teacher-forcing selection remains a separate regime.

The raw historical `decoder_stack_comparison` uses Stage5 isolated blocking traces and the former precision policy. Its negative `layer_stack_overhead_ms` values are arithmetic differences across regimes, **not a physical negative model overhead**. They are not selection or serving headline metrics. The source manifest records unchanged model/native/shared sampling/CCL sources across setup and performance.

No material configurable field was found ignored. There is no vLLM adapter in this scope. A future adapter must call the public selected-default builder and matching planner/cache interfaces; this audit does not claim an adapter or serving test.
