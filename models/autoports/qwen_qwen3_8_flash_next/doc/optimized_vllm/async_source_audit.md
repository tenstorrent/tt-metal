## Historical finding and proposal — superseded by the applied repair above

The remainder of this section preserves the original pre-repair analysis and proposed alternatives as history. Its present-tense cap32 limitations and two-owner suggestion are **superseded**, not descriptions of current source. At the time of that investigation this was a proposed contract change, **not implemented or hardware-validated**. The root agent owns the separate native AutoDebug investigation. Its proposed presorted64 native draw interface is a dependency here, not assumed to work already. No plugin change is needed: its existing route decision consults the model capability, and `input_batch.py` preserves an ordinary k40 request. Its nearby fixed-top32 comment is not a runtime clamp. The actual clamp is common `format_sampling_params`, followed by `TTSampling._normalize_device_params` using its constructed `max_top_k`.

Merely setting constructor `max_top_k=64` is unsafe. Native sampling `compute/sampling.cpp` hardcodes `nearest32_K=32`, `logk=5`; its reduction packs only the winning32 per merge pair. The writer waits for one tile and walks two16-element row faces, and the factory sends `ids_per_batch=32`. Passing k40 can therefore read the next row rather than candidates33–40. Increasing the local candidate width alone does not fix the draw. Changing only the native K constant also fails to repair the merge algorithm, writer indexing, mask production, and buffer credit counts. These are correctness blockers to a Python-only patch.

The smallest integration that preserves existing all-<=32 runs is **two prepared sampling families**, with family32 retaining today's exact operations and buffers, and family64 used only when an actually sampled row requests non-greedy k>32. An always64 sampler would change the greedy operation sequence, candidate order, and cost. Existing full-model component evidence reports split sampling0.481938ms on its representative standalone workload, not a serving profile; there is no basis to burden every greedy step with a wider draw.
