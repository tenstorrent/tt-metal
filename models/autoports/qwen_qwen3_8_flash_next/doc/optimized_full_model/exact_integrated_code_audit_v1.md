## Findings and required coverage

1. **Integration coverage: rank-sum replacement has wider scope than GR.** `Collectives.sum` retains synchronous BF16 `all_gather`, then replaces the local reduction for standard DRAM tiles `[1,4,Q,2560]`, Q=1..32. Besides GR and FinalMixer, matching callers include MoE routed/shared output, QSA output projection, and packed PLE embedding. These consumers preserve their existing scale/cast and residual layouts. The all-Q component tests support the common arithmetic, but the integrated suite must exercise these siblings and their trace lifetimes. Savings must be attributed across actual callers rather than described as a GR-only change.

2. **Coverage limit: finite projection operands and synthetic activations.** Current R16 Watcher and clean probes use real role weights with deterministic synthetic activations. They establish raw-FP32 and BF16 equality for selected GR-up/GDN-out geometry, including changed-input replay, but not NaN-payload propagation or all real model activation histories. Keep the declared finite-operand scope and run the integrated accuracy/resident/non-aligned gates. GR-up's explicit BF16-to-FP32 precast is covered by the current R16 evidence; older no-precast records alone would not suffice.

3. **Low severity documentation drift.** Module docstrings in `exact_projection_q1.py`, `exact_rank_sum.py`, and `exact_residual_write.py` still claim they are unwired/test-only or that production dispatch is unchanged. They are now imported and selected in `multichip_decoder.py`. Update those descriptions after the source freeze. `exact_rank_sum_plan.md` also retains an obsolete fixture-repair description; the passing fixture uses public two-shape `ttnn.reshape` with explicit padded shape, not the failed one-shape logical-volume-changing view.

## Source checks

| Area | Checked result |
|---|---|
| Projection dispatch | Only GR-up and GDN-out opt in; Q1 uses R16, `zero_once=True`. GR-up alone requests FP32 precast when BF16 activation meets FP32 weight. Q2..32 inherits the selected projection. Q>32 explicitly calls the base implementation per chunk, including a Q1 tail, avoiding accidental native dispatch from recursive `self(...)`. No alignment restriction was added to caller prompt lengths. |
| R16 physical addressing | R16 divides the 32-row weight tile. Reader groups start at row 0 or 16 within a tile, read both 16-column faces, and fit within each face. Eight SFPU iterations cover the full top 16-row band. Weight rows are copied into that band; query row 0 is broadcast. Output assembly maps 32 columns into the correct two faces and owns complete output tiles. |
| Projection arithmetic | Separate FP32 product and K-tile accumulation, first-product seed, accurate SFPU row reduction, then explicit BF16 output cast. FP32 CBs request unpack-to-DST FP32. Both SrcA/SrcB formats are restored before query broadcast; the earlier mixed-format failure is not present in this source. No matmul, K split, FMA, or balanced-tree policy substitution. |
| Projection initialization/lifetime | `zero_once` clears both physical pages of each input CB on every invocation. Compute only reads those CB pages. Scratch is invocation-local, every group writes its 128-byte page, and assembly zeroes and writes every full output tile. Scratch/raw tensors are passed to each queued generic operation; no helper cache, explicit early deallocation, input alias, or shared-output writer was found. Tracked integrated replay is still needed to validate lifetime in the larger allocation graph. |
| Rank-sum arithmetic/padding | Fresh FP32 output; each of 80 feature tiles has one worker. Four gathered rank planes remain ordered. Each operand receives the two positive-zero additions before the selected right-nested rank tree, preserving tested signed-zero behavior. All physical token rows are processed independently, so unused token padding cannot feed live rows. Output padding is not promised to equal the generic reducer's padding; reviewed consumers use logical token extents, and no cross-token reduction of that padding was found. |
| Residual writer | Fresh output, one owner per full feature tile. Injection reads the matching row's column 0. Explicit BF16 rounding after FP32 multiplication and again after FP32 residual addition preserves both inherited BF16 boundaries. Inputs remain immutable and retain four distinct rank streams. Q1..32 share one physical token tile; Q>32 retains the old path. |
| RMS fusion | Full 2560-wide per-stream square/mean is unchanged; RHS epsilon/rsqrt is merged into multiplication, followed by the same FP32 learned scale and BF16 output. This does not select the previously rejected native RMS reduction or a replicated stream. |
