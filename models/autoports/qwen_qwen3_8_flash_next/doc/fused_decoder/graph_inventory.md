# Graph inventory and movement boundaries

This is a source-derived graph inventory, not measured per-op timing. The final
whole-trace profiler tables provide actual complete-pass device intervals. Each
public prefill calls the physical graph for 1..32 logical rows; decode uses one row.
All buffers below are device buffers. Checkpoint upload, immutable packing and
index-table preparation happen before measured execution.

|Subgraph|Functional sequence|Candidate rewrite / movement|
|---|---|---|
|Public chunk I/O|Read actual BF16 rows and encoded token words; assemble actual output rows|Inherited bounded generic copy kernels; arbitrary logical tails preserved. No padded row advances state.|
|PLE, layer1|Device n-gram hash with request token history; packed resident lookup; four norms/projections, gates and temporal convolution|Hash input/index words remain row-major as required by the native readers; lookup delivers device features. Sigmoid/multiply and SiLU/add folds tried separately. No table or token computation moves to host.|
|Four-stream residual read, twice/layer|Group10240 as4x2560, permute, FP32 square/mean/epsilon/rsqrt/weight, BF16; flatten; precise down10240->320; SiLU; precise up320->10240; sigmoid; stream mean and injection|Native RMSNorm changes source precision and fails integrated routing. Original normalization retained unless an explicitly measured exact partial merge is selected. FP32 product/addition projection trees become accurate SFPU sum; independent output blocks merge directly from checkpoint data at setup for decode. BF16 weight widening occurs inside the SFPU unpacker; FP32 weights bypass redundant casts. Prefill retains bounded product blocks. Grouping permutations change element order and cannot be dropped.|
|GDN projections|Precise QKV2560->10240 plus z2560->6144/a2560->48/b2560->48|A dedicated QKV product/half-tree kernel preserves the original FP32 addition order after the accurate-sum candidate failed batch32 request3; checkpoint RHS permutes once at setup; shared-LHS z/a/b become one packed native projection with output slices. Learned weights remain unchanged.|
|GDN convolution|Concat3 history rows, four shifted FP32 products, pairwise sums, BF16 boundary, FP32 SiLU, BF16; split Q/K/V|Native causal-convolution fusion is rejected after a synthetic decode failure. The selected model-local SFPU kernel preserves original FP32 pairwise products/sums, explicit BF16 RNE, FP32 SiLU and second BF16 RNE. It consumes real history and excludes padded rows from state advancement.|
|GDN recurrence|FP32 normalized Q/K; decay/ beta; permute/repeat heads; generic SFPU recurrent kernel; state copy; gated norm; precise output6144->2560|Existing dedicated recurrence kernel retained. Metadata-only reshape removes redundant row-major round trips. The selected compact reader additionally folds head repeats and padded token/scalar expansion, and the writer returns compact logical rows without changing kernel arithmetic. Output projection tree uses accurate SFPU sum.|
|QSA projections|Separate Q+gate, K, V native projections; slice/reshape/permute; per-head norms|Setup shared-LHS packing, gate-aware prefill head split and native decode heads tried. Decode heads require L1 sharding followed by interleaved DRAM conversion for existing consumers.|
|QSA rotary|Position embedding lookup into cos/sin; partial64-wide rotate-half; exact128-wide indexer special case|Position indices are row-major for embedding, tables produce row-major selected rows, then TILE for arithmetic. Native main-Q/K rotary and token_index0 adaptations tried; logical token/head trimming required. Exact indexer rotary BF16 boundaries retained.|
|QSA indexer|Dedicated ordered indexer projection; query norm/rotary; four-row FP32 sliding pool; key norm/rotary; selected-key scores/topk|Pinned ordered projection arithmetic is preserved; its fused reader materializes broadcasts only for valid rows. Four peer score graphs merge; accurate SFPU sums replace their128-wide trees after full-capacity score/set controls. A device FP32 heap selector fuses causal masking, top512, four-token expansion, sentinels and partial-group tail. Pool concat+mean is rejected as slower. QSA selection defines ascending-index ties within the native non-stable contract; the MoE router retains its separate exact ATen tie contract.|
|QSA state and attention|Serialize per-token paged K/V writes and compressed-key writes; selected paged cache gather; explicit mask; native SDPA|Cache updates use row-major integer positions; required by paged update interfaces. Existing SDPA already fuses score/scale/softmax/value product. Physical page remapping remains request-owned.|
|QSA output|Sigmoid gate, multiply, head permute/reshape, output projection|Binary input sigmoid and dedicated concatenate_heads; native decode concat adapted and measured with required height sharding and DRAM return.|
|MoE routing|Precise2560->512 logits; BF16 boundary then FP32; ATen-compatible top10; stable softmax; scatter dense scores; max over token tile|Router projection tree becomes accurate SFPU sum. Device BF16 empty+fill avoids a redundant FP32 zeros/cast pair; dense score layout uses a metadata-only reshape. Dedicated tie-compatible selector and stable softmax retained. Sparse-matmul activity mask must be row-major.|
|Routed experts|Sparse gate/up projections; SiLU then multiply; sparse down; multiply512 expert rows by scores; sum experts|Physical count 1 uses 10 sorted device expert IDs; physical count 2 uses the device union in at most 20 fixed slots with zero scores for padding. Both use compact native indexed sparse matmul. Counts 3..32 retain the 512-group tile-union graph. The threshold is internal and does not restrict public logical lengths. Setup packs gate/up with40column cores. A dedicated packed reader folds slices, exact BF16 SiLU and multiply; early destination allocation preserves PLE capacity. Sparse matmul's activation config is ignored and cannot substitute. Score-weighted dedicated DeepSeek reduction consumes row-major scores and expert IDs, replacing weighted large output plus sum.|
|Shared expert|Gate/up/route projections sharing input; SiLU*up, down projection, sigmoid(route)*output, add routed output|Setup gate/up/route packing, binary SiLU and sigmoid input activation folding. Dense matmul activation and routed gate/up packing tested independently.|
|Residual write|Injection update, permute/flatten, FP32 residual add and final BF16|Selected dedicated writer reads block, injection and residual directly; preserves product BF16 RNE and final BF16 RNE, and writes the final four-stream layout. The intermediate cast/permute graph is eliminated. Standard 32x32 TILE DRAM shapes are checked before dispatch; no host step.|

Full pattern-by-pattern decisions and exact evidence paths are recorded in
`pattern_assessment.json` and `work_log.md`. Historical candidates remain explicitly
labeled and cannot substitute for final default correctness or timing evidence.

The selected final defaults include `fuse_residual_write=True` and
`compact_prefill_limit=2`. `wrap_final_plan.json` records the final-default
closure jobs; their results, not this source inventory, determine completion.
The owner wall-cap instruction ends further candidate tuning. See
`wrap_handoff.md` for untried ideas.
