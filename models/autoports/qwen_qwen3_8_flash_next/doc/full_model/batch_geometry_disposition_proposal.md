# Proposed disposition of the batch-geometry diagnostic

CPU-only proposal, 2026-11-14. **No gate is waived or promoted by this document.** This is not stage-review. The original failed artifacts and thresholds remain unchanged. The initial review preceded the sampled-token run; the dated evidence update below supersedes its pending reduced-test status.

Proposed decision, conditional on the evidence below: retain the inherited n1 FP32-DEST / n>1 BF16-DEST routed-reduction policy; retain the cross-width result as a failed numerical diagnostic with an explicitly reviewed inherited-policy limitation; judge serving correctness through exact same-history reproducibility/state ownership and direct HF accuracy. Do not introduce an FP32 batched fallback or per-row execution to manufacture cross-width equality. This disposition is unavailable if a required same-history, sampling, cache, feedback or HF-accuracy gate fails.

**Terminology correction:** `shared_pool_generator_v5` does not instantiate a configured-B1 TT generator. Its solo controls are single-active n1 calls within configured B2, compared with active n2 and a B2-history singleton survivor. The original `probe_full_model_batch.py` similarly uses single-active controls inside its configured larger generator. Original HF controls do use true B1/B2 tensor geometries. A true configured-B1-versus-configured-B2 TT wrapper equivalence claim therefore requires separate evidence; neither the historical probe nor the pending new probe proves it.

The full-model skill explicitly requires deterministic repeated greedy behavior, logit reproducibility across batch positions, mixed-prefill batched-equals-solo, and correct larger-batch state/feedback. These remain hard requirements. Row relocation with the same width/history must not change request semantics. The skill does not supply the locally adopted universal cross-width PCC/top1 bounds. The user's explicit policy-preservation instruction also does not promise that two differently rounded arithmetic paths produce identical logits. A reasonable opposing reading is that “batch positions” includes arbitrary scheduler-concurrency changes and the adopted frozen gate is binding under “failed gates: work.” That objection requires an explicit stage-owner/reviewer decision; it cannot be erased by relabeling a failure or by this proposal.

The matched HF evidence supports recording a narrow numerical limitation: deterministic outputs may depend on active-width history on the tested original-HF backend and selected TT arithmetic. It does **not** establish identical severity, universal backend behavior, a distribution/logprob error bound, or completion of the separate matched-seed/blind qualitative-check exception. In particular, the historical TT43 short-request solo token 78917 is within HF top5 while the B2 token 71111 equals HF argmax. Its TT-self top5 failure is therefore not automatically a failed HF-accuracy gate. The larger PCC discrepancy still belongs in the limitation and review evidence.

## Audit of the pending probe

Source review found no blocking history-mapping or scoring defect. The probe uses one current configured-B2/C128 shared pool, explicit seed lists, request-ordered authoritative migration parameters, and request0 surviving in physical slot1 after release of slot0. Saved HF rows are selected by original request identity and exact forced-history step. Actual device predictions are checked against the maximum of the same call's full TT logits; HF top1 uses `argmax`, with ties separately reported. Repeats are excluded from accuracy denominators. A second-suite check requires unchanged trace IDs/program count and no capture/release. Tracking is required before TTNN import and full logits never feed the next token.

Limitations are intentional and explicit: forced inputs do not prove free-running feedback; no full-cache/RNG-state equality assertion is added here; configured-B1 equivalence and actual hardware success are unproven. A zero exit from this diagnostic does not make the separately reported frozen failure pass. CPU self-test and pinned formatting checks passed previously; this audit did not run devices or change source.
