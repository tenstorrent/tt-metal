# Preserved decoder policy and full-model boundaries

The inherited selection is `tt/multichip_decoder.py`, TP4 attention and hybrid TP4 indexed / EP4 grouped MoE on the 1x4 Blackhole mesh. The previous stage's [residual contract](../optimized_multichip_decoder/residual_contract.md), [candidate decisions](../optimized_multichip_decoder/optimization_decisions.md), [topology audit](../optimized_multichip_decoder/topology_audit.md), and rejection evidence remain authoritative. This stage does not replace rejected families or reinterpret their performance as accepted results.

The selected replicated BF16 residual is an activation distribution; all four chips continue to execute their attention/expert shards. B1 keeps its selected L1 width-sharded carrier. Fixed-slot batched decode retains the decoder's DRAM singleton tuple between layers. No wrapper collective is inserted between layers. The embedding gathers hidden shards once, while the vocabulary-sharded LM head keeps logits distributed for the common sampler. Terminal normalization canonicalizes its own input to DRAM; the singleton equivalence artifact proves this matches the legacy terminal result exactly.

Ordinary/expert weights remain BFP8, activations and CCL payloads retain the selected BF16/FP32 exceptions, ordinary/shared projections use selected HiFi2 and routed expert computation LoFi, and router selector arithmetic remains FP32. FP32 recurrent matrices and BF16 convolution history are separate from full-attention paged KV. KV backing remains BF16 TILE with page size32 and duplicated head ownership[0,0,1,1]. Prefill explicitly casts fill payloads to the destination dtype; decode retains the native paged-update input/repack contract. No shared cache dtype variable collapses these distinct boundaries.

The full model adds BF16 hidden-sharded embedding, BFP8 vocabulary-sharded untied LM head, and the HF offset RMSNorm weight (`1 + weight`) in FP32. Its head uses HiFi2 with FP32 accumulation. One shared collective workspace is consumed serially across the layer stack. Identical immutable SiLU lookup storage is shared, and unreachable inherited router buffers are released after layer construction; selected mutable selector outputs remain layer-local. These storage repairs do not alter decoder computation.

## Full-model boundary inventory (source-derived)

The mesh is 1x4, hidden width H=2048, and vocabulary V=248320. `padded_vocab_size=ceil(V/128)*128=248320`, so each rank owns 62080 contiguous vocabulary columns. Let B be the prepared decode capacity (1–32), R the logical terminal row count, and P(R)=32*ceil(R/32). Shapes below are **per rank**, with singleton leading axes omitted where stated; TILE padding is distinct from mesh replication. Sources: [model construction/embed/terminal/decode](../../tt/model.py), [bounded prefill](../../tt/prefill.py), [generator buffers/capture](../../tt/generator.py), and [common sampling](../../../../common/sampling/tt_sampling.py).

### Boundary communication accounting

These are source-derived **tensor payload/received-byte formulas**, not measured Ethernet wire traffic; they exclude protocol headers, alignment, semaphore traffic and topology forwarding. For a four-rank all-gather with S source bytes per rank, each rank receives 3S new bytes and aggregate new delivered payload is 12S.

- Embedding: S=`P(R)*512*2` BF16 bytes. Each 64-token bounded-prefill chunk has S=65536; each decode slot has S=32768 because its singleton is tile-padded to32 rows. Decode therefore has B such gathers per model step; prefill has `ceil(prompt_suffix_length/64)` per submitted prompt. Their aggregate delivered payloads are respectively `B*393216` and `ceil(length/64)*786432` bytes. These occur only at model entry, not per decoder layer.
- Terminal norm and LM head require zero cross-chip payload. Layout conversion, norm casts and copying logits into the persistent sampler buffer are device-local traffic, not CCL.
- Split sampling gathers 32 physical rows ×32 candidates: S=`32*32*(2+2)=4096` bytes/rank across the value and UINT16-index gathers, giving 12288 received bytes/rank and 49152 aggregate delivered bytes per sample. Global-index widening occurs after those gathers. No separate sampled-token gather is needed because every rank receives the same candidates and has replicated parameters/seeds.
- For comparison, a full physical-32-row vocabulary gather would have S=`32*62080*2=3973120` BF16 bytes/rank before any argmax. This is an explanatory shape formula; the measured alternative below is authoritative for its actual runtime.

## Fixed-slot arithmetic repair

A new backwards-compatible fused-MoE `stochastic_rounding=True` argument preserves all existing callers and prefill. Fixed-slot batched decode explicitly selects deterministic rounding. With stochastic FPU rounding, the arithmetic for one request depended on expert counts from other requests in the same launch. Real-weight diagnostics held its MoE input and shared-expert output exact while routed output changed. Disabling only this rounding removed that dependence. Capacity>1 now uses one fixed-capacity trace even when only slot0 is active; capacity1 keeps the selected fast singleton path. Dtypes, fidelity, projections, collectives, and inter-layer layout remain unchanged.

Evidence: `AUTODEBUG_MIXED.md`, `AUTOFIX.md`, `generator_replay_probe/mixed_fixed.json`, and `generator_replay_probe/final.json`. The final reduced replay passes solo-versus-mixed rows, changed/unchanged pages, inactive rows, arbitrary prompt lengths, continuation, and seed reproducibility with8489 program entries and zero growth. Full-stack batched top-k accuracy is a separate acceptance requirement, not inferred from this reduced probe.

The broad alternatives remain rejected: globally disabling stochastic rounding would change prefill unnecessarily; switching between singleton and fixed-batch numerical paths within one prepared capacity breaks request isolation; host routing or host sampling would violate the measured token-out contract. The explicit host-sampling compatibility mode is never selected automatically.

All40 fixed-slot numerical acceptance now passes (`batched_teacher/result.json`): each of three slots has combined top1=.98, top5=1.0 and top100=1.0 over100 AIME predictions. This validates the retained policy with the deterministic batched rounding repair; reduced request-isolation evidence remains separate.
