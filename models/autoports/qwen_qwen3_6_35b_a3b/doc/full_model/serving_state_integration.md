# Explicit reload, slot remap, and output ownership primitives

Status: **source implementation, not integrated or device-validated**. This document does not establish a serving capability. `tt/serving_state.py` is the only runtime source added by this task. No generator/model/decoder source was edited and no device was used.

Source contract: `vllm-tt-plugin@042a94863ad27d88207bcf71abdf67122c6f4c27`, `docs/DECODE_RELOAD_CONTRACT.md`, `docs/MODEL_LIFECYCLE.md`, `docs/MODEL_EXECUTION.md`, `src/vllm_tt_plugin/model_runner.py::_decode_state_slot_remap`, `src/vllm_tt_plugin/async_decode.py`, and `tests/test_decode_reload_contract.py`. This is a full-model generator primitive, not a plugin adapter or vLLM integration.

## Implemented primitives

- `ReloadCommands`: four independent strict boolean commands, plugin defaults, rejection of full-input plus page-only reload and state-reset without authoritative inputs. `from_kwargs` rejects legacy `reset_batch` and runner-private `decode_layout_changed`.
- `SlotState.from_generator(generator)`: captures every current per-slot recurrent/conv/page-table tensor, stable positions/activity, packed tokens, staging/feedback tokens, masks, sampler seeds/parameters, penalty tensors, host page shadows, host sampling values, host RNGs, seed-manager state, penalty prompt history, and logprob metadata. It preserves dormant sampler state during host sampling. Shared physical K/V pools remain owned by the cache; their page mappings move with requests.
- `SlotState.prepare()`: identity warmup for all registered shapes before capture. Group snapshots and packed-row index storage are allocated in construction. `apply(full_permutation)` snapshots all source slots before copying destinations. Packed tiles read all 32 source rows before writing, preserving BF16/32-bit bits through cycles. The mapping is destination-to-source, including off-batch slots. Runtime uploads change mapping contents without rebinding captured state addresses.
- `ReloadExecutor.execute(...)`: validates callback presence and mapping, requires pending outputs drained for remap/full-input/parameter/reset transitions, applies remap once, then enabled full-input/page-only/parameter/reset callbacks, then one forward. Page-only refresh does not force a drain. A failure after mutation poisons both helpers; recovery must reconstruct authoritative state rather than retry the remap.
- `DecodeOutputPool`: allocates a bounded ring of independent token and vocabulary-sharded logits snapshots before capture. `reserve` precedes forward; `publish` queues a same-CQ snapshot before a future replay can overwrite output. `read` retains a host transfer and covering event; `process` waits and creates independent writable CPU output before releasing the lease. Readback never samples or advances positions. `discard` is an explicit exceptional drain, including partially queued copy/read failures.

The custom row kernel uses the existing generic-op descriptor builder in `slot_state.py`; its empty compute kernel already includes `api/compute/common.h`. It supports interleaved DRAM vectors of 32 elements and tiles with exactly 32 penultimate rows, with singleton outer dimensions. The selected mesh is tensor parallel only. Unsupported layouts/dtypes fail during registration. Grammar state currently fails registration explicitly; it needs its own prepared row-major row remapper before this helper can support it.

## Required generator integration

1. After all persistent sampler/cache/input buffers exist, construct `self.slot_state = SlotState.from_generator(self)`, `self.output_pool = DecodeOutputPool(self.mesh, token_template=self.tokens, logits_template=self.sampler_logits, vocab_size=self.model.vocab_size, capacity=self.max_batch_size, depth=2)`, and `self.reload_executor = ReloadExecutor(self.slot_state, require_drained=self.output_pool.require_drained)`. Include all group snapshots and both output rings in the persistent allocation census. `SlotState` holds actual device tensor references: registrations must be rebuilt before capture if any owner replaces storage.
2. During global preparation, before **any** model or sampling trace capture, call `self.slot_state.prepare()` and `self.output_pool.prepare(token_template=self.tokens, logits_template=self.sampler_logits)`. Warm any additional parameter/history-reset operation before capture too. Merely registering these helpers without warmup is insufficient.
3. Add keyword-only `reload_inputs=True`, `reload_page_table=False`, `reload_sampling_params=False`, `reset_sampling_state=False`, `slot_remap=None`, and `read_from_device=True`. Validate commands with `ReloadCommands` and reject legacy command keys. Do not silently combine `refresh_inputs` with the new contract: retain it in a distinct compatibility wrapper or reject conflicting inputs. Do not set the negotiation/capability markers until validated.
4. Build and validate authoritative input/activity updates **only inside the enabled full-input branch**. In the resident branch, use the already committed `active_slots` and device positions. Current `decode_forward` computes active rows from `start_pos` even when `refresh_inputs=False`; that code must move into the full-input branch. Do not even derive the slot count from stale `start_pos` when resident. Explicit row/layout metadata or resident ownership determines output rows. A page-only callback invokes `_bind_pages` and touches no token/activity/position/RoPE state; unchanged mappings remain no-op through `_host_pages`.
5. Keep requested seed identity (including `None`) in `sampling_values['seed']` or an equivalently registered host list. This is distinct from mutable device seed state and transformed `seed_values`. A parameter callback updates requested seed metadata and calls `configure_sampling(..., reset_seed_state=False)`. This must preserve every live device seed and host RNG stream. A reset callback uses current requested seed metadata and resets selected streams unconditionally, including `None`; it must work when parameter reload is false. Reject unsupported fields before any mutation instead of silently dropping them. If penalty support is enabled, explicitly rebuild commanded prompt/output history using stable buffers even when its current mode is dormant. Current `configure_sampling` only implements temperature/top-k/top-p/seed, not the full plugin penalty/logprob feature set.
6. Invoke `reload_executor.execute(commands, slot_remap=slot_remap, reload_forward=..., reload_pages=..., reload_parameters=..., reset_sampling=..., forward=submit)`. The callbacks update existing allocations. Do **not** also invoke common `sampler.apply_slot_remap`: that helper invalidates parameters and would duplicate ownership movement. Likewise, a later bookkeeping-only `note_state_slots_moved` must not reapply the physical permutation.
7. Inside `submit`, reserve the result lease before replay, choose the prepared model trace from committed activity, issue the model trace once, and issue the prepared sampling trace once in device-sampling mode. Publish `self.tokens` for token mode or `self.sampler_logits` for host-logit mode. Output leases must not be reserved before the executor's transition drain check, because they would make the current submission appear to be an older outstanding output. Transition commands guarantee an empty ring; a steady submission must check/reserve available ring space before issuing replay. Validate all shapes/parameters before this point. On an actual queued mutation failure the executor poisons state; drain and reconstruct before retry.
8. Host compatibility returns unsampled logits from submission; CPU sampling belongs to the explicit compatibility caller. Device mode keeps model → sampler → token feedback on device and traced. `return_logits=True` currently calls `host_logits` immediately; replace that route with output ownership when `read_from_device=False`. Returning live `self.tokens` directly is unsafe across overlapping submissions.
9. `read_decode_output(handle, async_read=True, sample_rows=None)` delegates to `output_pool.read`. `process_decode_output_host(handle, is_tokens=..., sample_rows=None)` delegates to `.process`. The submitted physical row order is immutable. For normal full-slot fallback, reserve the full configured slot range, including gaps; do not compact solely from active slots. For a compact-host call, reserve the supplied unsorted `sample_rows` order. The pool requires later row lists to match. It returns int64 `[B,1]` tokens or FP32 `[B,1,V]` logits with real vocabulary and independent writable storage. It currently reads the full device buffer and compacts on host, so this does **not** establish selective device readback.
10. Require `output_pool.require_drained()` before reset, prefill that changes live state, cache rebinding, sampler mode changes, and release. Explicit exceptional teardown can `.discard(handle)` and then release traces/resources. A poisoned reload executor is not cleared by ordinary `reset()` without reconstructing and verifying all ownership state. Hold the helper and all buffers through trace release and outstanding read completion.

The output pool assumes CQ0 for both compute/sampling/copy and read event ordering, matching this generator. A future multi-CQ implementation needs explicit inter-queue events before snapshot and transfer. The pool does not carry logprob payloads or speculative verification outputs. It must not silently discard such outputs if those features are later enabled. The executor intentionally does not infer RNG counters from host positions; a position-based seed scheme must align counters only on commanded reset using authoritative inputs.

## Required device validation before capability claims

- Exact row permutations `[1,0]`, a cycle, and a permutation moving off-batch slots; compare recurrent/conv/pages and all registered scalar/packed metadata bitwise. Repeat in host mode with a dormant sampler. Include BF16 vectors, UINT32 vectors, BF16 tiles, and INT32 tiles with widths spanning multiple tiles. Identity/remap changes must create no new program entries after preparation.
- Resident decode must tolerate deliberately stale or sentinel host token/position arguments. Verify unchanged and changed page tables without token/position/activity reload. Verify exactly one position/seed advance and traced token feedback.
- Parameter-only reload preserves live seeded/unseeded streams. State reset without parameter reload uses remembered requested seed; `None` always initializes fresh seed state. Slot moves preserve each request's stream and leave padded/off-batch owners intact.
- Submit/read A, submit/read B before consuming A; replay again only into a free lease. Verify each output matches its submission, output CPU storage remains writable and independent, and a full ring rejects before forward. Test unsorted rows/gaps, changed-row rejection, double consume/cancel, nonblocking read events, and exceptional read/copy teardown.
- Full-input/remap/reset transitions reject outstanding leases; page-only update can queue while old observational readback is pending. Verify no late persistent allocation after capture, and count snapshot storage in the DRAM census.

## Implemented command entry points and prefill sampling staging

`tt/serving.py::decode_with_commands` now implements the integration described above. It accepts all four explicit commands, full slot remaps, shared or per-layer pages, explicit slots, cache ownership, sampling parameters, histories, readback selection and trace selection. It uses existing model/sampling traces only. Resident calls never inspect host tokens or positions; sparse inactive rows retain RNG/parameter/history state. Parameter-only reload remembers requested seeds without resetting live streams. A subsequent state reset can use those remembered seeds independently. Per-layer tables override group-zero tables; their submitted row-order prefix is used when padded to capacity. Short tables are padded with the final owned physical page, preserving decoder-safe causal padding. Active device penalties/logprobs and tracing-disabled decode are rejected before mutation; explicit host-logit mode performs no device sampling.

`PrefillLogitRows` adds one persistent scalar metadata buffer and an exact BF16 tile-row transport. Construct it in generator initialization and warm it with `source=zero_logits_row, destination=sampler_logits` before any capture. It canonicalizes singleton source rank to `[1,1,1,Vshard]` and writes only the selected destination row in the fixed 32-row sampler buffer. A runtime row index avoids request-specific programs. `tests/run_serving_state_probe.py` now checks this transport on all four devices before and after retained trace capture, in addition to the earlier remap/output tests. The earlier hardware result at `serving_state_probe/result.json` passed remap/async-output tests after correcting unsupported TT Shape slicing; it predates this new row transport, which still needs a rerun.

`tt/serving.py::prefill_with_sampling` accepts an explicit `low_level` callable for the existing unsampled prefill implementation. It validates requests before mutation, invokes that callable with `device_output=True`, stages each final logical logit row, and deallocates all temporary prefill logits before sampling-trace replay. The existing sampler advances seeds and writes persistent tokens; it does not advance prompt-end positions. A token or full-logit output is snapshotted into the same owned output pool. `sampling_params=None` selects host logits. Sampling parameters select the existing traced common sampler. The helper rejects prefill graph tracing because no prefill trace is implemented; decode-only tracing still uses a traced sampling step. Keep the legacy all-logits and explicit `device_output` low-level routes separate from this public serving path, and reject unknown public request keywords.
