# Inter-layer residual and state contract

The selected MultichipDecoder is TP4 attention plus hybrid TP4 indexed/EP4 grouped routed MoE on the 1x4 Blackhole mesh. A replicated residual is a distribution of the hidden activation, not replicated model execution: each rank owns attention projections and expert shards, and all four participate in each layer.

The public per-request carrier is BF16 TILE [1,1,2048], replicated across ranks. `decode_batch` accepts and returns a tuple of these carriers in request order. B1 retains the inherited L1 width-sharded carrier through norms/adds. B>1 returns DRAM interleaved singleton carriers after one whole-batch untilize and per-row slice/tilize. A next layer consumes those tensors directly; callers must not insert gather, all-reduce, reshard or host conversion between layers. The mixed-stack validation is the executable integration example. Keeping the tuple interface charges all output splitting to the measured decoder.

Within the layer, full-attention B>1 packs the request rows for RMSNorm/QKVG and the local output matmul. Paged SDPA and cache updates retain per-request position tensors and page tables. Linear attention retains separate FP32 recurrent state per request and combines its two same-input ordered projections. Attention partials are batched before a single direct all-reduce; linear partials remain FP32 until reduction. The local residual add follows reduction. Routed and shared expert contributions combine before the MoE output collective. These are intra-layer reductions; no external inter-layer collective is required.

BF16/FP32 direct all-reduce scratch and semaphores belong to the shared CollectiveWorkspace. Prepare all needed MoE capacities and position/state tensors before capture. Workspace-backed outputs are transient and serially consumed before the next operation may overwrite them. Do not overlap independent traces that alias that workspace. Retain weights, workspace, cache pages and capture-owned backing allocations until every referring trace is released. Logical rows, sequence lengths and positions are public; tile padding is owned by the implementation and must not become an API precondition.

KV remains BF16 TILE, page size32, duplicated head ownership[0,0,1,1]. Each request owns disjoint physical pages; padded page-table aliases are causal read-only padding. Linear convolution and recurrent layouts are unchanged. The supported pool remains262144 aggregate cached tokens and up to32 recurrent request slots, not32 simultaneous262K requests. Context smoke and capacity details are recorded in ../context_contract.json.

Alternative hidden-sharded residual families were consumed by the next norm without an immediate restore at the boundary. ## Selected singleton helpers and lifetime

The full-attention singleton input norm uses the same 32-core L1 width shards as the residual carrier (per-core physical shape32×64). Linear singleton norms preserve the input carrier after the exact compensated epilogue. The 32-worker local SiLU returns 32×32 width shards to its in-layer output projection; this is not an inter-layer carrier change. The FP32 router selector keeps two setup-owned DRAM outputs per decoder. Consume both before another selector call; keep their backing allocations alive until all referring traces are released. Selector outputs are independent across decoder instances, while the shared CCL workspace remains serial.
