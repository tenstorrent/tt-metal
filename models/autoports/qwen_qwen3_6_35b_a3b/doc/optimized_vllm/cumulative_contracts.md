## State/row cumulative source audit and remaining scope

The row helper reviewed here has SHA256 `434a7c2a3596a40bb037b46a768150f3a7c2f98be8ce143fc07db2d03699f564`, matching the v4 hardware artifact. `hidden_row_mask_candidate.patch` now embeds that exact helper, including canonicalization and the row-count cache key. Reverse-application validation against current production sources passes; no production source was changed by this review.

**Row transport and cache identity.** The raw-copy candidate was rejected: the old split/tilize boundary maps all exponent-zero values to positive zero and strips NaN mantissas to signed infinity. The exhaustive rerun covers every actual uploaded BF16 pattern on all four chips, four mask cases, and complete physical padding. Normal finite bits and existing infinities remain unchanged. The v3 microgate then exposed a separate generic-op cache collision: B2/B4/B32 share accessor geometry but have per-core argument counts10/14/70. `compute_program_descriptor_hash` in `ttnn/cpp/ttnn/operations/generic/device/generic_op_device_operation.cpp` hashes the outer runtime-argument container size and compile-time args, not each core's argument-vector length. Appending `rows` after the accessor descriptors separates these signatures without shifting accessor offsets. Core ranges and CB geometry remain in the key; page count, addresses and fixed slot mapping remain runtime args of unchanged arity within a bucket.

The v4 micro uses B2/B4/B32, W2048 plus W64 reversed/high-slot variants, source changes, activity changes and unchanged repeats. It preserves previously read outputs across intervening traces, checks source preservation, verifies independent row storage and every padded word, and rejects the deliberate unsafe-allocation positive control. Tracking and program-cache checks stay enabled; no acknowledgments are used. The 12 traces are retained throughout 84 nonblocking replays and released only during teardown; the mesh closes. This establishes the helper microgate, not async overlap, model quality or serving speed. Final destinations are prepared before capture in this probe; full-model graph-construction lifetimes still need their own gates.

**State commit and numerical order.** `QwenModel` passes its default-off `fuse_recurrent_state_commit` flag to every decoder. The linear-attention branch selects direct conditional commit only when `StateSlabRecurrence.supports_native` accepts the exact q/k/v/beta/decay/state layouts and a persistent INT32 ROW_MAJOR DRAM activity scalar with a DRAM output state. The writer reads activity on device, predicates only the four state writes, unconditionally drains all four state CB entries, always publishes attention output and retains NoC completion barriers. The compute sequence, rounded/unrounded signature and Q/K layout conversion are unchanged. Each worker reads/writes its own head/column slab, so in-place output does not create a cross-worker state dependency. Conditional mode changes writer accessor args, defines and scratch-CB schema, preventing the analogous conditional/unconditional runtime-arity collision.

There is an intentional correctness fallback if native state-slab guards fail: the previous recurrence/staging/conditional-copy path remains. It has no new host readback or dtype coercion, but it would remove the intended traffic saving. The reduced tests validate selected layers0/3; they do not establish that every full40 layer always selects direct commit. The selected generator constructs the required INT32 activity scalars and updates them together with its U32 activity vector only when the authoritative slot set changes. Unchanged slot sets reuse both representations.

**Model boundary and dispatch scope.** Row fusion is default-off and selects only masked decode with more than one slot plus the persistent activity vector. `decode_batch` rejects an unsupported bucket or missing slot mapping; helper dtype/layout/geometry checks fail rather than silently converting. Initial embedding masking, all grouped residual/MoE arithmetic, terminal and sampling remain on their existing paths. Post-layer scalar-mask copies are omitted only when the decoder has returned fused masked rows. B1, unmasked decode and prefill retain the old path. No host conversion, synchronization or eager fallback was found in either fused path; device NoC barriers and the processor-store fence are required kernel completion, not host-side readback. The selected QwenModel decoder uses `split_rows_once=True`; equivalence to an externally altered `split_rows_once=False` decoder is outside this candidate's measured scope and is not silently claimed.
