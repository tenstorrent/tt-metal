## Candidate: consume native Q/K rows in the state-slab reader

`tt/mesh_state_slab_recurrence.py::supports_native/from_native` currently accepts FP32 TILE Q and K of logical shape `[1,1,4,128]`, padded `[1,1,32,128]`, then executes **two `ttnn.permute(...,(0,2,3,1))` calls** and reshapes to `[1,4,1,128,1]`. These change row vectors into physically padded column tiles. The existing reader then fetches four complete4096-byte tiles of each Q/K for every worker. Only column0 is consumed: key enters `sfpu_mul_bcast_col` and `broadcast_column_bits`; query is scaled with the existing unary operation then enters `sfpu_mul_bcast_col`.

A default-off reader variant can accept the original four-tile Q/K tensors and reconstruct exactly those consumed column0 values in the same CB1/CB2 slots. Keep all state/value/beta/decay reads, compute source, rounding, CB publication/consumption, conditional writer, completion barriers and output geometry unchanged. Initially select it only inside the already-authoritative solo0 linear-attention signature; ordinary B2/B4/B32 and all other owners retain the original path. No new host-per-token work or source-input refresh is needed. Different reader/layout semantics must participate in program-cache identity, as the earlier row-helper collision demonstrated.

Exact source mapping, with FP32 words and conventional16×16 tile faces:

- A worker owns value head `h=0..7` and output column tile `c=0..3`; its Q/K head is `j=h//2`.
- For input width tile `t=0..3`, source page is `t`. Fetch two aligned64-byte segments at byte offsets `64*j` and `1024+64*j`; together these hold the32 elements of that Q/K head for this width tile.
- Write element `r=0..31` into destination CB page `t`, FP32 word offset `(r//16)*512 + (r%16)*16`, i.e. column0 of each tile row. The logical old permuted page index is `j*4+t`.
- Preserve source bits or explicitly reproduce any **observed** old permute/packing canonicalization. The prior BF16 row bug forbids assuming all transport preserves signed-zero/subnormal/NaN payloads. Initialize unused CB lanes deterministically in the first candidate; only relax that cost with consumed-lane proof and poisoned-padding tests.

The source proves removal of60 Q/K permute API calls per token across30 linear layers, not a count of underlying native kernels. Existing Q/K reader payload is `32 workers × 2 tensors × 4 tiles × 4096 = 1,048,576 bytes/layer`. ## Secondary structural opportunities, with lower confidence

1. **Read the packed3136-wide linear projection directly.** `_linear_attention` slices `attention_combined` into1600 state columns and1536 output columns, constructs QKV by copying output columns0..511 then state columns0..1535, and extracts a/b/z. A model-owned convolution reader could map its64 QKV tiles directly: destination tiles0..15 read combined tiles50..65; destination16..63 read combined0..47. That removes QKV materialization while leaving convolution compute/state updates identical. Further decay/z-reader offsets could remove more slices (a1536..1543, b1568..1575, z2112..3135), but are separate changes with padding/canonicalization gates. Do not quietly replace sigmoid or lookup arithmetic. This removes small repeated transport; no source evidence makes it a floor-sized win.
2. **Norm-tail/local-SiLU transport fusion.** After recurrence, the current path narrows output to BF16, widens, squares/reduces, pads core/sums to32 rows in `TP4WeightedNormTail`, then applies the existing exact norm tail and LUT SiLU reader. Combining only a proven transport boundary could remove pads/intermediates. Fusing reductions, RMSNorm, L2, or native unary kernels requires reproducing exact intermediate rounding and reduction order; mathematical equivalence is insufficient. Existing active-row norm/scan/recurrence kernels already include prior exact fusions.
3. **Once-per-token embedding/terminal work.** Solo0 can avoid slot1's dead embedding/all-gather only with a correctly typed immutable residual-zero tensor and freshly validated collective sequencing. Head output could bind/stage directly into persistent sampler logits, avoiding the extra pad/copy. Both are once/token; B2 and B1 head each already occupy one physical row tile. The retained split device sampler must stay intact; dormant top-k/seed owners still govern the native32/64 signature. No evidence identifies sampling as the remaining dominant cost.

The B2 full-attention input projection, post-attention normalization/router/shared branch, residual additions and terminal norm/head are not independent dead row1 operations. Changing their logical shape can change the numerical implementation. The already-kept dead singleton norm was exceptional. Likewise, replacing ordered linear projections with conventional matmul, reassociating Q/K L2 or recurrence, or substituting indexed singleton experts does not meet the exact-family contract.
