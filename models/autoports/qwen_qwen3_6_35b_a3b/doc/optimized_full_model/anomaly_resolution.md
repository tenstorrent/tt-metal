# Optimization experiment anomaly resolution

This ledger records the explicit persistent sampler experiment; its failures do not describe the selected production split sampler. Decoder persistent CCL scratch remains enabled, while **explicit sampler AG output buffers remain disabled**. No failed experimental result is counted as a passing final validation gate.

| Observation | Evidence | Diagnosis and disposition |
|---|---|---|
| First persistent sampler run stops at the helper's axis assertion before native dispatch | [watched v1 log](logs/persistent_sampler_l1_watched.log) | Shared sampler returns `cluster_axis=None` for mesh `(1,4)`; production CCL resolves that to physical axis 1. Experimental helper repaired to accept equivalent None/1, validate exact mesh, normalize valid negative dimensions, and expose argument values in diagnostics. Rerun reaches hardware |
| Greedy replay produces token 127615 for every row instead of the varying baseline output | [watched v2 log](logs/persistent_sampler_l1_watched_v2.log) | `127615 = 65535 + 62080` implicates the poisoned UINT16 index plus a vocabulary-shard offset. Added raw transfer and eager/single-replay intermediate gates before queued stress; no production workaround was applied |
| Raw eager BF16 gather leaves remote data unchanged on every rank | [watched v3 log](logs/persistent_sampler_l1_watched_v3.log), [all-rank diagnostics and source hashes](persistent_sampler_l1_watched_v3.diagnostics.json) | Each local 32-column tile is correct; remote 96 columns remain nonfinite poison, exactly 3072/4096 mismatches per rank. Source proves one 2048-byte page remains in an unflushed 4096-byte scatter packet. Native local writes and final ready signaling still execute. This isolates a transfer defect before sampling or trace capture. **Candidate rejected; selected sampler unchanged** |

See [exact native restriction, repro and alternatives](sampler_persistent_broadcast_rejection.md) and [ownership/barrier audit](sampler_persistent_audit.md). The narrow one-tile C++ packet specialization is a proposal only; no native source change or rebuild was made. There is no per-operation packet-size configuration. Global 2048-byte payload is unsuitable for the selected FP32 collective pages; padding/compaction is legal at one link but untried and has no measured benefit. These are explicit handoff alternatives, not evidence that sampler persistent outputs were enabled.
