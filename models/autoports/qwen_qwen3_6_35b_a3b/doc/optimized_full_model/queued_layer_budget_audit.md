# Queued representative-layer budget

`run_queued_layer_budget.py` is a measurement harness outside the frozen production/tests tree. The implementing agent ran CPU checks only. Parent-owned hardware must establish compilation, exactness and latency.

The earlier FUNCTIONAL latencies include a blocking replay fence on every token. Their weighted sum (21.2976 ms) exceeds the queued full-model measurement (20.9426 ms including terminal work), so that sum is not a valid strict lower bound. This harness removes the fencing mismatch: it submits nonblocking CQ0 trace replays and synchronizes only at each sample boundary. No host tensor operation, input upload, token readback or per-token synchronization occurs inside the measured loop. Runtime `device_only` guards remain active. The result is an engineering budget for the stated workload, not a mathematical lower bound on every full-model request.

The workload is one optimized production TP4 layer, batch1, actual checkpoint weights, seed42 BF16 activations, prefill128 and a fixed resident decode activation/position128. Prefill inputs stay interleaved DRAM. Decode input is converted once before eager/capture work into the retained inter-layer carrier: BF16 TILE L1 WIDTH_SHARDED,8x4cores,32x64shards in row-major order (`dec.direct_ar_memory`). Eager and capture output metadata must match this input carrier exactly; JSON records both geometries. No per-layer DRAM-entry reshaping is charged. It matches the existing functional fixture's first decode input. State mutates on every replay: linear recurrent state advances under that fixed input, while full attention repeatedly writes KV position128. Positions, RoPE and page tables remain resident and unchanged. Cache context defaults4096. The probe is neither autoregressive generation nor an accuracy test.

Before capture, restoration and all eager output/state readback layouts are warmed. Four eager steps establish an independent exact evolving-state oracle. Two reset trace streams must match every output and mutable state byte on all four ranks. Eight warm replays precede timing. Each timing sample restores the same post-prefill state, completes restoration, then queues200 replays followed by one completion fence. Five sample latencies are recorded; state/output finiteness checks occur after timing. No output copy is added inside the trace. Program-cache count must remain stable through warmup and timing.

The JSON records command, input hashes, checkpoint revision/index hash, all production Python hashes, relevant native CCL source hashes and loaded native binary hashes. It contains exact comparison results, per-sample latency and the representative contribution (`30*layer0` or `10*layer3`); CSV preserves individual measurements. Both runs must use identical options before adding their representative contributions. That weighted budget excludes embedding, terminal norm/head/logits/sampling, position advance and generator orchestration. Isolated L1 pressure, fixed router/input choices, context128 and variation across actual layers remain limitations. Native full-model profiling and naturally changing full-model inputs provide separate evidence.

The available natural activation artifacts have32-token prompts, not128. The harness deliberately does not relabel repeats or mixed natural/synthetic state as a natural128-token sequence.

Watcher, device profiler, TTNN op profiler and profiler trace tracking must be unset. The script rejects diagnostic instrumentation rather than reporting polluted clean timing. External process timeout and serial device ownership remain the parent's responsibility. `queued_layer_budget_cpu_l0.json` and `queued_layer_budget_hooks.log` establish only CPU fixture/source checks, not hardware acceptance.

## Retained residual carrier source check

`MultichipDecoder` constructs `direct_ar_memory` with32x64shards on an8x4row-major grid (`tt/multichip_decoder.py:1102-1108`). Its selected `_reduce` returns BF16 in that memory configuration, reshaped to logical `[1,1,2048]` (`:1281-1318`). Both residual additions return their default memory configuration (`:1570-1611`). Native binary dispatch chooses the existing sharded operand when the other operand is interleaved DRAM, then retains the sharded configuration on following additions (`ttnn/cpp/ttnn/operations/eltwise/binary_ng/device/binary_ng_device_operation.cpp:688-718`). Thus subsequent B1 layers retain that L1 carrier; the old DRAM input probe would have charged an entry conversion not present at each stacked boundary. The very first layer after embedding may still pay an initial transition; a weighted steady-carrier budget does not separately model that first-layer boundary. Mesh replication of residual values is unchanged; WIDTH_SHARDED here describes each chip's local storage.

The probe asserts input carrier buffer/layout/shard shape/orientation/grid and logical/padded shape, and verifies exact eager/capture output memory equality. These are source-supported assertions awaiting parent-owned hardware. The default allocated context remains4096; the parent may use `--context1024` to match the full-model performance run without changing the fixed attended position128.
