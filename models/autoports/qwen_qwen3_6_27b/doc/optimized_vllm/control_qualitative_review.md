# Generator control qualitative review

This is a direct inspection of all 12 current TT generator outputs and their 12 matched HF controls: six prompts, greedy and sampled, seed 0 only. It is **not a population quality verdict or final serving acceptance**. No generation, server request, model import, or device operation was performed for this audit.

The TT artifact is [qualitative_tt_control.json](qualitative_tt_control.json); the reused HF artifact is [hf.json](../../readiness_vllm/qualitative_controls/hf.json). The recorded TT command in [diagnostic_commands.json](diagnostic_commands.json) uses the standalone generator with a 256-token output cap and the full 262144-token context allocation. The HF control is reused rather than regenerated.

The matching metadata was checked directly: `Qwen/Qwen3.6-27B`, revision `8f33b98937c6031bb49e713dee3e8e185aafd26f`, `Qwen2Tokenizer`, chat template present, `apply_chat_template(add_generation_prompt=True)`, thinking off, the installed shared `vllm_prompts.txt` suite, and a 256-token cap. Sampled settings are temperature 0.7, top-p 0.9, top-k 20. Each matched row has identical prompt ID, source prompt, rendered prompt, prompt token IDs, seed and sampled flag. Greedy generation is explicitly nonsampled in the collector. The rendered assistant prefix contains an empty thinking block; output text is not being judged from an unformatted raw completion request.

Following [qualitative-check](../../../../../../codex_home/plugins/cache/tenstorrent-skills/tt-model-bringup/0.1.24/skills/qualitative-check/SKILL.md), the observations below describe these individual samples. A content-based claim that TT is worse than HF requires at least 10 matched samples per side with blinded scoring under the predetermined rule. This audit does not provide that experiment or waive it.

The six capped rows on each side are prompts 1–3 in both modes. Each has exactly 256 output tokens and no terminal chat EOS in its text. This explains their visible truncation without requiring greedy EOS completion as a gate. The other six rows on each side end with token 248046 and a displayed `<|im_end|>`. The collector [run_suite.py](../full_model/qualitative/run_suite.py) saves `tokenizer.decode(result)` without stripping special tokens; HF displays the same terminal marker. These final markers are explained raw-artifact serialization, not a demonstrated serving API leakage defect. No interior role delimiters, thinking-text leakage, doubled-token pattern, single-token collapse, gibberish, or unexplained language switching were visible in these 12 TT texts.

The TT story's greedy pronoun inconsistency and the sampled haiku's awkward opening remain recorded sample-level content observations. The HF story does not reproduce that pronoun change, so this report does not label it an HF-reproduced limitation. If either observation is promoted into a quality gate or a TT-versus-HF degradation claim, the required matched, blinded multi-seed experiment remains outstanding. These observations alone do not identify a trace, cache, sampler, or precision root cause.

As a historical comparison only, the six fresh TT greedy strings match all six strings in [the existing Stage 9 served outputs](../../readiness_vllm/vllm_qualitative_outputs.json) exactly after removing only TT's terminal `<|im_end|>` where present. That comparison also preserves the greedy story's pronoun inconsistency. The historical file contains served text rather than output token IDs, so this is text equality, not claimed token equality. It is evidence that these greedy outputs were already present before the current serving optimization; it does not validate the final optimized server, its sampled outputs, or its mixed-request behavior.

Final optimized-serving sampling/qualitative runs and comparison against this same-code generator control are still required. This report supplies a prompt-correct control review and explicit anomalies; it does not complete those serving gates or establish long-context generation quality merely from the allocated context size.
