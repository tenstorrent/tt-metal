# Prefill-only full-attention packing and isolated norm probe

Source-only artifacts; no device execution or main decoder edit.

## Prefill norm probe

`tests/run_prefill_norm_probe.py` imports a candidate by path and calls `--function` (default `prefill_hidden_rmsnorm_sfpu`). It tests B1/S1,17,33,65; B3/S33; B32/S33,128, with both real pinned input/post-attention folded FP32 gamma tensors. Each CPU reference receives exactly the same BF16 random activation as TT and performs FP32 normalization/affine followed by BF16 cast. It checks repeated execution with a supplied stable output buffer. This is a diagnostic, not latency evidence or a full-model test.

```bash
python -m models.autoports.qwen_qwen3_6_27b.tests.run_prefill_norm_probe \
  --candidate models/autoports/qwen_qwen3_6_27b/doc/optimized_decoder/candidates/prefill64.py \
  --output models/autoports/qwen_qwen3_6_27b/doc/optimized_decoder/prefill64_norm_probe.json
```

To test the standalone helper directly, use `--candidate .../candidates/hidden_rmsnorm_prefill.py --function hidden_rmsnorm_sfpu`. Parent must use the existing serial device wrapper. The runner writes metrics before its unchanged isolated-norm relative-RMS `<1e-4` gate, PCC `.995` gate, and exact-repeat check. It does not relax any decoder gate.

## Frozen packing candidate

`candidates/full_prefill_pack.py` snapshots `integrated57.py`, generated by `candidates/make_full_prefill_pack.py`. Exact source hashes are in `full_prefill_pack_generation.json`. Select it through `QWEN_OPT_CANDIDATE=full_prefill_pack`, using the same integrated57 full-attention policy plus `"full_pack_all":"prefill"`.

- Setup constructs the existing packed-QKVG matrix but retains separate packed-QKV and gate tensors for decode.
- `_qkv` receives an explicit `prefill` keyword. `_attention_prefill` sets it true, including valid S1 prefill. Neither logical length nor start-position heuristics infer phase.
- Legacy decode keeps the default `prefill=False`. Compact decode only selects packed-QKVG when policy is literally `True`, preserving its existing separate route in `"prefill"` mode.
- `False` and `True` retain the original separate/all-phase behavior. Gamma, q/k norms, scalar gate order, rotary, paged cache operations, SDPA, and all matmul configs remain unchanged.
- This snapshot deliberately does not include the independently generated prefill64 changes, allowing a controlled packing experiment.

The QKVG packing order is Q6144, K1024, V1024, gate6144. All boundaries align to32 and therefore to the16-output-channel BFP8 exponent groups. Packing does not introduce cross-projection exponent sharing at those boundaries. Device correctness and faster prefill versus the tuned legal separate candidate remain required; no speedup is claimed.

## Exact incremental storage

The decoder retains the baseline separate weights and adds K5120×N14336. BFP8 tile payload is1088 bytes for32×32 values, including block exponents. The source Blackhole descriptor has8 DRAM channels. For the existing C8/R2 default or C32/R4 geometry, the factory's alignment is16 or32 output tiles respectively;448 output tiles is divisible by both. No extra width padding is introduced:

```text
tiles = (5120/32) * (14336/32) = 71,680
additional persistent bytes = 71,680 * 1,088 = 77,987,840
                           = 74.375 MiB total
                           = 9,748,480 bytes per DRAM bank (8 banks)
```

These numbers exclude transient setup duplication, program buffers, and allocator bookkeeping. If runtime hardware harvesting or geometry changes, recompute from the actual bank count: `A=lcm(banks*readers,cores)`, `physical_N=ceil((14336/32)/A)*A*32`, bytes=`(5120/32)*(physical_N/32)*1088`. The helper does not change KV dtype, layout, or advertised context; parent must check peak DRAM/context headroom before retention. No capability reduction is justified without physical-capacity evidence.

CPU validation in `full_prefill_pack_cpu_checks.json`: all six mode/phase combinations route correctly; legacy decode AST is unchanged; compact decode AST is unchanged except its phase-aware policy condition. Syntax compilation passed for the generated candidate, generator, and norm probe. No TTNN module was imported during child validation.
