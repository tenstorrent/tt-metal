# Integrated candidate162

`candidates/integrated162.py` is an immutable cumulative candidate generated by `make_integrated162.py`. It starts from `integrated_fused_persistence134.py` and integrates only the requested independently measured changes. No main source or hardware was touched during this integration.

| Component | Exact source | Integration |
|---|---|---|
| Fused BF16 recurrent persistence | integrated_fused_persistence134.py | Entire recurrence and `_gdn_compact` retained unchanged |
| Narrow BFP8 QKV/B_A residual and one-op combine | narrow_gdn_fused_combine.py (158) | Setup, `_linear`, combine method, both corrected-prefill helpers and exact generic-op helper |
| Exact BF16 nonaligned prefill unflatten | prefill_unflatten_v2.py (146) | Final packed-input result only; exact direct-segment helper |
| Full-attention normalized-activation L1 handoff | norm_l1_handoff_v3_on134.py (153) | Exact `_norm`, `_finish`, decode/prefill private-activation releases |
| Short-capacity decode SDPA | short_capacity_sdpa156.py | Exact classical/compact decode methods and capacity selector; selected K64 |

The sole overlapping edit is `corrected_projection_chunk_add_prefill`. It retains narrow-candidate per-chunk FP32 addition/BF16 packing, then applies the exact unflatten-v2 guard only at the final packed BF16 result. The flat-prefill helper is otherwise exact to narrow158. No recurrence method was transplanted from any non-persistence base.

Explicit added defaults are GDN `zero_z_correction=True`, `narrow_gdn_correction=True`, `narrow_gdn_fused_combine=True`, `prefill_unflatten_packed=True`, `narrow_gdn_verify_setup=False`, and both optional worker capsNone. Full-attention adds `norm_projection_l1=True` and `short_capacity_decode_k_chunk=64`. All other defaults are identical to persistence134, including selected compute fidelity, weights, geometry, cache dtype and recurrence flags. Each new option remains independently overridable.

`candidates/integrated162.generation.json` records source/generator/output SHA256 hashes, exact method origins, flags, and overlap resolution. `tests/test_integrated162_source.py` passes: every recurrence definition/kernel string and `_gdn_compact` is exact to persistence134; transplanted methods/helpers are exact to their requested source; the combined helper reduces exactly to narrow158 when its unflatten guard is removed; default differences are precisely the listed flags. It executes90 pure capacity/phase dispatch cases and reruns36 narrow-address and1024 unflatten-alignment cases without TTNN import. Python compilation passes. Results: `integrated162_cpu_checks.json`.

Hardware cumulative signoff remains pending: prefill/decode PCC/state, nonaligned prefixes, long/repeated sequence, traced performance, profiler and watcher. Independent passes are not treated as proof that this cumulative candidate passes.
