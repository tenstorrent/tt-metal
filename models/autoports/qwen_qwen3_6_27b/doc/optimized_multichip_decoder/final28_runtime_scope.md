# Final default runtime audit scope

`final28_runtime_audit.json` is the CPU call-graph audit of the frozen stage5 source. It follows154 functions from prefill/decode, inherited dispatch, imported helpers, packed-projection ownership, and normalization ownership across policy branches. All48 forbidden-call/binding mutation controls pass; no unresolved violations remain. Source snapshots in final command receipts, together with the final manifest, establish helper freshness. The final audit also attaches the selected default runtime results; a static-only result is insufficient for acceptance.

Setup may load real weights with torch, upload tensors, construct cache/page metadata, and generate kernel source strings. Runtime numerical work stays on the four-device TTNN mesh. Host shape/address metadata and AST-proven literal string operations are not numerical host fallback. The audit does not infer arbitrary property descriptors or unreviewed user subclasses; certified page-table ownership and actual owner bindings were separately inspected. CPU lease positive checks use the production module, and the historical buggy deepcopy implementation is a negative control (`page_table_ownership_cpu_production.json`).

The runner's runtime sentinels reject six public host-transfer/materialization APIs during initial eager prefill, initial eager decode and decode capture. Timed prefill is outside that sentinel context and is checked for exact output/state against the guarded initial execution. This is not a claim that every possible host API is intercepted. Separate actual-HF contract tests guard supported nonaligned prefill/resume/list entrypoints. The native code and compiled binaries are recorded in every command and final inventory; the validator observes actual mapped TT shared libraries in each target process.

Strict allocation tracking uses tracking1/skip-program-cache0, requires the positive control to reject unsafe capture, and accepts no blanket allocation exemptions. Final resource and stack gates check repeated replay, independent state/CCL owners, no late program-cache growth, and direct hidden-shard boundaries. Watcher runs are separate from timing/profiling. Each process owns the full1x4 mesh serially and closes before the next begins.

The selected default keeps distributed decode norm off; its experimental helper is conservatively audited but its64-owner L1 failure is not hidden by this audit. Unselected candidate API branches and measured rejected families remain documented hand-off work, not runtime fallback.
