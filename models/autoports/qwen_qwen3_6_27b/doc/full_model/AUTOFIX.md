## B32 cached reshape mapping repair

Fresh `AUTODEBUG_b32_capacity.md` established fragmentation and proposed ownership measurements; its provisional peak-only repairs were not applied. The reduced [0,1,3] probe isolated 14,743,472,640 bytes/device released by clearing the program cache before any trace (17,247,420,928 → 2,503,948,288 bytes). Independent source/CPU investigations (`reshape_mapping_reconciliation.md` and `reshape_mapping/`) identify retained per-output-tile reshape mappings and exactly reproduce the largest size/multiplicity histogram bins. Ordinary kernel binaries do not explain the dominant growth.

The native tiled reshape factory now caches one column-zero map per tile row when input/output widths are equal and tile-aligned. Reader source page IDs add the current tile column; face offsets/lengths and writer behavior are unchanged. General width-changing/partial-width paths retain the original full map. Native factory and reader are the only production changes for this repair; full-model Python and accepted decoder remain unchanged. No cache eviction, context reduction, diagnostic head serialization, or prefill algorithm replacement.

Canonical build and both installation components passed. `reshape_mapping_device.json` passes 36 exact all-rank BF16/FP32/UINT32 cases, both directions, new input addresses/cache hits, strict traced replay, and fallback width cases. The first probe's memory assertion accidentally retained its last device-tensor readback alias; preserved `reshape_mapping_device_initial.log` shows that test-only failure. Dropping that alias correctly measures the map+program allocation: 155,648 bytes for B32/S33/W5120 versus the original mapping alone 22,282,240 bytes. No numerical failure or reset occurred. Full-repertoire all64/B32 capacity and slot acceptance now passes in `slots32_all64_pool_fixed.json`; all64 mixed lifecycle passes in `mixed_prefill_native_all64.json`. Current-native numerical, resumed-prefill, generation, performance, maximum-context and native Watcher receipts all pass; see `accuracy_native.json`, `performance_final.json`, `max_context_final.json` and `reshape_mapping_watcher_receipt.json`.
