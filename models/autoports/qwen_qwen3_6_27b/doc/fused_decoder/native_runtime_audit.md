# Native runtime audit

The Python reachable-method audit and runtime from_torch/to_torch sentinels complement native source inspection. Loading, HF references, state construction, trace-input refresh and profiler drains are outside measured windows.

- `chunk_gated_delta_rule.cpp`: all four constants (`eye`, `tril`, `ones`, `masks`) and initial state supplied explicitly. Thus build_const_tiles/build_zero_state host setup branches are unreachable. Q/K/V enter rank-3 BF16 flat form; the native reader folds L2 normalization, query scaling and head replication. Except for B1/one-token decode, the caller pads gates to 32 with neutral beta/g=0 before calling, so native `pad==0`. Native convolution Q/K/V already have this physical extent and are retained, without slice/re-padding. `output_head_major=True` selects metadata-only reshape, bypassing native ROW_MAJOR output conversion and the native non-aligned output RM fallback. The returned head-major tensor gets explicit logical/padded shape metadata; its physical row/tile ordering is unchanged.
- B1/one-token GDN calls the same native phased `chunk_gdn_prep` and `chunk_gdn_scan` primitives directly. Prep receives logical g/beta length1 and padded flat Q/K/V length32; `chunk_gdn_gate_read.hpp` zeros every gate row beyond the logical length. All constants/state are supplied; no host construction branch exists. The batch guard avoids the phased scan head/core ceiling. The public wave-capable fused op handles other shapes. State is copied into its original persistent address after scan; no pointer swap or alias assumption is used.
- KDA `qkv_causal_conv1d_silu.cpp`: input is already tiled; `tiled()` returns it unchanged. History and returned carry are ROW_MAJOR BF16; no untilize/tilize in this path. Each batch row has independent history. A single-device persistent exchange scratch and three semaphores are shared by sequential calls only. The op owns semaphore sequencing; no simultaneous forwards on the same layer/queue are permitted. All 1..512 logical-end tensors are prepared before capture. The logical end, not padded capacity, defines returned history. Shape-dependent metadata lookup is host Python arithmetic; tensor values remain on device.
- `rotary_embedding_hf.cpp` dispatches its native tiled rotate-half kernel and preserves logical shape. It rotates the first64 dimensions, then concatenates the other192. No repair slice, tilize, host tensor conversion or indexed-basis change is involved.
- `split_query_key_value_and_split_heads.cpp`: tiled packed QKV uses native nlp_create_qkv_heads and reshape views. No host tensor fallback. Both logical batch and sequence are preserved.
- `concatenate_heads.cpp`: input is DRAM interleaved, so the optional sharded-to-interleaved conversion is unreachable. Dedicated nlp_concat_heads produces tiled output.
- Full-attention uses native `paged_fused_update_cache` with equal-sized disjoint K/V core sets. Each has one height shard per request, shape[32,256], on an8x8 grid; batch32 occupies64 distinct cores. The two DRAM-to-L1 movements are required by the fused op; sharing one set would be invalid. The temporary input list is released immediately after the ordered update, before SDPA allocates its circular buffers; persistent caches remain live. Paged cache layout, ownership, key block, position tensor and BF16 dtype are unchanged.
- RMSNorm retains FP32 gamma/intermediates and HiFi4/FP32 destination accumulation. BF16-input native normalization absorbs unpack/pack casts for general shapes. B1/one-token hidden-width5120 uses native8-core width-sharded normalization: `interleaved_to_sharded(output_dtype=float32)` and `sharded_to_interleaved(output_dtype=bfloat16)` fuse the casts with required data movement. The matched unsharded control is slower; a40-core control gives no gain. These four per-layer transfers are justified by measured latency and are not redundant resharding. Dense matrices retain BF16/HiFi4/FP32 accumulation.

No functional implementation is imported by fused_decoder.py. FunctionalDecoder is loaded only by the evidence harness as an explicit numerical control. The final runtime class independently implements both layer kinds.

Profiler confirmation is recorded in the final report audit; this file alone makes no measured-op-count claim.
