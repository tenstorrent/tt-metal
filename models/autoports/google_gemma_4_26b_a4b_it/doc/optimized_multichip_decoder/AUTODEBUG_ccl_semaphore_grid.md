# AutoDebug: CCL semaphore grid misses Blackhole workers

## Finding and demonstrated correction

The decoder imported a CCL manager that allocates global semaphores only on
cores `(0,0)-(7,7)`. Native collectives select workers from the complete
11x10 Blackhole grid. Four-worker allgather and larger reduce-scatter launches
therefore use workers without allocated/initialized semaphore storage. This
is a concrete caller-owned geometry mismatch, independent of CCL pooling and
independent of a particular reduced precision.

The parent tested a model-local full-grid CCL manager with unchanged native
collective geometry. It restored exact replicas and 128 repeated/advancing
decode checks for the same-kind stack. At real 4096-token context, second-layer
prefill PCC improved from approximately 0.8965 with the old semaphore grid and
AG-worker1 workaround to 0.9997529898 with full-grid semaphores. The default RS
geometry was also exposed by the longer prefill, so fixing AG placement alone
was incomplete.

This correction does **not** establish the full stack's numerical gate:
second-layer decode minimum PCC remains 0.9866052424 under the selected reduced
policy at length 4096. The parent is separately running controlled precision
experiments. Do not attribute replica divergence to inherent quantization or
claim the final stage passes on this report's evidence.

## Evidence progression

1. `pool_shared_kinds.failure.json` and `pool_private_kinds.failure.json`
   both fail at `prefill/layer1` for layers `(0,1)` and length 33. Ranks 2/3
   differ in 2802 valid values; pooling is refuted as the cause of this symptom.
2. `pool_private_bf16_kinds.failure.json` reproduces the failure with BF16
   attention CCL (2692 differences on ranks 1/2/3). This refutes a BFP8-only
   explanation.
3. `prefill_boundaries_bf16.json` and `.tensors.pt`, generated by
   `diagnose_prefill_stack.py`, retain boundaries during prefill and read them
   only after both layer forwards complete. Pool entry counts are zero.
   Input/padding checks agree on all ranks, all added rows are zero, and the
   first divergent replicated tensor is **layer1/attention/collective_output**.
   First-layer attention and grouped-MoE collective outputs agree exactly.
4. The second attention output differs between rank 0 and ranks 1/2/3 only
   in the second tile row, logical rows 32-63. There are 15,351 differing
   values per differing rank over the full 64-row tensor. At row 32 the
   differing column spans are `[1440,1536)`, `[1728,1760)`, `[2112,2464)`.
   Later normalization spreads these errors through the valid output row.
5. Parent AG-worker1 control (`prefill_ag_workers1.json`) restores replica
   and repeated-trace equality but still fails the cumulative numerical PCC
   gate. This changes placement and avoids fabric muxes; it alone does not
   distinguish those mechanisms.
6. Parent full-grid semaphore control (`prefill_full_semaphore_grid.json`)
   restores replicas/replays with **unmodified AG geometry**, separating the
   missing-semaphore cause from a blanket multi-worker or mux prohibition.
   Layer1 prefill PCC is 0.9996850366 at length 33; decode minimum is
   0.9861042365, exactly matching the AG-worker1 workaround's reported floor.
7. `stack_full_grid_actual_context.json`, length 4096, preserves exact replicas
   and replays. Layer0 prefill/decode minimum PCC is 0.9998855247/0.9971969898;
   layer1 is 0.9997529898/0.9866052424. The old-grid AG-only workaround had a
   severe large-prefill loss, so the full grid is required for RS as well.

Hardware execution belongs to the parent. This diagnosis agent wrote bounded
probes, inspected their returned artifacts, and ran only host-side checks.

## Exact source contract

`models/demos/gpt_oss/tt/ccl.py:27-40` hard-codes `CoreCoord(8,8)` and sets
`self.ccl_cores` to that rectangle. `_init_semaphores` allocates six RS, four
AG and two barrier semaphores on that rectangle. The local `_worker_sub_device`
object is never registered/loaded on the mesh; it does not constrain native
collective worker selection.

The decoder calls native RS/AG without a constrained subdevice or core grid.
`ttnn/cpp/ttnn/operations/ccl/ccl_common.hpp:118-135` defaults worker allocation
to row-major. `ccl_common.cpp:454-535` obtains the device's worker cores and
enumerates x before advancing y. Its validation checks that selected cores
are real device workers, not that caller-provided global semaphores cover them.

The default AG factory computes two directions, one mux per direction when
workers >1, and `2 * (1 + workers)` total cores:
`all_gather_async/device/all_gather_async_default_program_factory.cpp:149-152,253-275,333-393`.
For four workers on an 11-column device, the core order is:

```text
forward mux  (0,0); workers (1,0), (2,0), (3,0), (4,0)
backward mux (5,0); workers (6,0), (7,0), (8,0), (9,0)
                                                ^      ^
                                  outside the 8x8 semaphore allocation
```

The writer and reader receive the global semaphore's common address and use
it on their own worker core. Missing allocation on `(8,0)` and `(9,0)` means
that address is not reserved and initialized there. Other model work may
leave data at that address or reuse it. Ready waits/increments/resets are
therefore applied to storage with no semaphore lifetime contract. A wait can
observe stale data or corrupt unrelated storage; the exact corruption depends
on surrounding operations and allocator history.

For the observed BF16 attention input `[1,1,64,2816]`, RS output is
`[1,1,64,704]`: 44 tiles per rank. Four AG workers receive 11 tiles each.
Worker indices 2/3 process tiles 22-43, exactly the second tile row (rows
32-63), and their backward cores `(8,0)/(9,0)` lack semaphores. This matches
the first divergent tensor's row boundary.

The dtype control also changes AG geometry. The heuristic uses output bytes
times 3/4 and chooses four workers above 256 KiB:

| Shape/dtype | Output bytes | Moved bytes/link | Default AG workers |
| --- | ---: | ---: | ---: |
| attention `[1,1,64,2816]`, BF16 | 360,448 | 270,336 | 4 |
| attention `[1,1,64,2816]`, BFP8 | 191,488 | 143,616 | 2 |
| grouped MoE `[1,2,64,2816]`, BFP8 | 382,976 | 287,232 | 4 |

Thus BFP8 attention alone staying on six cores does not make a full layer safe:
its grouped-MoE AG still selects the uncovered workers. Large RS uses the same
row-major placement, with `2*(1+workers)` cores. At four/eight workers that is
ten/eighteen cores, extending outside the imported 8x8 semaphore rectangle.
See `reduce_scatter_minimal_async/device/reduce_scatter_minimal_async_program.cpp:1136-1170`
and worker heuristics in `reduce_scatter_common/reduce_scatter_program_utils.cpp:32-96`.

## Minimal model-local repair

The parent integrated `_MeshCCLManager(CCLManager)` in
`tt/multichip_decoder.py`. Its `_init_subdevice` obtains
`mesh_device.compute_with_storage_grid_size()` and allocates the semaphore
rectangle through `(grid.x-1,grid.y-1)`, preserving `SubDeviceId(0)` and all
inherited ping-pong/initialization behavior. `from_state_dict` uses this
manager instead of changing the shared GPT-OSS helper.

Keep native worker heuristics, topology, numerical types and pooling policy
unchanged for the correction's comparison. Full-grid semaphores are needed
even when persistent decode payloads use a shared tensor pool. Semaphores
remain per-layer; the pool continues to share only role-specific tensors.

Restricting only AG to `manager.ccl_cores` is a useful diagnostic but does not
cover RS at longer contexts. Forcing worker1 likewise masks the allocation
mismatch and changes performance geometry. The model-local full-grid manager
fixes the caller contract directly.

## Native replay probe and its limits

`diagnose_prefill_ccl.py` uploads exact captured rank-local inputs for layer0
attention/MoE and layer1 attention/MoE. It uses separate per-layer managers,
native default RS/AG geometry, and two uninterrupted repetitions. It retains
the actual RS outputs, then checks AG **exactly** against their concatenation.
This oracle is independent of BF16/BFP8 reduction rounding.

`native_ccl_full_grid.json` passes all upload round-trips and all eight AG
invocations on all four ranks with program caching enabled. The parent also
ran `native_ccl_8x8.json`; it passes the isolated sequence too. Therefore the
native probe **does not independently reproduce** the original corruption.
It lacks intervening model compute and its L1 allocation/history. The original
whole-layer A/B and the concrete coverage violation establish the correction;
the isolated native control only verifies exact AG semantics in that narrower
environment. Do not report the native control as failing or use its success
to infer that unallocated semaphore storage is safe.

Runnable probe, executed by the parent:

```bash
python_env/bin/python -m models.autoports.google_gemma_4_26b_a4b_it.doc.optimized_multichip_decoder.diagnose_prefill_ccl --capture models/autoports/google_gemma_4_26b_a4b_it/doc/optimized_multichip_decoder/prefill_boundaries_bf16.json --full-semaphore-grid --output models/autoports/google_gemma_4_26b_a4b_it/doc/optimized_multichip_decoder/native_ccl_full_grid.json
```

## Durable host regression and validation

`tests/test_multichip_ccl_cpu.py` constructs the actual model-local manager
with a fake 11x10 mesh and mocks only semaphore device allocation. It verifies
all 12 allocations are initialized to zero and cover native row-major worker
placements for one, two, four and eight workers per direction, including the
previously missing x=8/9 cores. It does not open a device.

The diagnosis agent ran:

```bash
python_env/bin/python -m unittest models.autoports.google_gemma_4_26b_a4b_it.tests.test_multichip_ccl_cpu -v
```

Result: **one host regression passed**. Both standalone scripts parsed and
were formatted with Black for Python 3.10. These are Python-only changes;
no C++ build was needed for this diagnosis/probe/test work. The parent owns
required final stack accuracy, capacity, trace, watcher and performance gates.
