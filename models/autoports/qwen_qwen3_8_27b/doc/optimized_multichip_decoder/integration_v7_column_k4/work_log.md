### Temporal-window convolution adaptation

A second narrow independent source review (`temporal_conv_review.md`) established that the B1-only convolution API can process many decode users without mixing them. Pack each user's three raw history rows plus current projected QKV row in row-major layout, flatten to one sequence, internally tile-pad, and retain only each fourth output. The retained window sees exactly that user's four inputs; discarded outputs never feed future outputs. The default no-exchange op on mesh1x4 has sequence_parallel_axis0/size1. This removes repeated launches and8x padded convolution work at B8–32. Output extraction is row-major because strided tiled slicing is not legal.
