This work follows the operation-topology audit. Final B1 profiling exposed approximately2263us of hidden all-gather/reduce-scatter in the linear layer's7251us device window. Earlier decode-gated CCL trials did not establish prefill-family coverage. The reviewer flagged this as required work, and the stage remained open.

## Coherent families

- Separate async AG/RS: BF16 or BFP8 payload, BF16 statistics,2/4/8 workers,2/4 buffers,4/10/16 chunks per synchronization, transient and shared persistent buffers. Worker count is material; payload reduction alone does not necessarily win.
- Direct AG output in L1 feeds the consuming projection. RS output remains hidden-sharded in L1 through residual, distributed norm and the next projection. The candidate returns L1 without an immediate DRAM or replicated restore.4096,2048 and1024 internal chunks and bounded output blocks test capacity adaptations.
- Fused AG/MM consumes1280 local channels and interleaved BFP4 column weights; fused MM/RS consumes native DRAM-sharded row weights, emits1280 channels and uses mandatory persistent intermediate/output buffers. Combined families retain the same hidden-sharded residual. Mix-only4096 trials isolate a viable projection from wide gate/up capacity and whole-layer chunking overhead.
- BF8 matmul inputs are tested as actual role-local activation policies in adapter v4 onward. Earlier keep-BF8 flags in v1–v3 merely delayed a BF16 cast; those rows establish payload behavior, not BF8 matmul input. Source snapshots/hash receipts preserve this correction.

## Harness and synchronization repairs

`run_multichip_decoder.py` now releases eager/captured prefill outputs after host comparison and trace retirement. They are unused during decode; retaining both L1 outputs caused artificial phase-overlap capacity failures. The reviewer independently verified that state and decode inputs do not alias these outputs. Release is outside the measured prefill window. Earlier affected L1 trials are retried, not rejected from those failures.

`AUTOTRIAGE_prefill.md` derives the fused AG readiness mismatch from preserved stacks and current source. AG publishes two readiness increments per direction, but the receiver's second M output block requests a third. The sender also reuses the first M-row base. Setting one M/N output block per core avoids both defects. Legal2048/1024 internal chunks and4096 mix-only trials now complete with passing PCC on both meaningful layer kinds. H16 is only valid for these B1 shapes; it is not a general larger-batch repair.

There is a separate watcher-gated assertion defect: the AG factory hardcodes four transfers where the TP4 receiver expects two per direction. An AG candidate cannot be selected without addressing that metadata and passing watcher. The current production path does not use fused AG. No assertion is disabled for acceptance.

The8x8 full-height wide gate/up fusion exceeds physical L1, including after BF8 input/output adaptation. BF8 output can add a distinct output CB rather than sharing BF16 partial storage. The11x8 grid trial distributes output storage across more cores while retaining a4096-token chunk and reserves row8 for CCL. See the next grid results before treating capacity as a family rejection.
