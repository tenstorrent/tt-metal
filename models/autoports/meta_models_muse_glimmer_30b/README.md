# Muse-Glimmer-30B TTNN autoport

Primary greedy vLLM serving (**128 input / 128 output / 1 request, concurrency 1**) measures **69.22 ms TTFT and 58.13 decode tokens/s/user** on QB2/P300x2 with max_num_seqs=32 and max_model_len=131072. Native cache-group page inputs reduce TTFT by 22.68% and improve decode rate by 1.24% versus the fresh identical-workload baseline. The secondary CI burst (**100/100/32**) completes at 919.84 aggregate output tokens/s. See [optimized serving evidence and status](doc/optimized_vllm/README.md).

The 32-policy datatype sweep selects `head_bfloat4_b_LoFi_bf16_acc_r2_k4`: 99% top-1 and 100% top-5/top-100 in both prefill and teacher forcing on the pinned AIME24 chat reference (204 prompt / 100 generated tokens). Warmed traced teacher-forcing decode is 59.8420 t/s/user with 57.4023 ms TTFT. All faster evaluated policies fail either context or batch append gates. Normal-default warmed token-out is **60.3049 t/s/user, 50.5320 ms TTFT**, using 128 input / 128 generated tokens and no per-token readback (2.49% faster than the refreshed baseline). Use this token-out result for later serving comparisons. The [independent review](doc/datatype_sweep/STAGE_REVIEW.md) is **clean-pass**.

The [required precision artifact](doc/datatype_sweep/selected_precision_config.json) is consumed by normal construction. The LM head uses BFP4/LoFi/BF16 accumulation with 52 input cores, two readers and K4. Decoder precision remains inherited: BFP4/LoFi projections, sliding QKV FP32 accumulation, original norms, mixed BF16/BFP8 activations/CCL, BFP8 cache, BF16 residual/logits and BF16/uint32 sampling. `MUSE_PRECISION_CONFIG=baseline` provides rollback. Full 131,072-token context and 32 logical slots are preserved; physical cache pages are pooled.
