Method & caveats

Warmup pass. Before measuring, every ISL×concurrency shape is exercised once (results discarded) — matching tt-inference-server. This inoculates against the first-call program-recompile-under-resident-trace stall; it is why 128k decode reads 21.7 t/s/u here vs 13.5 in the prior unwarmed sweep.
Cold, APC off. Prefix caching disabled so identical random prompts don't cache-hit. Warm/agentic per-turn TTFT is far lower. Metrics: t/s/u = 1000/mean_TPOT; aggregate = output throughput; E2EL measured. Decode SDPA = accurate k64; PREFILL_FAST=1.
C=8 all-at-once collapse. At 16k+, launching 8 requests simultaneously saturates prefill, inflating TTFT (85 s) and starving decode (5.6 t/s/u/user). This is a benchmark-arrival artifact, not a steady-state limit — ramped arrival avoids it. 128k @ C=8 is infeasible on the current KV pool.
