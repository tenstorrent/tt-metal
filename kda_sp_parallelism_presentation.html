Sequence parallelism for a causal linear-attention model.

Kimi Delta Attention (KDA) is locally parallel over tokens inside a span, but its recurrent state and short causal convolution cross every sequence boundary. This deck explains how the current SP=2 × TP=4 implementation preserves that dependency without bouncing tensors through the host—and why it is a credible building block for Galaxy.

The key split: TP partitions heads/hidden work inside each four-chip group. SP partitions time into ordered contiguous spans between groups.
01 · What must cross an SP boundary?

Not activations. The causal memory.

Recurrent KDA state

Each TP rank owns eight of the 32 heads. Its FP32 recurrent state is 512 KiB for K=V=128. The next sequence span cannot produce correct KDA outputs without the previous span’s final state.

Sout = Aspan ⊙ Sin + Bspan

Causal short-convolution history

The KDA input projection includes a causal convolution with kernel size four. Therefore span 1 additionally needs the previous three projected Q/K/V samples from span 0: about 18 KiB BF16 per TP rank.

conv[xt−3, xt−2, xt−1, xt]
Important: this is not transformer attention’s all-gather of a growing KV cache. The boundary is fixed-size state plus a three-sample convolution carry; its size does not grow with context length.

Exact hardware mapping

The implementation opens the physical 1×8 LoudBox with 2D fabric, then creates logical 1×4 submeshes at chips 0–3 and 4–7. A TT_CCL object belongs to each TP group. One socket pair is reused in ordered sequence for recurrent then convolution state.

Trace stability

The destination states have fixed addresses. The trace can replay because each boundary overwrites the existing SP1 state buffer before it is consumed. Child traces own the two TP=4 command streams; the parent 1×8 mesh owns no KDA work.

04 · The Galaxy-shaped idea

Represent a span as an affine transform, then prefix transforms—not full token work.

S1 = A0 ⊙ S0 + B0
→
S2 = A1 ⊙ S1 + B1
→
S2 = (A1⊙A0)⊙S0 + (A1⊙B0+B1)

SP=2 today

SP0 produces a transform/end state and sends it to SP1. This is the smallest useful case: a single boundary, but exactly production-equivalent TP=4 work per rank at the long-sequence shape.

Why it helps: SP1 doesn’t wait for SP0’s complete token-output scan; it only needs the affine boundary state.

SP=8 on Galaxy

Each of eight contiguous spans builds its local transform. A log-depth prefix propagates entry states in roughly log₂(8)=3 stages, after which every span runs its seeded token scan locally.

Payload reality: for TP=4, A is 512 KiB and B is 512 KiB per rank—about 1 MiB uncompressed summary. This is the central distributed-prefix engineering problem.

05 · Inside the TP group

SP changes time ownership. TP still needs collectives.

Input and KDA work

TP=4 divides heads/hidden channels. Each rank processes its local heads for its local sequence span. No TP communication is needed for the head-local recurrent KDA scan itself.

Output projection

Each rank produces a partial hidden contribution. The optimized path fuses the row-parallel output matmul with a Linear reduce-scatter, returning only its hidden shard.

Why Linear reduce-scatter?

A TP=4 child mesh is a line in this logical construction. The fused primitive explicitly selects the Line program (a prior factory issue incorrectly built Ring). Line requires two input-sized intermediate regions for its forward and backward partial reductions.

Correctness trap found: fused MRS returns [B,1,T,H/TP]. A host test mistakenly indexed the singleton dimension as T, reporting a false boundary PCC failure. The code now reshapes it to [B,T,H/TP] before the SP layer uses it.

06 · Bad sides, limits, and next work

The prototype proves the direction, not Galaxy readiness.

PROBED

SP=8 prefix transport

The exact production TP4-rank A+B payload now runs through three traced 1×8 stages. Two lanes measure 1.274 ms median and all eight derived entry states pass PCC ≥0.999.

RISK

Experimental two-lane runtime

Two lanes are 45% faster than one (1.274 vs 2.333 ms) but emit the fabric runtime’s multi-sender warning. Keep it environment-controlled until a repeated stress run and TP4 overlap prove it robust.

LIMIT

LoudBox is not Galaxy

LB can validate the exact prefix payload and schedule, not SP8×TP4’s 32-rank contention. The SP8×TP1 layer probe still has four times the production head work and no TP CCL.

TODO

Overlap with real KDA

The 1.274 ms result includes standalone FP32 transform composition. Next place the prefix beside production-shape TP4 preparation and grouped scans to discover the usable critical-path overlap.

TODO

Stabilize SP2 first replay

The SP2×TP4 10-replay median passes, but its first measured replay was 3.922 ms. Find and remove this startup/replay imbalance before treating the topology result as production-quality.

DO NOT DO

Do not silently compress state

The recurrent state is FP32 for numerical correctness. Any quantization/compression requires an explicit accuracy study and must not be smuggled in as a transport optimization.
