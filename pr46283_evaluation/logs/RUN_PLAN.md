### Flags that are mandatory, not optional
- `--model-dir`, not a model id (F9: a local model dir is mistaken for a demo dir).
- `--pcc-test` explicitly (F10: the F9 workaround loses the model id, so optimize cannot build its
  own correctness gate).
- **`--devices 0` (F38).** The default `"0,1"` plans a 2-chip TP=2 topology on this 1-chip box and
  silently overrides an explicit `--mesh 1,1`.
- **Do NOT pass `--perf-test`.** Without it the perf workload is auto-generated from `--pcc-test`.
  If the profiler overflows on the real forward, that is a finding to record — not a cue to
  hand-roll a replacement test.
