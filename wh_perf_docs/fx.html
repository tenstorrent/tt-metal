The fix in Versim

Same config with the settle switch (LLK_ISO_SETTLE=2000), 0 and +4 bytes per function in unpack and math:

Versim0 bytes+4 bytes
Without the fix (cycles)71,87392,263
With the fix (cycles)71,79171,791
Code-line reads by unpack and math within 3,000 cycles of the first DEST read, with the fix00

With the settle, the idle threads finish their exit code more than 3,000 cycles before the packers start, so none of their L1 reads land in the pack window, and both builds give the card's value (71,791).
