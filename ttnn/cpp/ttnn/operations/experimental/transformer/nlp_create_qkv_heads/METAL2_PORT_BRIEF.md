## Watch for

- **CB endpoints (multi-binding):** none. Sharded `c_16` is two role-free touchers → 1P+1C, not the flag. Interleaved per-group compute specs are the disjoint-node work-split — not a two-toucher.
- **Sharded K/V output DFBs are per-node-conditional — plan two WorkUnitSpecs and a promoted define.** In Metal 2.0 a DFB's node set is the union of its binders' node sets (`program_spec.cpp:656-668`) and a borrowed DFB gets **one** base address on every bound node with no shard-grid coverage check (`program_spec.cpp:1583-1630`, `program_run_args.cpp:495-560`). Binding `dfb::kv_out` from a KernelSpec over all `q_cores` would place `c_17`/`c_18` on cores holding no K/V shard. Shape: WorkUnit A = `k_cores` (R binds `q_out`+`k_out`, W binds `q_out`+`v_out`, define `READ_KV_HEADS` on), WorkUnit B = `q_cores \ k_cores` (R, W bind `q_out` only, define off) — two same-source KernelSpecs per instance over disjoint node sets (legal per `program_spec.cpp:84-89`). Kernel: wrap the KV block (`sharded:69-119`, including the `cb_id_kv_out` CTA read `:78` and the `DataflowBuffer` on `dfb::kv_out`) in `#ifdef READ_KV_HEADS`; the `read_kv_heads` RTA (`sharded:25`, `:432`) becomes redundant — it is host-deterministic per core (`i < k_cores.num_cores()`), which is what makes the promotion legitimate (→ `port_patterns.md` *Conditional / optional resource bindings*, "Promote a CTA gate to a define" — here an RTA gate). Omit WorkUnit B when `k_cores == q_cores` (`num_kv_heads == num_q_heads`). `q_cores \ k_cores` is the tail of the row-major `grid_to_cores` order (`:405-408`). **This is a kernel-structure change beyond a syntax swap — check it against the kernel-side whitelist first; if forbidden, capitulate on `Sharded`, record the handoff, and port `Interleaved` alone.**
