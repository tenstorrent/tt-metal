The essential translation

Fabric order is not tensor order

The snake reverses every odd physical row. Tensor sharding does not: it stays row-major. A small involutive permutation lets the same function convert in either direction.

Host: find neighbors in snake space

At coordinate (row, col), compute a logical ring rank. Neighbors are simply rank ±1 modulo 32.

s = row·C + (row even ? col : C−1−col)
forward = (s + 1) mod 32
backward = (s − 1) mod 32

That produces horizontal hops within a row, vertical hops at alternating row ends, and one closing Y-wrap.

Kernel: address row-major output

Relay scheduling remains in snake space, but every output address first maps the stripe to its canonical tensor rank.

tensor_rank(s) = permute_odd_lanes(s, C)

permute(permute(x)) = x

The local copy, neighbor write, and downstream relay read all use this same translated iterator.

Host-side route proof

It runs only when every edge is truly direct

The op does not ask Fabric to forward around corners. Before creating a program, the host proves all 64 directed neighbor routes and verifies every requested link index.

Store and forward

One hop at a time, pipelined

A stripe terminates in the adjacent chip's persistent output. On the next iteration, that chip rereads the received rows and relays them onward. No packet itself crosses multiple mesh hops.

How to select it

cluster_axis=None means the whole mesh

Integer axes retain the existing independent row/column collectives. Explicit None is the new contract for one all-gather across all 32 Galaxy devices. 

# Fabric is opened as an 8×4 Galaxy mesh with Torus X and Y.
output = ttnn.empty(
    gathered_shape,
    device=mesh_device,
    layout=input_tensor.layout,
    dtype=input_tensor.dtype,
    memory_config=ttnn.DRAM_MEMORY_CONFIG,
)

ttnn.experimental.high_bw_all_gather(
    input_tensor,
    output,
    dim=gather_dim,
    cluster_axis=None,      # one 32-device snake ring
    subdevice_id=subdevice_id,
    sub_core_grid=worker_grid,
    num_links=2,          # Galaxy-compatible uniform link count
)
Input distribution

The gather tensor dimension must be sharded across every mesh device, with row-major mesh coordinates.

Output shape

The output extent at dim grows by 8×4 = 32, and that placement becomes replicated.

Output storage

The caller supplies a preallocated persistent interleaved-DRAM output used for both final data and relay staging.

What this design buys

A simpler collective, not magical bandwidth

Advantages

One program, one synchronization sequence, direct 32-way output placement, no corner-forwarding firmware changes, and a strict host proof that rejects unsafe topologies.

Boundaries

A generic mesh needs at least one even dimension: the host prefers a row snake and falls back to a column snake when only the X closure is direct. Full-mesh link selection is conservative, and the idealized link-volume bound is comparable to a two-phase axis-1 then axis-0 all-gather.
