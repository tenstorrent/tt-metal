Run the suite

From the repository root:

python scripts/run_reduce_migration_tests.py

The runner invokes scripts/run_safe_pytest.sh --run-all --no-precompile once per source group, serially. It continues through failing groups and returns nonzero if any group fails. It preserves the repository fixtures, architecture checks and skips; --runslow is enabled for TTNN unit-test modules. C++ cases run through the pytest adapter, using the existing build/test/ttnn/unit_tests_ttnn and build/test/ttnn/unit_tests_ttnn_udm binaries. The adapter checks that exactly the requested C++ test ran and propagates failures and skips.

Useful commands:

# Count the actual parametrized cases without executing test bodies
python scripts/run_reduce_migration_tests.py --collect-only

# Inspect the selection or the wrapper commands
python scripts/run_reduce_migration_tests.py --list
python scripts/run_reduce_migration_tests.py --dry-run

# Run groups associated with a report factory (family-level selection)
python scripts/run_reduce_migration_tests.py --factory F058

# Narrow by source/group and forward normal pytest filters
python scripts/run_reduce_migration_tests.py --group moreh -- -k callback

# Optional Python kernel warm-up; collection always disables precompile
python scripts/run_reduce_migration_tests.py --precompile

# Explicitly opt in to the four upstream-disabled C++ tests
python scripts/run_reduce_migration_tests.py --include-disabled-gtests --group T159

Each invocation creates a new generated/test_reports/reduce-migration-* directory. It contains a manifest snapshot, a log/JUnit XML/count JSON/node-ID list for each group, and summary.json. --output-dir accepts a new directory and refuses to overwrite an existing one. Use the test environment and hardware topology appropriate to the selected groups; this inventory spans single-device, multidevice and Quasar operation tests. The runner does not change hardware visibility or enable test-specific environment opt-ins. DeepSeek groups default MESH_DEVICE=AUTO, as their conftest requires a system selection even during collection; an existing caller-provided value takes precedence.

Selection and coverage limits

Existing compute reduce-helper factories plus the 19 dataflow-extension hosts in the migration inventory. Direct operation unit suites, their validation/cache/numerical/performance cases, model per-op suites, and C++ operation/UDM tests. End-to-end model suites and incidental math in unrelated tests are outside this suite.

Each Python test function/method is selected once; pytest expands all parameters and fixtures. Each C++ TEST/TEST_F is one case. Disabled C++ tests are retained as pytest skips unless explicitly enabled. Tests can cover more than one factory; mapping is a family selection aid, not proof that every case executes every listed factory.

The selected modules include sanity and nightly tests without applying their CI -k/-m filters. This is broader than the representative test nodes in the earlier factory/CI audit. Whole operations may dispatch among several factories; shared parameter tables are retained for that operation family. Unrelated standalone reductions (prod/top-k/argmax/fast NC), unrelated Moreh backward factories, NC-only Moreh softmax tests, model end-to-end tests, and perf-table report generators are excluded. prod rows are deselected from mixed generic-reduction parameter tables.

The suite includes MLA prefill/decode because those entry points select the listed SDPA factories. It does not credit standard ttnn.sum/mean calls in Quasar-named files to the separate experimental Quasar reduction factories.

Factories without direct executable coverage remain explicit:

  • F046, F047, F048, DH004: No direct test invokes the experimental Quasar generic-reduction entry points. The Quasar-named ResNet sum/mean tests actually call standard ttnn.sum/mean and are included against the standard factories.
  • DH005: No direct test found for the experimental Quasar joint SDPA factory.
  • DH001: No unit test found for the BGE custom encoder SDPA descriptor. Existing BGE attention PCC tests use the stock path.
  • F090: The explicit large-height general-softmax factory smoke test is disabled upstream; retained as a skipped adapter case.
  • F024: Source-composition-only test; does not execute a factory or helper kernel, so excluded.

F084 is covered through the shared sharded-normalization builder. Both factories in F087 are selected. F041 and F086 have factory tests but cannot enable the retained compute-helper branch identified in the earlier audit.
