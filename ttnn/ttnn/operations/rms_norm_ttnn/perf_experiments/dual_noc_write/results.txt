dual_noc_write -- measured results
Box: Blackhole p150b, 11x10 = 110-core compute grid, AICLK 1350 MHz, 8 DRAM banks.
Metric: DEVICE KERNEL DURATION [ns], median of 3-5 fresh runs.
Precision contract identical in every variant: HiFi2 / fp32_dest_acc_en=False /
math_approx_mode=False / bf16 in-out.  Never a lever.

PART 1 -- THE DM ROOFLINE INSTRUMENT  (dm_bench.py + kernels/dm_lane.cpp)
===========================================================================
Pure DRAM->L1->DRAM tile copy, NO Tensix compute kernel, reproducing the focus
shape's transfer pattern exactly: 110 cores, ttnn.split_work_to_cores(full_grid,
Rt=256, row_wise=True), WT=72 tiles/row, 2048 B interleaved pages, one
noc_async_read_tile / noc_async_write_tile per tile, one barrier per row-block.
Every run is bit-exact against the input (exact=True), so every number below is
correctness-gated.

===========================================================================
PART 2 -- THE CANDIDATE IN THE REAL OP  (bench_op.py, k_base vs k_alt)
===========================================================================
Only two things vary: PD.KERNEL_DIR, and whether the two DM kernels are built
DM_DEDICATED_NOC (shipped) or DM_DYNAMIC_NOC.  k_base is a byte-identical copy
of the shipped kernels (the control).  k_alt differs from k_base by exactly one
hunk in rms_norm_ttnn_writer.cpp: the last WT_CHUNK/10 tiles of every row-block
are issued with noc_async_write_tile(..., alt_noc), plus a second barrier.

  FOCUS (1,1,8192,2304) INTERLEAVED gamma, pcc 0.999985 for every variant
    base   191,901
    kbase  189,049 / 189,497 / 187,842      (spread 0.9 %)
    dyn    188,375 / 192,273     1.004x     DM_DYNAMIC_NOC alone is FREE
    alt    196,004 / 196,056     0.964x     REPRODUCIBLE 3.6 % REGRESSION

  domain sweep, kbase vs alt (pcc >= 0.999985 everywhere)
    (1,1,8192,1024)  INTERLEAVED    86,205 ->  85,879   1.004x  flat
    (1,1,8192,2304)  INTERLEAVED   189,049 -> 196,056   0.964x  REGRESSION
    (1,1,8192,7168)  INTERLEAVED   575,975 -> 580,294   0.993x  flat
    (1,1,32,1024)    INTERLEAVED     4,364 ->   4,678   0.933x  REGRESSION
    (1,1,32,7168)    W-SHARDED       3,778 ->   3,841   0.984x  (writer is a
        no-op there -- NATIVE_OUT gates ALT_W off -- so this is the residual
        DM_DYNAMIC_NOC cost on the sharded path, not the candidate)

WHY the isolated 1.03x becomes a real-op 0.96x: in the pure copy the writer is
saturated and NoC1 is the longer pole, so NoC0's 32 us of slack is worth buying
even at NoC0's 1.75x-per-byte write penalty.  In the real op the writer waits on
compute, NoC1 is NOT the pole, and every byte moved to NoC0 is simply 1.75x more
expensive -- plus one extra per-block barrier.
