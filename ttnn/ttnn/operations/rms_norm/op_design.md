# Operation Design: rms_norm

## Overview

| Field | Value |
|-------|-------|
| Classification | compute (a row reduction followed by a row-broadcast normalisation: two passes over each row's tiles, one DRAM read) |
| Goal | `ttnn.rms_norm` for Quasar as one `ttnn.ProgramSpec` dispatch: every row of the input scaled by `1/sqrt(epsilon + mean(x²))` over the last dimension and by `gamma[j]` per column. |
| Math | `out[..., j] = x[..., j] * gamma[j] * rsqrt(epsilon + (1/W) * sum_k x[..., k]^2)`, `gamma = weight.reshape(-1)[:W]` |
| Specification | `eval/specs/rms_norm/spec.py` (authoritative; this design is how, the spec is what) |
| References | `.claude/references/targets/quasar.md`, `.claude/references/backends/ttsim.md`, `.claude/references/quasar_op_examples/toy_row_passes/` (the row-dealing and per-row pass structure this op follows), `.claude/references/quasar_op_examples/toy_thread_plan/kernels/reader_mixed.cpp` (implicit + explicit rings in one reader), `ttnn/cpp/ttnn/operations/experimental/quasar/softmax/device/kernels/` (tt-metal's own Quasar row reduction: reduce scaler generated by the reader, explicit-sync scaler ring), `tt_metal/impl/dataflow_buffer/DataflowBuffer.md` (ring semantics), `ttnn/ttnn/operations/examples/master.md` (catalog entries cited per knob below) |

### Catalog entries that informed the knobs

| Entry | Knob it informed | What it says that applies here |
|-------|------------------|--------------------------------|
| `row_reduce_accumulate` | how Σx² over a row is formed | accumulate the row's tiles in DEST first, then reduce **once**; do not fold the whole row into one reduce (it pays the reduce datapath per tile, and in tf32 here) |
| `eltwise_l1_vs_dest_accumulate` | `sum_squares_block` | keep the running sum in DEST (`DestAccumulation`), one pack at the end: the L1 traffic upper bound |
| `compute_fusion` | `normalize_block` perf lamp | an SFPU multiply is slower than an FPU multiply, and FPU dest-reuse loses to an L1 round trip: the gamma multiply is a lamp |
| `double_buffer` | `gamma_block_tiles`, depths | several reads per barrier (4–8 sweet spot), buffers sized `2 × block` |
| `width_split` | the deferred `w_split` regime | a one-tile-row-tall tensor split by tile-rows runs at single-core speed (up to 7.8× left on WH for an elementwise op) |
| `tensix_all_reduce` | `w_split` topology | for a 1-D group and a tiny payload: every member sends its partial to a root, the root reduces and multicasts back |

## Blocking Model

### Axes

The op's data, enumerated: the input's batch-like dims `N, C` and the tile-row index of `H` fold into one axis `tile_rows` (contiguous in tile order, treated identically, rows never interact); the 32 rows inside a tile; the width `W` in tiles; and the weight operand.

| Axis | Character (+ one-clause reason) | Extent knob | Phase 0 value | Knob source | Core-assignment | Later unlock |
|------|--------------------------------|-------------|---------------|-------------|-----------------|--------------|
| `tile_rows` (N·C·ceil(H/32)) | **independent** — every output row depends on its own input row only | `rows_per_block` (tile-rows one NEO holds and drives through one pass) | 1 | host constant `ROWS_PER_BLOCK` | rounds of `C_eff` tile-rows dealt whole to clusters by `ttnn.split_work_to_cores(grid, num_rounds)`; inside a cluster tile-row `k·C_eff + t` goes to NEO `t` | knob-turn (`rows_per_block` > 1 via a `grid(rows, Wt)` walk with PerRow DEST accumulation) |
| intra-tile rows (32 per tile-row) | independent — rows of a tile never interact | fixed by the tile (32) | 32 | tile geometry | not assigned across cores: the tile is the indivisible transfer unit; cutting it would re-read the whole tile per core (rejected regime `subtile_row_split`) | — |
| `w_tiles` (Wt = ceil(W/32)) | **dependent** — the mean of squares spans every tile of the row | `block_wt` (tiles of a row one NEO holds at once) | `Wt` (the whole row, resident) | derived on host from the regime: `block_wt = tensor_w_tiles` in `row_resident` | not split across NEOs or clusters: a split needs a combine (deferred regime `w_split`) | scheme-change (`w_split`); knob-turn to `block_wt < Wt` only together with the deferred `row_streaming` regime |
| weight operand (W gammas) | **reuse-shared** — it does not vary along `tile_rows`, the split axis, so every NEO re-reads the same bytes (operand-reuse check) | `gamma_block_tiles` (gamma tiles assembled per reader barrier) | largest divisor of Wt ≤ `GAMMA_BLOCK_MAX_TILES` (16) | host constant `GAMMA_BLOCK_MAX_TILES`, block derived | each NEO streams the gammas of its own row; no sharing across NEOs or clusters | deferred regime `gamma_resident` (one copy per cluster, ALL ring) |
| intermediate `row_stats` (Σx², row sum, inv_rms: one tile per tile-row) | independent along `tile_rows` (inherited) | one tile per tile-row | 1 tile | — | computed by the NEO that owns the tile-row: no designated core, no idle group | — |

**Scheme committed for Phase 0:** `row_resident` (regime table). Tile-rows split across clusters and across the 4 NEOs of a cluster; each NEO holds a whole tile-row resident in its slice of the input ring, takes Σx² over it in DEST, reduces once, finalizes `inv_rms`, and normalizes the same resident tiles. Every knob above, `C_eff`, the grid and the depths below are parameters (host constants or values derived from them, passed as CT/RT args); no kernel loop bound is a literal.

### Thread plan knob (fourth day-1 knob)

| Knob | Phase 0 value | Source | Why |
|------|---------------|--------|-----|
| `THREAD_PLAN` (R, C, W) | (4, 4, 2) | host constant in `rms_norm_program_artifacts.py` | bound by compute (Work Distribution); the reader reads more than the writer writes (input + a gamma read and local assembly per tile), so R = 4, W = 2 |
| `C_eff` per call | `min(THREAD_PLAN.C, c_fit, pow2floor(num_tile_rows))` | derived on host | `c_fit` = largest `c ∈ {1,2,4}` with `Wt · c · tile_bytes ≤ min(DFB_EXTENT_CAP_BYTES, budget_for_input_ring)` (mechanism cap, below); `pow2floor(num_tile_rows)` stops a cluster with fewer rows than NEOs from recomputing rows |
| `R_eff`, `W_eff` | `min(R, C_eff)`, `min(W, C_eff)` | derived | keeps R \| C, W \| C, R + W ≤ 6; with (4,4,2) every reader feeds exactly one NEO (`group = C_eff / R_eff = 1`) |

Worked values on this target: Wt ≤ 127 → c_fit = 4; 128 ≤ Wt ≤ 255 → 2; 256 ≤ Wt ≤ 511 → 1 (bf16, 2,048-B tiles). For the Phase 0 INPUTS: (1,1,32,2048), (1,1,32,128), (1,1,8,128), (1,1,32,2560), (1,1,32,64), (1,1,17,64), (1,1,32,4096), (1,1,32,8192) → C_eff = 1 (one tile-row); (1,1,64,128), (1,1,50,128) → 2; (1,1,128,4096), (2,1,64,4096) → 2 (c_fit); (4,8,32,256), (2,4,128,512), (1,1,2048,256), (2,1,512,512), (4,8,47,256) → 4.

| CB | Depth knob | Phase 0 value | What the depth buys |
|----|------------|---------------|---------------------|
| `cb_input_tiles` | `IN_DEPTH_ROWS` (whole tile-rows per NEO) | 1 | the row is resident across both passes (input crosses DRAM once); pass 2 pops per tile, so the reader refills freed slots with the next row while pass 2 runs |

| `cb_row_sum` | — | 1 per NEO | — |
| `cb_scaler` | — (constant) | 1 per NEO | — |

### Mechanism caps

| Mechanism | Cap on which extent | Clamp | What happens unclamped |
|-----------|--------------------|-------|------------------------|
| Ring extent (uint16 × 16 B) | `block_wt · IN_DEPTH_ROWS · C_eff · tile_bytes ≤ 1,048,560` (input ring); also every other ring | `C_eff ≤ c_fit`; if `c_fit` does not exist (Wt · tile_bytes > cap at C = 1: bf16 Wt ≥ 512) the op raises `NotImplementedError` naming the deferred `row_streaming` regime | the program is refused |
| Indexed pass-1 access on a ring | the input ring's capacity per NEO must be **exactly** `IN_DEPTH_ROWS · Wt` | capacity derived from `Wt`, never padded | a row would start mid-ring and an indexed (Block-mapped) window would straddle the ring end |
| Implicit-sync credit batches (`DataflowBuffer.md` §"How the ISR threshold is programmed") | credits post in batches of `capacity / num_txn_ids` | input ring capacity = whole rows per NEO, so every row ends on a batch boundary | pass 1's cumulative wait for the row's last tiles would wait on a batch completed only by the next row's reads, which wait on pass 2: deadlock |
| Reader-assembled gamma entries | `gamma_block_tiles` must divide Wt, and gamma capacity per NEO = `GAMMA_DEPTH_BLOCKS · gamma_block_tiles` | `gamma_block_tiles` = largest divisor of Wt ≤ 16 | a `reserve_back(n)` window straddles the ring end: the reader writes past the ring |
| Row broadcast on Quasar | gamma entry format and row | gamma ring is Float16_b; gammas sit in row 0 of faces 0 and 1 (`bcast_row_idx == 0`) | 32-bit page: LLK_ASSERT (`bcast.h:113`); another row: LLK_ASSERT / wrong gammas |
| DEST capacity (fp32, half sync: `DEST_AUTO_LIMIT` = 4) | `inv_rms_block` and `normalize_block` keep 2 tiles live at once (D0, D1) | 2 ≤ 4; no larger lane count planned | — |
| Thread plan | C ∈ {1,2,4}, R + W ≤ 6, R \| C, W \| C | `C_eff`, `R_eff`, `W_eff` as derived | refused at program build, or entries dealt to a missing thread: hang |
| Rings per NEO / per cluster | 6 rings ≤ 24 per NEO, ≤ 32 per cluster | fixed inventory | refused at program build |
| Gamma page transfer | one 64-B page (bf16) per tile column, DRAM-aligned (64 B) | the page is read whole, never at a 32-B source offset | a misaligned DRAM read |

### Regimes

| Regime | Status | Predicate | Block | Data movement vs. minimum (DRAM boundary) | What a bigger block buys |
|--------|--------|-----------|-------|-------------------------------------------|--------------------------|
| `row_resident` | **built** | `c_fit ≥ 1`, i.e. `Wt · tile_bytes ≤ min(DFB_EXTENT_CAP_BYTES, budget_for_input_ring)` (bf16 on this target: Wt ≤ 511; holds for every Phase 0 and every bf16 INPUTS shape) | `rows_per_block` (1) × `block_wt` (= Wt) tiles per NEO | input crosses once (minimum) plus at most `C_eff − 1` padded tile-rows re-read in the whole op; output once plus the same duplicates; gamma `num_tile_rows · W · 2 B` = 1/32 of the input bytes (above the `W · 2 B` minimum: re-streamed per tile-row, see `gamma_resident`) | per tile-row: 4 helper inits, 3 `pack_init`s, 1 reduce, 1 finalize chain, one scaler wait, all paid once per Wt tiles; `block_wt = Wt` also removes a second DRAM pass entirely (the `row_streaming` cost) |
| `row_streaming` | **deferred** — no PHASE0 cell reaches it on this target: bf16 Wt ≤ 256 needs ≤ 524,288 B at C = 1, under the cap; it becomes necessary for float32 (Wt = 256 × 4,096 B = 1 MiB > cap) | `c_fit` does not exist | `rows_per_block` × `block_wt < Wt` (a window of `2 · block_wt` per NEO) | input crosses DRAM **twice** (pass 1 and pass 2 each stream the row) | fewer window handshakes; reachable as a knob-turn on the built structure: the reader's per-round loop gains a `passes` CT arg (1 → 2), pass 1 switches its input policy from Cumulative/None to PerTile/PerTile, pass 2 is unchanged |
| `w_split` (dependent axis across NEOs and clusters, all-reduce of Σx²) | **deferred** — a built regime (`row_resident`) already serves every shape it would serve; by the binding traffic ranking it is second (it adds a combine to the same DRAM bytes), and what it buys is occupancy alone. It is the first refinement for the model calls: each of the four traced shapes is one tile-row, so Phase 0 runs them on one NEO of 128 | `num_tile_rows < C_eff · num_cores` and `Wt ≥ 2` | per NEO: `rows_per_block` (1) × `ceil(Wt / (G · C))` tiles of one row, the row's Wt tiles dealt over a group of G clusters × C NEOs | input once and output once (minimum) **plus** a combine per row: G·C partial Σx² tiles to a root (4 KiB each) and one `inv_rms` tile multicast back to G clusters | the combine round (semaphores and multicast) is paid once per row, so a bigger per-NEO W-chunk amortizes it. **Topology, kept reachable:** each NEO's `sum_squares_block` result (`cb_row_stat`, one tile) is exactly the partial the combine sums; NEO partials leave through a compute→writer ring, the writer unicasts them to the group root's gather buffer and increments the root's semaphore (`ttnn.Mcast` / `McastArgs`); the root's compute sums G·C tiles (FPU `add` with DEST accumulation), runs `inv_rms_block`, and the root's writer multicasts the tile to the group; each member's reader pushes it into `cb_row_stat` once per NEO. **Stall shadow:** while a member waits for `inv_rms` it can already form `x · gamma` (`normalize_block` reordered: the per-row scale commutes with the per-column weight); this changes the rounding order (gate it on the precision baseline). `normalize_block` is otherwise unchanged |
| `gamma_resident` (broadcast of the reuse-shared weight) | **deferred** — on this target every INPUTS shape has ≤ 64 tile-rows, so each NEO does ≤ 1 round and already reads gamma once; residency saves `(num_tile_rows − clusters) · W · 2 B` ≤ 1/32 of the input bytes | `num_tile_rows > C_eff · num_cores` (several rounds per NEO) | Wt gamma tiles per cluster, one copy seen by every NEO (`all_consumer_of`, ALL pattern) | gamma `clusters · W · 2 B` instead of `num_tile_rows · W · 2 B` | the gamma reader barriers drop from Wt/`gamma_block_tiles` per row to once per kernel. Reachable: the gamma ring's binding changes from STRIDED to ALL and the compute's gamma input from PerTile pops to Upfront hold; nothing else moves |
| `subtile_row_split` (split the 32 rows of a tile-row over clusters, each reading the whole tile-row) | **rejected** — superseded by `w_split`, which gains the same occupancy with no duplicate reads | — | — | input crosses DRAM G times | — |
| sharded placements | **not in TARGET** (`sharding: ["interleaved"]`) | — | — | — | — |

Regime selection function (host, before building the program): `row_resident` if `c_fit` exists, else `NotImplementedError("rms_norm: row of {Wt} tiles exceeds one ring at C=1 (regime row_streaming not built)")`. Within `row_resident` the variant is `C_eff ∈ {1, 2, 4}`, a different compiled program; **regime-pinned tests** cover each `C_eff` (Work Distribution).

### Traffic ranking

| Rank | Split | DRAM crossings | Cross-core traffic | Verdict |
|------|-------|----------------|--------------------|---------|
| 1 | `tile_rows` across clusters and NEOs, row resident (`row_resident`) | input 1×, output 1×, gamma 1/32 of input | none | **chosen** — the cheapest: it reaches the minimum on input and output, and no other split touches fewer bytes |
| 2 | `w_tiles` across clusters and NEOs + all-reduce (`w_split`) | input 1×, output 1×, gamma 1× per W-chunk | per row: G·C × 4 KiB partials to a root, 1 × 4 KiB multicast to G | deferred — more bytes than rank 1 and a rendezvous per row; preferred only where rank 1 leaves the grid empty (occupancy, a measured trade) |
| 3 | `tile_rows` split, row streamed twice (`row_streaming`) | input 2×, output 1× | none | deferred — only where the row does not fit one ring |
| 4 | intra-tile rows across clusters (`subtile_row_split`) | input G× | none | rejected |

The reuse-shared weight under the chosen split: gamma does not vary along `tile_rows`, so every NEO re-reads it. Its broadcast (`gamma_resident`, or a multicast from one reader) is a separate deferred row. The bytes involved are 1/32 of the input.

### Block schedule

Per cluster (NEO `t` of `C_eff`, round `k` of `rounds = ceil(rows_this_core / C_eff)`; NEO `t`'s tile-row in round `k` is `row_start + k·C_eff + t` when it exists, else the round's NEO-0 row):

```cpp
prepare_scaler();                                     // reader, once per kernel per NEO
for (uint32_t block_idx = 0; block_idx < num_blocks_this_core; ++block_idx) {   // = rounds, one tile-row per NEO
    load_row_block(block_idx);        // reader: Wt input tiles -> cb_input_tiles (implicit sync)
    load_gamma_block(block_idx);      // reader: Wt gamma tiles, gamma_block_tiles per barrier -> cb_gamma_tiles
    sum_squares_block(block_idx);     // compute: Σ_w x_w² in DEST over the resident row -> cb_row_stat
    reduce_row_block(block_idx);      // compute: SUM over the 32 columns -> cb_row_sum
    inv_rms_block(block_idx);         // compute: rsqrt(sum · (1/W) + eps) -> cb_row_stat
    normalize_block(block_idx);       // compute: x · inv_rms (col bcast) · gamma (row bcast) -> cb_output_tiles
    store_row_block(block_idx);       // writer: Wt tiles -> output (implicit sync)
}
```

| Operation | Block shape | Resident across it | Intended frequency of fixed costs |
|-----------|-------------|--------------------|-----------------------------------|
| `prepare_scaler` | 1 tile per NEO | stays resident in `cb_scaler` for the whole kernel; compute pops it after its last round | once per kernel |
| `load_row_block` | 1 × Wt tiles | the row stays in `cb_input_tiles` through `sum_squares_block` and is consumed by `normalize_block` | no barrier (implicit sync, one tagged read per tile); the reader issues round k+1's reads for gamma block j right after pushing round k's gamma block j (interleaved, so the next row's reads fill slots freed by pass 2) |
| `load_gamma_block` | 1 × Wt tiles in blocks of `gamma_block_tiles` | — | one `reserve_back` / barrier / `push_back` per gamma block (Wt / `gamma_block_tiles` per row); one 64-B read + one 32-B local copy per tile |
| `sum_squares_block` | 1 × Wt tiles → 1 tile | input row held (cumulative wait, no pop) | one `pack_init(cb_row_stat)`, one chain init, one DEST acquire/pack per row; starts on the first landed tile (cumulative wait), not after the whole row |
| `reduce_row_block` | 1 tile → 1 tile | scaler held | one reduce init/uninit per row (the helper re-aims the packer itself) |
| `inv_rms_block` | 1 tile → 1 tile | — | one `pack_init(cb_row_stat)`, one chain init per row |
| `normalize_block` | 1 × Wt tiles | `inv_rms` held for the whole row (Upfront / AtEnd) | one `pack_init(cb_output_tiles)`, one chain init per row; the input is popped per tile |
| `store_row_block` | 1 × Wt tiles | — | no barrier (implicit sync); the tag reset once at kernel end |

`compute_kernel_hw_startup` once at the top of the compute kernel. The reader's and the writer's last statement hands the tag back (`noc_async_read_set_trid(0, noc.get_noc_id())` / `noc_async_write_set_trid(0, noc.get_noc_id())`, `dataflow_api.h:2558,2579`).

### Perf lamps

| Lamp | Why the default may be wrong here | Nearby alternative to measure |
|------|-----------------------------------|-------------------------------|
| gamma multiply on the SFPU | `normalize_block` applies gamma through `UnaryBcast<Row>` + SFPU `MulBinary`; the catalog (`compute_fusion`) measured an SFPU multiply at 0.58× of the FPU's | two FPU multiplies with an L1 intermediate: `x · inv_rms` (Col bcast) → a `cb_scaled` block of k tiles, then `cb_scaled · gamma` (Row bcast FPU) → out; costs one ring of `2k` tiles per NEO and two `pack_init` per block |
| reduce and finalize as two calls | `cb_row_sum` and a pack/unpack per row exist only to keep the post-op out of the reduce | `reduce<…>(…, post_reduce_op)` doing `mul_unary_tile`, `fill_tile`, `add_binary_tile`, `rsqrt_tile` on DEST 0/1 inside the reduce, dropping `cb_row_sum` |
| FPU reduce in tf32 | the 32-column collapse unpacks the fp32 Σx² tile through SrcA (19 bits) | the SFPU collapse (`sfpu_reduce<SUM, Float32, ROW>`, exact in fp32 on the simulator) as the precision alternative (`row_reduce_accumulate`: same speed, more accurate) |
| overlap (`IN_DEPTH_ROWS` = 1) | with more than one round per NEO, pass 1 of row k+1 can only start on tiles pass 2 of row k has freed | `IN_DEPTH_ROWS` = 2 where `2 · Wt · C_eff · tile_bytes` fits the ring cap |
| grid synchronization / occupancy | the page's rule deals whole rounds of C rows to fewer clusters; with `num_tile_rows < C · cores`, spreading rows one per cluster at C = 1 engages more DM harts and NoC endpoints for the same NEO count | `C_eff` = smallest c with `ceil(rows / c) ≤ cores` |
| thread plan (timed backend only) | (4,4,2) is argued from the bound, not measured; this backend has no clock | (1,1,1), (2,4,2) and (4,4,2) in model cycles on `ttsim-perf` |
| `gamma_block_tiles` = up to 16 | 64-B reads are per-transaction bound; the catalog's sweet spot is 4–8 per barrier | 4 and 8 |

## Dataflow Strategy

| Stage | Format | Mechanism | Notes |
|-------|--------|-----------|-------|
| input DRAM/L1 → `cb_input_tiles` | bf16 tiles (2,048 B) | reader, implicit sync: `noc.async_read<NocOptions::TXN_ID>(acc_input, cb_input_tiles, {.page_id = row · Wt + w}, {})` (`noc.h:252`); page order `row · Wt + w` | L1 and DRAM inputs alike, through the tensor's accessor |
| weight → `cb_gamma_tiles` | bf16, one 64-B page per tile column → row 0 of faces 0 and 1 of a 32×32 entry | reader, explicit sync: `reserve_back(gamma_block_tiles)`; per tile one `noc.async_read<NocOptions::TXN_ID>` of the whole 64-B page to entry offset 0 with `{.trid = 0}`; `async_read_barrier<TXN_ID>({.trid = 0})`; per tile copy bytes 32..63 to entry offset 512 (face 1, row 0); `push_back(gamma_block_tiles)` | bytes 0..31 already sit in face 0 row 0; the rest of the entry is don't-care for a row broadcast (row 0 of faces 0/1 only) |
| reduce scaler → `cb_scaler` | bf16, 1.0 in the reduce layout | reader, explicit sync: `dataflow_kernel_lib::calculate_and_prepare_reduce_scaler<cb_scaler, PoolType::SUM, ReduceDim::REDUCE_ROW>(scaler)` once per NEO it feeds | SUM scaler 1.0 is exact in bf16; 1/W is applied in fp32 by `inv_rms_block`, not by the scaler |
| compute rings | `cb_row_stat`, `cb_row_sum` Float32 (fp32 DEST); compute both produces and consumes | per-NEO slices of STRIDED rings | `unpack_modes` lists both as `UnpackToSrc` (a 32-bit ring with `enable_32_bit_dest` must name its mode) |
| `cb_output_tiles` → output | bf16 tiles | writer, implicit sync: `noc.async_write<NocOptions::TXN_ID>(cb_output_tiles, acc_output, {}, {.page_id = row · Wt + w})` | a padded-round row is stored again, same bytes, same pages |

TARGET axes as regime rows:

| TARGET axis value | Cost class | How |
|-------------------|------------|-----|
| `memory_config` DRAM / L1 (interleaved) | built in Phase 0 | placement only: the accessor reads either, and the output is allocated from the input's spec |
| `sharding` other than interleaved | not in TARGET | — |
| `dtype` float32 | knob-turn, plus `row_streaming` for Wt ≥ 256 | `tile_bytes` 4,096 changes `c_fit`; pages already follow DEST width |

## Work Distribution

| Field | Value |
|-------|-------|
| Work unit | a tile-row block: `rows_per_block` (1) × `block_wt` (Wt) tiles, owned by one NEO |
| Grid | `device.compute_with_storage_grid_size()` (8×4 = 32 on this target); never a literal |
| Per-core work | `num_rounds = ceil(num_tile_rows / C_eff)`; `ttnn.split_work_to_cores(grid, num_rounds, row_wise=True)` deals whole rounds; a core with `r` rounds owns `min(r · C_eff, num_tile_rows − row_start)` tile-rows from `row_start` (the `split_rows` pattern of `toy_row_passes_program_artifacts.py`). RT args: `rows_this_core`, `row_start` (reader, writer), `rows_this_core` (compute) |
| Remainder | `ceil` everywhere: `Wt = padded_shape[-1] // 32` (tile-padded per image), `num_tile_rows = buffer_num_pages() // Wt` (= `prod(shape[:-2]) · ceil(H/32)`, never `floor(N·H/32)`); only the last round of the last core can be short; its missing NEOs recompute that round's NEO-0 row (at most `C_eff − 1` rows in the whole op) |
| Bound | **compute** — per tile: two HiFi4 FPU multiplies (4 fidelity phases each, one accumulating into DEST), a broadcast copy and an SFPU fp32 multiply, plus a reduce, an SFPU finalize and an rsqrt per row; against 2 KiB in, 2 KiB out and 64 B of gamma per tile |
| Thread plan | `THREAD_PLAN = (4, 4, 2)` (host constant, `rms_norm_program_artifacts.py`); per call `(R_eff, C_eff, W_eff)` as in the Blocking Model; the counts are CT args (`reader_threads`, `compute_threads`, `writer_threads`) and the kernels size loops from them and `get_my_thread_id()` |
| Unit dealt to compute threads | a tile-row (larger than a ring entry): every NEO takes the same entries per round (Wt input, Wt gamma, Wt output); the last round is padded with recomputed rows; the host deals whole rounds of `C_eff` rows to clusters |
| Tests the plan needs | (1) **threads ran**: a test-only hook (module constant `_TEST_TAG_THREADS` in the program-artifacts module, compile define `RMS_NORM_TAG_THREADS`) makes NEO `t` multiply its pass-2 output by `t + 1`; on a shape with ≥ 4 tile-rows per cluster at C_eff = 4 (e.g. (1,1,2048,256)), the test checks that tile-row `row_start + k·4 + t` equals `(t + 1) ·` reference. (2) **sessions**: in one device session, the op after another program (e.g. `ttnn.add`), and the op followed by `ttnn.to_layout(output, ttnn.ROW_MAJOR_LAYOUT)`. (3) **regime-pinned**: one case each for C_eff = 1 ((1,1,32,2048)), C_eff = 2 by row count ((1,1,64,128)), C_eff = 2 by the ring cap ((1,1,128,4096)), C_eff = 4 ((2,4,128,512)); and one padded-round case (3 tile-rows: (1,1,96,128) → C_eff = 2, one recomputed row). The reduce helper has not run under a plan before (target page); (3) runs it at C = 1, 2 and 4. |

Ring protocols (`Sync` column below): input and output rings are implicit sync (one tagged transfer per entry, no reserve/push/wait/pop on the DM side); gamma and scaler are explicit sync (the reader writes or assembles the entries), so the reader's hw config lists `disable_dfb_implicit_sync_for=["gamma", "scaler"]` and every gamma read carries `{.trid = 0}` with a barrier on the same id (`reader_mixed.cpp` pattern).

## Key Risks and Gotchas

| Risk | Why it bites here | Mitigation in this design |
|------|-------------------|---------------------------|
| pack target | three of the four compute operations pack into `cb_row_stat` / `cb_row_sum` and the fourth into `cb_output_tiles` | `pack_init(<ring>)` before `sum_squares_block`, `inv_rms_block` and `normalize_block`; the reduce re-aims itself |
| input ring not exactly whole rows | indexed pass-1 access and implicit-sync batches both assume row-aligned slots | capacity per NEO = `IN_DEPTH_ROWS · Wt` exactly, derived from `Wt`, never rounded up |
| ring extent cap | Wt · C · 2,048 > 1,048,560 for Wt ≥ 128 at C = 4 (W = 4096 and 8192 are Phase 0 shapes) | `C_eff ≤ c_fit`; the extent is asserted on the host before building the program |
| DEST start value for `DestAccumulation::WholeShape` on Quasar | the first accumulating multiply of a row adds onto whatever DEST holds | covered by every cell (random data); the padded-round test runs two rounds on one NEO; if the first row reads stale DEST, seed with a non-accumulating `square` of tile 0 into D0 inside the same chain call |
| reduce helper indexed policies under a plan | not used | only `WaitAndPopPerTile` on a one-tile block |
| 32-bit rings need an explicit unpack mode | `enable_32_bit_dest` with a Float32 ring fails validation without one | `unpack_modes = {cb_row_stat: UnpackToSrc, cb_row_sum: UnpackToSrc}` (FPU consumers: reduce and the Col broadcast need SrcA/SrcB) |
| gamma assembly | the 64-B page lands as face 0 rows 0–1; the row broadcast reads row 0 of faces 0 and 1 | one 32-B local copy (+32 → +512) per entry after the barrier; random gammas in every cell catch a wrong layout (R5) |
| tag register | implicit-sync kernels leave a ring's transaction id in the hart's tag register | the tag reset as the last statement of the reader and the writer; the session tests |
| fidelity | set on every compute kernel | `ComputeHardwareConfig(fpu_math_fidelity=cfg.math_fidelity, enable_32_bit_dest=cfg.fp32_dest_acc_en, sfpu_precision_mode=Approximate if cfg.math_approx_mode else Precise, unpack_modes=…)`, built from the normalized `ttnn.ComputeConfigDescriptor` (R4: a device config is read by attribute, never refused for its type) |
| scaler ring never drained | `reduce()` waits on the scaler but never pops it (`reduce_helpers_compute.hpp:39-41`) | compute pops `cb_scaler` once after its last round |
| h_non_aligned padding rows | the tile's padding rows go through every pass | rows are independent: padding stays in padding rows (zero padding gives `rsqrt(eps) · 0 = 0`); only logical elements are compared; nothing is masked in Phase 0 |
| epsilon placement | R7: eps is added to the **mean**, before rsqrt | `inv_rms_block` order: `·(1/W)` then `+eps` then `rsqrt`; `inv_w_bits` from the logical W; covered by the `small_magnitude` regression case |
| DataflowBuffer objects | on Quasar a DataflowBuffer drains when it goes out of scope | one object per ring at kernel scope, passed by reference to every helper |
| validate order | X1 / X2 / R1 / R15 | `memory_config` not None → its axis reads `"other"` and is refused; weight with `shape[-1] != 32` or `numel != ceil(W/32)·32` → `ValueError` (X1); axes from `AXES` (`INPUT_TAGGERS = AXES`), `memory_axes`, the weight and the resolved compute config; anything outside `SUPPORTED` → `NotImplementedError`; then the `c_fit` predicate |
