=== 4. RECOMMENDED COMPOSITION ==============================================================
 cand_recv (compact fold + ONE <1,8> finalize; RC only above BR = 16)
 + sender-side member_pack, bank = BR bf16 one-hot pages, SEED = 0
 + receiver-side recv_unpack, DEST_BATCH = min(BLOCK_ROWS, 8)
Chosen over cand_root because their ROOT timelines are within 1.3% (1732 vs 1709 at the focus)
while cand_recv also multicasts ONE page instead of BLOCK_ROWS -- a writer-side saving this bench
does not measure and does not claim.

=== 5. L1 PER CORE (fp32 tile 4096 B, bf16 tile 2048 B) =====================================
Focus shape (BLOCK_ROWS = 8, GROUP_SIZE = 8):

  cb_row_stat        2*BR = 16 p   65536      16 p   65536
  cb_sum_handoff       BR =  8 p   32768       1 p    4096

  cb_stat_handoff      BR =  8 p   32768       1 p    4096
  cb_stat_mcast_in            --        -       2 p    8192

  TOTAL                            458752            196608
  => the compact layout FREES 256 kB per core.  It does NOT force BLOCK_ROWS down: it REMOVES the
  gather CB's GROUP_SIZE x BLOCK_ROWS term from the descriptor's L1-bound BLOCK_ROWS solve
  (GROUP_SIZE * BLOCK_ROWS pages -> GROUP_SIZE pages), which is the largest BR-scaling CB there is.
  At BLOCK_ROWS = 32 / GROUP_SIZE = 32 the gather goes 4096 kB -> 128 kB.

=== 6. WHOLE-OP EXTRAPOLATION (explicitly extrapolated, NOT measured end-to-end) ============
Focus shape has num_blocks = 4.  Bench baseline 4 x 6398 = 25592 ns against the whole-op peel's
23230 ns of wall for the same chain -- the isolated reconstruction is 10% high (no DM overlap), so
scale by 23230 / 25592 = 0.908:
  candidate root chain  (4 x 1192 + 4 x 540) x 0.908 =  6290 ns   (was 23230)
  sender pack, if FULLY exposed          4 x 421 x 0.908 =  1529 ns
  => 64753 -> 49342 ns (1.31x) fully exposed, 47813 ns (1.35x) if the sender pack hides inside the
     root's 13610 ns gather WAIT (7 of the 8 senders finish pass A before the root does).
NOT banked: the gather ships BLOCK_ROWS x fewer pages, the mcast BLOCK_ROWS x fewer bytes, and the
writer's boot-zeroing of the gather CB becomes unnecessary (every compact position is defined by
construction) -- that zone is 7633 ns but only 1063 ns of wall, so it is deliberately not counted.
Perf 1's extrapolated 1.94x was against the pre-D16 root; against the CURRENT root it is ~1.3x.
