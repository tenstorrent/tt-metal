# Changelog: rms_norm

## Phase 0 — Core Implementation
- **Date**: 2026-09-14
- **What was done**: Initial implementation via incremental pipeline (planner → implementer → verifier). One native `ttnn.generic_op` dispatch per call; three regimes on the same kernels — R1 row split, R2 W-split with root gather + `mcast_pipe` rstd broadcast, R3 zero-copy WIDTH_SHARDED shards (incl. non-rectangular shard grids with passive bounding-box cores and a ragged/padded last shard). Native ROW_MAJOR legs (in-kernel tilize/untilize), TILE or ROW_MAJOR gamma, fp32 intermediates.
- **SUPPORTED at Phase 0**: dtype=[bfloat16, float32], fp32_dest_acc_en=[True], layout=[TILE, ROW_MAJOR], rank=[2, 3, 4], alignment=[tile_aligned], gamma_mode=[gamma, no_gamma], gamma_dtype=[bfloat16, float32, "none"], gamma_layout=[TILE, ROW_MAJOR, "none"], memory_layout=[INTERLEAVED, WIDTH_SHARDED]; EXCLUSIONS=[{float32, fp32_dest_acc_en=False}] (permanent).
- **Accuracy achieved**: PCC ≥ 0.999998 (bf16) / ≥ 0.9999997 (fp32); max_abs_err ≤ 0.045 (bf16) / ≤ 0.033 (fp32); relative RMS 0.0018 (bf16) / 0.0014 (fp32) — measured on 4 shapes × 2 dtypes via `test_rms_norm_precision_baseline.py` (HiFi4, fp32 DEST). Small systematic −0.1 % scale bias from FPU tf32 truncation, documented in `verification_report.md`.
- **Golden suite at Phase 0**: 656 / 656 supported cells passing, 1441 xfail_expected, 9624 invalid_skipped, 1 infeasible_skipped, 0 in any loud category (per `verifier_report.json`); whole golden directory 656 passed / 0 failed / 0 hangs of 11722.
- **Device time (HiFi4 / fp32 DEST, Tracy)**: decode 32×7168 10.3 µs (26 cores); prefill 8192×1024 123.7 µs (130 cores); prefill 8192×7168 658 µs (120 cores); WIDTH_SHARDED 32×2048 / 8 cores 5.7 µs.
- **Issues encountered**: (implementer) gather/combine extent had to be `num_partials` (active shards), not the mcast-rectangle area — non-rectangular shard grids summed never-written slots; CB budget bounded by the largest contiguous free L1 block to avoid CB/L1 clashes. (verifier) ragged/padded last WIDTH shard was refused → implemented natively with a strided in-shard walk; writer mcast arg bases were duplicated literals → derived from `McastArgs` offsets and list lengths; the tile-alignment gate was a `ValueError` invisible to the registry → `alignment` tagger + SUPPORTED axis (typed refusal); design doc's stale `num_w_splits` gather sizing corrected.
- **Tests added**: `test_rms_norm.py` (acceptance, 59), `test_rms_norm_perf_shapes.py` (4 LLM shapes for `--profile`), `test_rms_norm_precision_baseline.py` (8), `test_rms_norm_ragged_width_shard.py` (6, regime-pinned). Acceptance directory: 77 passed (`--dev --run-all`).
