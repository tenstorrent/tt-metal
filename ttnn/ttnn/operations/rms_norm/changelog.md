# Changelog: rms_norm

## Phase 0 — Core Implementation
- **Date**: 2026-09-14
- **What was done**: Initial implementation via incremental pipeline (planner → implementer → verifier). One native `ttnn.generic_op` dispatch per call; three regimes on the same kernels — R1 row split, R2 W-split with root gather + `mcast_pipe` rstd broadcast, R3 zero-copy WIDTH_SHARDED shards (incl. non-rectangular shard grids with passive bounding-box cores and a ragged/padded last shard). Native ROW_MAJOR legs (in-kernel tilize/untilize), TILE or ROW_MAJOR gamma, fp32 intermediates.
- **SUPPORTED at Phase 0**: dtype=[bfloat16, float32], fp32_dest_acc_en=[True], layout=[TILE, ROW_MAJOR], rank=[2, 3, 4], alignment=[tile_aligned], gamma_mode=[gamma, no_gamma], gamma_dtype=[bfloat16, float32, "none"], gamma_layout=[TILE, ROW_MAJOR, "none"], memory_layout=[INTERLEAVED, WIDTH_SHARDED]; EXCLUSIONS=[{float32, fp32_dest_acc_en=False}] (permanent).
- **Accuracy achieved**: PCC ≥ 0.999998 (bf16) / ≥ 0.9999997 (fp32); max_abs_err ≤ 0.045 (bf16) / ≤ 0.033 (fp32); relative RMS 0.0018 (bf16) / 0.0014 (fp32) — measured on 4 shapes × 2 dtypes via `test_rms_norm_precision_baseline.py` (HiFi4, fp32 DEST). Small systematic −0.1 % scale bias from FPU tf32 truncation, documented in `verification_report.md`.
- **Golden suite at Phase 0**: 656 / 656 supported cells passing, 1441 xfail_expected, 9624 invalid_skipped, 1 infeasible_skipped, 0 in any loud category (per `verifier_report.json`); whole golden directory 656 passed / 0 failed / 0 hangs of 11722.
- **Device time (HiFi4 / fp32 DEST, Tracy)**: decode 32×7168 10.3 µs (26 cores); prefill 8192×1024 123.7 µs (130 cores); prefill 8192×7168 658 µs (120 cores); WIDTH_SHARDED 32×2048 / 8 cores 5.7 µs.
- **Issues encountered**: (implementer) gather/combine extent had to be `num_partials` (active shards), not the mcast-rectangle area — non-rectangular shard grids summed never-written slots; CB budget bounded by the largest contiguous free L1 block to avoid CB/L1 clashes. (verifier) ragged/padded last WIDTH shard was refused → implemented natively with a strided in-shard walk; writer mcast arg bases were duplicated literals → derived from `McastArgs` offsets and list lengths; the tile-alignment gate was a `ValueError` invisible to the registry → `alignment` tagger + SUPPORTED axis (typed refusal); design doc's stale `num_w_splits` gather sizing corrected.
- **Tests added**: `test_rms_norm.py` (acceptance, 59), `test_rms_norm_perf_shapes.py` (4 LLM shapes for `--profile`), `test_rms_norm_precision_baseline.py` (8), `test_rms_norm_ragged_width_shard.py` (6, regime-pinned). Acceptance directory: 77 passed (`--dev --run-all`).

## Refinement 1 — Numerical configurability: 16-bit DEST accumulation + bfloat8_b
- **Date**: 2026-09-14
- **What was done**: Knob-turn, zero compute-kernel changes (the helper-based compute kernel reconfigures formats from the CB descriptors). `rms_norm_program_descriptor.py` gained the single source of truth `acc_dtype_for(fp32_dest_acc_en)` / `acc_tile_bytes_for(...)` (fp32 DEST → `Float32` 4 KiB pages, 16-bit DEST → `Float16_b` 2 KiB pages); every accumulated-intermediate CB (`cb_sumsq_partial`, `cb_partial_collapsed`, `cb_gather`, `cb_rstd_handoff`, `cb_rstd`, `cb_normed`), `Footprint.per_block`, `derive_blocking` (new `fp32_dest_acc_en` parameter) and the writer's gather/mcast payload stride (named CT `ACC_TILE_BYTES`, was `P32_BYTES`) derive from it — the collective payload halves under 16-bit DEST. The `cb_normed`/`cb_gamma_sticks` alias is now sized `max(B·Wc·T_acc, Wc·T_g)` rounded to both page sizes (under 16-bit DEST an fp32 ROW_MAJOR gamma's start-up stick block is larger than the normed block at B = 1) and priced in `Footprint.fixed` (`gamma_rm`). Element bytes are only read on the stick paths (block-float tensors are TILE-only). `SUPPORTED`: `dtype` and `gamma_dtype` += `bfloat8_b`, `fp32_dest_acc_en` += `False`; `EXCLUSIONS` unchanged (`{float32, False}` permanent). `l1_ledger.md` page-format column now states "follows the DEST width" per accumulated row (`T_acc` symbol); `op_design.md` §H0/H1 and the support table updated.
- **Accuracy achieved** (reference = fp32 RMSNorm of the dtype-rounded device inputs): bf16 / 16-bit DEST / HiFi2 (the perf-flagged config) PCC ≥ 0.99998, rel-RMS 0.0056–0.0072 on all 8 matrix shapes incl. R2 `(1,1,64,12288)` and decode `(1,1,32,7168)` (26 partials: PCC 0.999984, rel-RMS 0.0065); bf8b input + bf8b gamma PCC ≥ 0.99995, rel-RMS ≤ 0.011 (HiFi4, either DEST width); WIDTH_SHARDED R3 `(1,1,32,2048)`/8 cores bf16 16-bit 0.0066–0.0071, bf8b 0.0103–0.0105; ROW_MAJOR x + ROW_MAJOR fp32 gamma at 16-bit DEST 0.0062. Full precision matrix (8 shapes × {bf16, fp32, bf8b} × {HiFi4, HiFi2, LoFi} × {fp32, 16-bit DEST} × {rand, randn}): 240/240 at PCC ≥ 0.99, worst PCC 0.99971 (bf8b LoFi), worst rel-RMS 0.043 (fp32 LoFi) — the DEST width moves the error by < 10 % (bf16 max rel-RMS 0.0376 at 16-bit vs 0.0403 at fp32 DEST); fidelity dominates. Table: `tests/ttnn/unit_tests/operations/rms_norm/precision_matrix_results.md`.
- **Golden test progress**: whole golden directory 1708 passed / 388 xfailed / 9626 invalid-skipped / 0 failed / 0 xpass (Phase 0: 656 passing) — every `fp32_dest_acc_en=False`, `bfloat8_b` and `gamma_dtype=bfloat8_b` cell incl. the 12 `_PERF_BASE` and 24 × 8 resilience loose cases (ROW_MAJOR at 16-bit DEST included). Acceptance directory: 81 (prior files) + 11 + 240 new, all green.
- **Device time (post-R1 baseline for Refinement 2, Tracy, one fresh run)**: `(1,1,32,7168)` bf16 / HiFi2 / 16-bit DEST / bf16 TILE gamma: **9208 ns** on 26 cores (Phase 0 corner: 10288 ns). Already under the clock-unscaled 14894 ns R2 goal; R2 re-measures and clock-scales.
- **Issues encountered**: none on device — every named cell passed on the first run. One self-caught host bug before it could bite: the `cb_gamma_sticks`-on-`cb_normed` alias assumed `T_g ≤ T_acc`, which 16-bit DEST + fp32 ROW_MAJOR gamma violates at B = 1 (fixed by sizing the shared CB as the max demand; pinned by `test_rms_norm_row_major_16bit_dest[...-fp32_gamma]`).
- **Tests added**: `test_rms_norm_precision_matrix.py` (240 cells + results file writer), `test_rms_norm_numeric_config.py` (11: R3 sharded bf16/bf8b × both DEST widths, ROW_MAJOR at 16-bit DEST with bf16/fp32 RM gamma on R1/R2, bf8b no-gamma, `{float32, False}` refusal), `test_rms_norm_perf_shape_flagged_config` (4 shapes at the perf-flagged config, profile by node id). Probes `probes/probe_012.py`, `probe_013.py`.
