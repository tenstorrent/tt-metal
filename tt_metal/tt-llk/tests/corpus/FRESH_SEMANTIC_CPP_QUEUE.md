# Next fresh semantic-C++ queue

This queue ranks the next ten Blackhole corpus conversions after the measured
Welford, Reduce-SDPA, binary-broadcast, TTNN Where, and MulInt32 lanes.  It is
an explicit row-by-row review, not a basename or substring classification.

A candidate is accepted as “fresh semantic C++” only when the algorithmic body
uses typed SFPI values and operations.  Physical LREG numbers, `TTI_*`, raw
`.ttinsn`, replay commands, load-macro configuration words, and a copied
handwritten issue order are forbidden in the generated body.  Typed wrappers
may name architectural boundaries (Dst addressing, counters, transpose, or
paired state), but the selector must expose the optimizable dataflow between
them.  Every silicon comparison follows compile -> paired correctness -> CRAQ
where supported -> serialized scoped device cycles.

## Execution order

Run ranks 1--4 as the first macro-formation batch because they share the same
compiler investment and have the clearest cycle upside.  In parallel, use
rank 10 as the clean semantic-source control and rank 7 as the typed integer/
condition-code API probe.  Start rank 5 only after the TopK multi-result work
establishes sound transpose state.  Ranks 8--9 should share one typed-integer
API plan; if either requires hardcoded LREGs, stop and fix the IR rather than
accepting a nominal selector.

No item is a win until the paired selector passes its complete correctness
contract.  PCC is never sufficient by itself: float lanes also retain their
element/edge contract, while integer and index-bearing lanes are exact.
