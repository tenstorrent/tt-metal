# Analysis tools used on 2026-10-08 (experiment branch, not for merge)

- `vrun.sh <name> <tree> <test id> [ENV=VAL ...]`: one Versim run with a VCD in its own worktree.
- `ext.py <vcd> <out.txt>`: DEST crossbar, packer L1 writes, per-TRISC fetch/icache/mispredict and NoC L1 signals; then `to_cycles.py` (from `nstojictt/versim-m1-repro`) makes one row per clock.
- `tilean.py <run.cyc>`: per-tile packer refusals, L1 write waits, code-line reads (tile = 32 packer-0 grants).
- `ican.py <run.cyc> <trisc>`: instruction-cache line reads per loop pass and the sets they map to.
- `nocan.py <run.cyc>`: NoC reads of L1 inside the packing window.
- `card_stress.sh`, `advan.py`, `advrt.py`: card stress runs (each `LLK_*` switch) and their comparison (values that move > 2%).
- `cqan.py`, `mmids.py`, `vcdvars.py`: small helpers (compare runs, map math_matmul ids to configs, list VCD signals).
