## tilize.init

Rearranges a row-major input into tiles. The unpacker rearranges (tileize mode), math copies srcA to DEST (datacopy A2D), the packer writes tiles. On Blackhole the packer runs in Tilize mode to undo a row swizzle, except for 8-bit inputs (Int8, UInt8, Fp8_e4m3, Lf8), which do not need it. Thread handoff (math_wait_for_dest_available, dest_section_done, packer_wait_for_math_done) is called by tilize_block but is not part of this contract.

Operands: `in0` on srcA, `out`
