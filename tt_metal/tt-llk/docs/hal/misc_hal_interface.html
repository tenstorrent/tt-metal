hal::misc

Blackhole Miscellaneous Instruction HAL

Thin typed wrappers for the standalone Tensix instructions that belong to no engine family.

Architecture Blackhole Header hal/misc.h Instructions RESOURCEDECL · FLUSHDMA · RSTDMA · TBUFCMD
Include the package#include "hal/misc.h"

Quick start

#include "hal/misc.h"

// Declare that MOP-expanded instructions (class 13) touch everything.
constexpr hal::misc::ResourceDeclaration mop_uses_all {
    .instruction_class = 13,
    .resources         = 0x1FF,
};
hal::misc::run<mop_uses_all>();   // RESOURCEDECL

hal::misc::flush_tdma<hal::misc::FlushScope::Packer>(); // FLUSHDMA

Operations

MemberInstructionNotes
ResourceDeclarationRESOURCEDECLPersistent AutoSync class declaration; MOP/replay expansions inherit the parent's class; per-class defaults live in assembly.yaml.

None of these operations has an LLK call site today; they exist so the ISA surface is covered with the caveats made explicit.
