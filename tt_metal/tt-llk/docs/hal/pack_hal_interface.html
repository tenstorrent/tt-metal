Quick start

#include "hal/pack.h"
#include "hal/utils/address_modifier.h"

// Configure two distinct ADDR_MOD_PACK sections in one grouped CFG operation.
constexpr hal::pack::AddressModifier step_rows {
    .selection       = hal::cfg::Sec::S0,
    .source_row      = {.step = 1},
    .destination_row = {.step = 1},
};
constexpr hal::pack::AddressModifier advance_face {
    .selection       = hal::cfg::Sec::S1,
    .source_row      = {.clear = true},
    .destination_row = {.clear = true},
    .source_face     = {.step = 1},
};
hal::pack::configure_address_modifiers<step_rows, advance_face>();

// One packer data transfer appending to the current output row (untilize-style).
constexpr hal::pack::DataTransfer face_transfer {
    .address_modifier = ADDR_MOD_0,
    .interfaces       = 0b0101,           // Dest-read interfaces 0 and 2
    .concatenation    = hal::pack::Concatenation::Append,
};
hal::pack::run<face_transfer>();

// The transfer that closes a tile: strided Dest walk, zero-pad the final rows to 16 datums.
constexpr hal::pack::DataTransfer close_tile {
    .address_modifier = ADDR_MOD_1,
    .dest_access      = hal::pack::DestAccess::Strided,
    .padding          = hal::pack::RowPadding::FinalOnly,
    .alignment        = hal::pack::PaddingAlignment::To16Datums,
    .boundary         = hal::pack::TileBoundary::Last,
};
hal::pack::run<close_tile>();

hal::pack::flush_write_aligners(); // degenerate no-data PACR (Flush)

Functional model

Blackhole has one packer with four Dest-read interfaces; that vocabulary — not Wormhole's four packers — is this interface's language. A DataTransfer selects the participating interfaces (a zero mask means all four; under DatumOverride::Zero a zero mask instead activates the documented special mode), the Dest walk order, row padding, concatenation into the output row, and whether the transfer closes the tile. Contexts resolve directly from the descriptor or from the hardware's RTL-flop counters (ContextControl). The hard span rules live in the packer CFG state, outside this instruction.

AddressModifier describes how one PACR selection updates the packer's source and destination row/face counters. configure_address_modifiers composes all fields for each selected 16-bit ADDR_MOD_PACK word, then emits one immediate SETC16 per distinct selection.

TileBoundary::Last and flush_write_aligners() are deliberately separate: one is a mode of a data transfer, the other is a degenerate no-data instruction — the same split as hal::unpack's canonical descriptors.

Packer address modifiers

struct CounterUpdate
{
    std::uint32_t step = 0;
    bool clear = false;
};

struct AddressModifier
{
    hal::cfg::Sec selection = hal::cfg::Sec::S0;
    CounterUpdate source_row {};
    CounterUpdate destination_row {};
    CounterUpdate source_face {};
    CounterUpdate destination_face {};
};

template <AddressModifier... Modifiers>
void configure_address_modifiers();

selection accepts Sec::S0 through Sec::S3. Row steps are four-bit values; face steps are one-bit values. Clear applies after the PACR transfer that selects the modifier. The compile-time interface rejects an empty list, out-of-range fields, and repeated selections; repeating a selection would otherwise request multiple writes to the same CFG word.

DataTransfer (PACR)

struct DataTransfer
{
    std::uint8_t address_modifier      = 0;  // 2-bit ADDR_MOD_PACK index
    ContextControl context             = ContextControl::Direct;
    std::uint8_t configuration_context = 0;  // [0, 3]; Direct context only
    std::uint8_t counter_context       = 0;  // [0, 2]; used with override_thread_id
    bool override_thread_id            = false;
    std::uint8_t interfaces            = 0;  // 4-bit Dest-read interface mask; 0 = all
    DatumOverride datum_override       = DatumOverride::None;  // ZeroWrite
    DestAccess dest_access             = DestAccess::RowMajor; // or Strided (0, 8, 16, 24)
    RowPadding padding                 = RowPadding::None;
    PaddingAlignment alignment         = PaddingAlignment::PerRow;
    Concatenation concatenation        = Concatenation::NewRow;
    TileBoundary boundary              = TileBoundary::NotLast;

    constexpr std::uint32_t get_operation() const;
};

RowPadding and PaddingAlignment compose the hardware's 3-bit RowPadZero field; 16-datum alignment requires a padding selection. Every descriptor offers get_operation() for MOP and replay embedding, plus compile-time run<Op>() and runtime run(op).

RegisterWriteValue / RegisterWrite (PACR_SETREG)

struct RegisterWriteValue { bool high_half; std::uint16_t value; };   // stage one 16-bit half
struct RegisterWrite      { std::uint8_t address_slot; std::uint8_t stream_id; }; // ordered write

Two-phase pipeline-ordered MMIO write through the packer: stage each 16-bit half of the value, then issue the write. The target address forms as {0xFFB, REG_ADDR[11:10], stream_id, REG_ADDR[9:0], 2'b00} from one of four preprogrammed TDMA address slots. No LLK call site exists; the stall-disable chicken bit is never encoded.
