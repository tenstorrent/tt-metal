namespace hal::cfg

Blackhole CFG HAL

A typed, compile-time interface for reading and programming Blackhole thread and state configuration registers without copying raw addresses, masks, or shifts into kernel code.

Architecture Blackhole Language C++17 Public header hal/cfg.h Namespace hal::cfg
Include the complete public interface #include "hal/cfg.h"

The API combines a generated Field descriptor with an Access policy. The descriptor identifies the register file, address, repeated sections, bit shift, and mask. The access policy selects RISC MMIO, the Tensix Configuration Unit, or the Tensix Scalar Unit. Both are template arguments, so selection adds no runtime dispatch.

The rule of thumb

Name the field, choose Access::MMIO or Access::TensixCfgUnit, select its Sec, and pass an unshifted value. Select Access::TensixScalarUnit only for an explicit GPR-to-THCON REG2FLOP transfer. Use set() to group assignments automatically by physical word, and from_gpr() to place complete-word transfers in the same ordered call.

Quick start

A minimal runtime field write needs an access path, a generated field, an explicit section, and a value.

#include "hal/cfg.h"

void configure(const std::uint32_t enable)
{
    // Mixed path: compile-time field, runtime value
    hal::cfg::write<
        hal::cfg::Access::TensixCfgUnit,
        hal::cfg::AluAccCtrl::Fp32_enabled,
        hal::cfg::Sec::S0>(enable);
}
Runtime value

Write one field

// Mixed path: compile-time field, runtime value
cfg::write<
    cfg::Access::TensixCfgUnit,
    cfg::AluAccCtrl::Fp32_enabled,
    cfg::Sec::S0>(enable);

The descriptor supplies the address, mask, and shift.

Runtime result

Read one field

// Compile-time-selected MMIO path
const auto seed = cfg::read<
    cfg::Access::MMIO,
    cfg::PrngSeed::Seed_Val,
    cfg::Sec::S0>();

The returned value is masked and shifted down to bit zero.

A realistic grouped write

Fields across several physical words can be described together. The HAL groups assignments by register file and address, checks mask compatibility at compile time, and emits one logical update per group. 

namespace cfg = hal::cfg;

// Mixed path: compile-time fields, runtime values, multiple words
cfg::write<cfg::Access::TensixCfgUnit>(
    cfg::set<cfg::AluAccCtrl::INT8_math_enabled, cfg::Sec::S0>(int8_mode),
    cfg::set<cfg::StaccRelu::ApplyRelu, cfg::Sec::S0>(relu_mode),
    cfg::set<cfg::AluAccCtrl::Fp32_enabled, cfg::Sec::S0>(fp32_mode),
    cfg::set<cfg::AluAccCtrl::SFPU_Fp32_enabled, cfg::Sec::S0>(fp32_mode));

Combine field updates and GPR transfers

Use from_gpr() when one ordered Configuration Unit sequence contains both field updates and complete-word WRCFG transfers. Consecutive set() operations are grouped at compile time; each GPR transfer is an ordering barrier.

// Mixed path: compile-time destinations, runtime values
cfg::write<cfg::Access::TensixCfgUnit>(
    cfg::set<cfg::AluFormatSpecReg1::SrcB, cfg::Sec::S0>(dst_format),
    cfg::set<cfg::Thcon[cfg::Reg0].TileDescriptor.InDataFormat, cfg::Sec::S1>(src_format),
    cfg::from_gpr<cfg::Thcon[cfg::Reg3].Base_address, cfg::Sec::S1>(
        cfg::gpr<p_gpr_unpack::L1_BUFFER_ADDR,
                 cfg::GprTransferSize::Bits32,
                 cfg::WrcfgCompletion::Deferred>()),
    cfg::set<cfg::Thcon[cfg::Reg2].Haloize_mode, cfg::Sec::S0>(haloize));

Functional model

address = F.addr32(S);
shift   = F.shamt(S);
mask    = F.mask(S);

// Read one field
result = (read_word(address) & mask) >> shift;

// Preserve unrelated bits in a partial state-CFG write
next_word = (current_word & ~mask) | ((value << shift) & mask);

// Group identity for field assignments
group_key = (register_file, address);

A generated Field resolves the register file, physical address, repeated section, shift, and mask. Access then selects how the logical read or write reaches hardware; there is no runtime dispatch for that selection.

Two register files

RegisterFile::Thread

Thread CFG

  • Private to each Tensix thread.
  • 16-bit physical words.
  • Written by Tensix SETC16.
  • Read by TRISC or BRISC through the CREG-selector MMIO path.
  • A write replaces the complete 16-bit word; bits not supplied are zero.
RegisterFile::State

State CFG

  • 32-bit ALU, PACK, UNPACK, THCON, and global configuration.
  • Accessible through RISC MMIO and Tensix CFG instructions.
  • Partial field writes preserve unrelated bits.
  • Banked blocks use the current thread's active CFG state.

Field descriptors are addresses plus layout

Generated register families expose static constexpr Field members. A final expression such as Thcon[Reg0].TileDescriptor.InDataFormat is a complete descriptor. Callers should not repeat its numeric address, shift, or mask. 

// A nested state-CFG field.
hal::cfg::Thcon[hal::cfg::Reg0].TileDescriptor.InDataFormat

// A repeated thread-CFG field.
hal::cfg::AddrMod[hal::cfg::SrcA].Incr

Section and CFG state are different axes

Sec::S0 does not mean CFG state 0.

Sec selects a repeated descriptor section. The active state-CFG bank is selected independently by CfgStateId::StateID and by the RISC pointer returned from ckernel::get_cfg_pointer().

Types and enums

enum class

Access

enum class Access : std::uint8_t
{
    MMIO,
    TensixCfgUnit,
    TensixScalarUnit
};

MMIO selects the TRISC/BRISC memory-mapped path. TensixCfgUnit selects SETC16, RMWCIB, WRCFG, or RDCFG according to the overload and register file. TensixScalarUnit selects REG2FLOP and is valid only for a GPR-backed write to THCON.

// Mixed path: compile-time access and field, runtime value
write<
    Access::TensixCfgUnit,
    AluAccCtrl::Fp32_enabled,
    Sec::S0>(enabled);
enum class

RegisterFile

enum class RegisterFile : std::uint8_t { Thread, State };

Carried by every generated Field. Callers normally do not choose it directly.

// Compile-time descriptor inspection
static_assert(
    AluAccCtrl::Fp32_enabled.file == RegisterFile::State);
enum class

Sec

enum class Sec : std::uint8_t { S0, S1, S2, S3, S4, S5, S6, S7 };

Selects one repeated section of a descriptor. Public field APIs require an explicit compile-time section, including S0, so every call exposes the complete register-file, field, and field-section selection. Each field declares its supported section count in Field::count; selecting S >= F.count fails compilation.

// Mixed path: compile-time section, runtime value
write<
    Access::TensixCfgUnit,
    Thcon[Reg0].TileDescriptor.InDataFormat,
    Sec::S1>(format);
Sections are field-specific.
// Compile error: Fp32_enabled has count == 1 and supports only S0.
write<
    Access::TensixCfgUnit,
    AluAccCtrl::Fp32_enabled,
    Sec::S1>(enable);

enum class

ThreadTarget

enum class ThreadTarget : std::uint8_t { Current, T0, T1, T2 };

Selects the private thread-CFG bank used by a RISC MMIO read. Current resolves to the issuing TRISC and is invalid for BRISC; BRISC must name an explicit target.

// Compile-time-selected MMIO path
const std::uint32_t state = read<
    Access::MMIO,
    CfgStateId::StateID,
    Sec::S0,
    ThreadTarget::T2>();
enum class

GprTransferSize

enum class GprTransferSize : std::uint8_t { Bits32, Bits128 };

Selects a one-word or four-word WRCFG or REG2FLOP transfer. RDCFG supports Bits32 only.

// Compile-time GPR and transfer-width path
const auto source = gpr<16, GprTransferSize::Bits128>();
enum class

WrcfgCompletion

enum class WrcfgCompletion : std::uint8_t { Wait, Deferred };

Wait emits a spacing NOP immediately after WRCFG and is the safe default: the next instruction must not consume the new configuration. Deferred omits it because the surrounding sequence already provides the required spacing; it does not mean that completion is checked dynamically.

// Compile-time GPR and policy path
const auto deferred_source = gpr<
    16,
    GprTransferSize::Bits32,
    WrcfgCompletion::Deferred>();

Operand and assignment builders

function

gpr

// Compile-time index path
template <std::uint32_t Index>
constexpr auto hal::gpr();

// Runtime index path
constexpr auto hal::gpr(const std::uint32_t index);

// Compile-time index path with CFG policy
template <
    std::uint32_t Index,
    GprTransferSize Size = GprTransferSize::Bits32,
    WrcfgCompletion Completion = WrcfgCompletion::Wait>
constexpr auto gpr();

// Runtime index path with CFG policy
template <
    GprTransferSize Size = GprTransferSize::Bits32,
    WrcfgCompletion Completion = WrcfgCompletion::Wait>
constexpr auto gpr(const std::uint32_t index);

hal::gpr constructs the common index-only GPR identity shared by CFG and address-counter operations. CFG read/write accepts it with the default 32-bit transfer and wait policy. cfg::gpr decorates the same identity when a 128-bit transfer or deferred WRCFG completion is required. Each family offers compile-time and runtime-index forms.

Constraints
  • RDCFG accepts only the compile-time-index form and only Bits32.
  • WRCFG accepts compile-time or runtime indices and either transfer size.
// Compile-time path: 128-bit GPR block with default completion wait
const auto block = gpr<16, GprTransferSize::Bits128>();

// Runtime path: 32-bit GPR selected at runtime
const auto selected = gpr(runtime_gpr_index);
function

set

// Mixed path: compile-time field, runtime value
template <const Field& F, Sec S>
constexpr FieldAssignment<F, S> set(const std::uint32_t value);

// Compile-time path
template <const Field& F, Sec S, std::uint32_t Value>
constexpr ConstantFieldAssignment<F, S, Value> set();

Associates an unshifted runtime or compile-time value with a generated field. It describes an assignment; it does not access hardware by itself.

Runtime values are not range-checked

set<F, S>(value) stores the supplied value and masks it to F when the assignment is encoded. The compile-time set<F, S, Value>() form instead rejects a value that does not fit.

// Mixed path: compile-time field, runtime value
const auto runtime_assignment =
    set<AluAccCtrl::Fp32_enabled, Sec::S0>(fp32_enabled);

// Compile-time path: field and value
constexpr auto constant_assignment =
    set<AluAccCtrl::Fp32_enabled, Sec::S0, 1>();
function

from_gpr

// Compile-time destination with CFG transfer policy
template <const Field& F, Sec S, typename Source>
constexpr GprWrite<F, S, Source> from_gpr(const Source source);

Associates a state-CFG destination with a GPR operand for use inside the heterogeneous write() interface. It describes a complete one-word or four-word WRCFG transfer and does not access hardware by itself.

Constraints
  • F must belong to state CFG and begin at bit zero.
  • S must identify an existing section.
  • The source must come from hal::gpr() or cfg::gpr().
// Compile-time path: destination, GPR, width, and completion policy
const auto base_address = from_gpr<
    Thcon[Reg3].Base_address,
    Sec::S1>(
        gpr<p_gpr_unpack::L1_BUFFER_ADDR,
            GprTransferSize::Bits32,
            WrcfgCompletion::Deferred>());

Read API

function

read — extracted value

// Compile-time-selected path
template <
    Access A,
    const Field& F,
    Sec S,
    ThreadTarget Target = ThreadTarget::Current>
std::uint32_t read();

Reads the containing word through RISC MMIO, applies F.mask(S), and shifts the result down to bit zero.

A
Must be Access::MMIO.
F
A state- or thread-CFG field no wider than one physical word.
S
Explicit repeated section; compilation fails when S >= F.count.
Target
Used only for thread CFG. State reads must leave it at Current.

Thread reads issue a CREG-selector request, wait one cycle, read the response, then extract the field.

// Compile-time-selected MMIO path
const std::uint32_t seed = read<
    Access::MMIO,
    PrngSeed::Seed_Val,
    Sec::S0>();
function

read_word

// Compile-time-selected path
template <
    Access A,
    const Field& Anchor,
    Sec S,
    std::uint32_t WordOffset = 0,
    ThreadTarget Target = ThreadTarget::Current>
std::uint32_t read_word();

// Mixed path: compile-time address, runtime MMIO pointer
template <
    Access A,
    const Field& Anchor,
    Sec S,
    std::uint32_t WordOffset = 0>
std::uint32_t read_word(
    const volatile std::uint32_t* tt_reg_ptr cfg);

Reads a complete physical word at Anchor.addr32(S) + WordOffset. It does not apply the anchor's field mask or shift.

  • State anchors return the complete 32-bit word.
  • Thread anchors return the complete 16-bit word in the low bits.
  • The pointer overload is state-only and reuses a pointer from ckernel::get_cfg_pointer().

A 32-bit transfer replaces one complete state word. A 128-bit transfer replaces four consecutive words starting at a four-word-aligned address.

The common hal::gpr overload is equivalent to cfg::gpr<Index, Bits32, Wait>(). Use cfg::gpr only when CFG-specific transfer or completion policy is needed.

Access::TensixCfgUnit emits TTI_WRCFG for a compile-time GPR index or TT_WRCFG for a runtime index. WrcfgCompletion::Wait emits the default spacing NOP because the instruction immediately after WRCFG must not consume the new configuration. Deferred omits that NOP only when the surrounding sequence supplies the required spacing.

Access::TensixScalarUnit emits TTI_REG2FLOP or TT_REG2FLOP. It accepts only THCON addresses, maps them relative to THCON_CFGREG_BASE_ADDR32, blocks the issuing thread for the Scalar Unit operation, and emits no completion NOP. Prefer it when a GPR-to-THCON transfer should avoid Configuration Unit contention.

Constraints

  • F must be a state field beginning at bit zero.
  • Use a GPR index in [0, 63].

  • For 128-bit WRCFG, the HAL requires the destination to be four-word aligned; current code does not reject a misaligned source, and hardware clears its low two index bits. Pass an explicitly aligned source.

The lambda overload creates a WriteBatch<Access> and passes it to the callable. A RISC batch resolves the current state-bank pointer once. The callable may use ordinary C++ control flow for genuinely runtime-dependent programming.

The pointer overload accepts a bank returned by ckernel::get_cfg_pointer(), allowing several batches in one LLK path to reuse the same resolution.

out(set(...), set(...))Group field assignments by register file and address, then write each group.

Compile-time iteration

template <typename Function>

Bounded, homogeneous descriptor collections expose forEach(function). The call is expanded at compile time; the callback receives an std::integral_constant<std::uint32_t, I> for each valid index. The index can therefore select a generated field used as a non-type template argument and can also index runtime source data.

Function is invoked once for each valid index. Its argument is an std::integral_constant<std::uint32_t, I>, so it can be used as a generated descriptor index and as an index into runtime data.

Same word versus distinct words

// Same physical word: masks and data can be combined.
write<TensixCfgUnit>(set<FieldA, Sec::S0>(a), set<FieldB, Sec::S0>(b));

// Distinct physical words: grouped automatically, one update per address.
write<TensixCfgUnit>(
    set<FieldAtAddressA, Sec::S0>(a),
    set<FieldAtAddressB, Sec::S0>(b));

Fields sharing one byte lane can share one RMWCIB operation. Fields at different addresses cannot be fused by the HAL. Nonadjacent assignments for the same address are composed into one group, and groups follow first-address-seen order.

For a heterogeneous call, this grouping restarts after every from_gpr(). Therefore fields on opposite sides of a WRCFG are deliberately not fused, even if they target the same address.

Ordering and safety

Grouped assignment order

A direct write(set(...), ...) call is declarative. The HAL composes every assignment with the same register file and address, then emits distinct groups in first-address-seen order. For example, arguments targeting A, B, A produce one composed update for A followed by one update for B. Use separate calls for an observable A → B → A transition.

In a heterogeneous write(set(...), from_gpr(...), ...) call, every from_gpr() operation is an ordering barrier. Assignments are grouped only within the consecutive run before or after that barrier, so updates on opposite sides cannot be moved across WRCFG. The GPR transfer's Wait or Deferred policy is preserved exactly.

Keep assignment runs visible while writing heterogeneous calls. 
assignment run [A, B, C]
GPR transfer X
assignment run [D, E]
GPR transfer Y
assignment run [F]

This is how the HAL partitions write(set(A), set(B), set(C), from_gpr(X), set(D), set(E), from_gpr(Y), set(F)). Only assignments inside one displayed run can be grouped by physical word. Do not assume that matching fields on opposite sides of X or Y will fuse, and do not move a field across a GPR transfer merely to improve grouping unless the hardware programming order is known to remain safe.

The expressions that produce C++ function arguments are evaluated before entering write(); do not rely on their evaluation order or place ordering-sensitive side effects inside set() value expressions.

Active state selection

Each Tensix thread selects its state-CFG bank with CfgStateId::StateID. Tensix CFG instructions use that selection. RISC MMIO uses the bank represented by ckernel::get_cfg_pointer(). Keep hardware and software selections synchronized; use ckernel::flip_cfg_state_id() when changing banks.

Safe reconfiguration sequence

  1. Identify the consumer. Determine which EXU observes the field.
  2. Quiesce it. Issue the required STALLWAIT if the EXU may still be active.
  3. Choose the path. Use MMIO for setup, TensixCfgUnit for the normal ordered CFG path, and TensixScalarUnit only for an explicit THCON REG2FLOP transfer.
  4. Honor completion. Leave WRCFG at Wait, or prove that a deferred sequence supplies enough spacing.
MMIO is a sideband path.

RISC MMIO is not ordered with Tensix instructions already in the pipeline. Do not reconfigure a live EXU through MMIO unless the surrounding sequence proves the update is safe.

Serialize RDCFG across threads.

The hardware reference documents that same-cycle RDCFG requests from multiple Tensix threads can lose all but one request. Use synchronization or instruction scheduling to ensure that only one thread issues RDCFG in a cycle.

The HAL cannot infer an EXU barrier from a field name. The caller owns the correct STALLWAIT.
