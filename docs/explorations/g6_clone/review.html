g6_clone

A bit-identical copy of one DRAM-interleaved device tensor into a new tensor of the same shape, dtype, layout and placement (torch.clone semantics).

Model

What it computes

M1  out = new tensor, shape(out) = shape(x), dtype(out) = dtype(x), layout(out) = layout(x), placement(out) = placement(x)
M2  bits(out[i]) = bits(x[i])   for every logical index i
