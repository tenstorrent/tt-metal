The read-only standard-library auditor never imports or executes numerical producers, loads tensors, runs device work, or modifies evidence. It validates the plan's exact Cartesian coverage, label/output/command agreement, selected kernel flags, current source pins and principal coverage, enabled exact preparation, finite metrics and output, reference scope, absent timing, pair contracts and process repetitions. No historical source fallback is allowed. JSON is stdout-only. Exit 0 means the disclosed recorded gates pass, 2 means required evidence is missing, and 1 means a failed gate or malformed plan/record.

python3 -B experiments/sdpa-l2/bfp4-lofi-v2/validate_exp_stress.py --json
python3 -B experiments/sdpa-l2/bfp4-lofi-v2/validate_exp_stress.py \
  --plan experiments/sdpa-l2/bfp4-lofi-v2/exp-stress-long-plan.json --repeat-suffix=-v2 --json

The long-plan commands require their separately supplied plans and do not create them. Shape, core count, sample count and labels come from the selected plan; the explicit 1K/32K/256K coverage contracts prevent a missing configuration from being silently removed. The default repeat rule replaces each planned `-v1` suffix with `-v2`; only the label changes. All recorded result fields other than the label must match across process repetitions, including complete-output hashes and metrics. Equal outputs across separate processes are not a trace-replay claim.

## Important asymmetry in evidence

HiFi2 BF16-KV records explicitly provide original CPU/device input hashes, prepared Q/K/V hashes, input-immutability checks, all-output finite/source-stability booleans and two correctness trace replays. Native/LUT pairs must retain the same original/prepared hashes, source manifests, numerical settings and data layout; only exp-refinement flags may change.

The existing LoFi producer with `iters=0` returns before trace capture. It records **no correctness replay, original/prepared tensor hashes, or original-input immutability gate**. The audit does not fabricate these from the `trace_equal=None` field or the final output reread. It verifies the source-matching finite-output/source-stability assertions and explicit exact preparation counts. Pair input equivalence rests on the same seed/configuration and pinned deterministic input generator, plus the exact value-oracle checks; this is not a measured paired-input bit-hash guarantee. Value equality permits signed-zero equivalence. Separate-process full-output equality strengthens reproducibility without filling those missing fields or claiming unchanged tensors that were never hashed.

Finite aggregate L2 is required, but **there is no common L2 acceptance cutoff**. The producer's `max_l2=1e9` is only an abort-safety setting. Undefined PCC for constant references is permitted. A recorded-gates PASS is not model-quality acceptance, an exp recommendation for all distributions, a long-context performance measurement, or a proof that every compiler/firmware dependency was pinned.
