FSD route: add -x TT_METAL_FACTORY_SYSTEM_DESCRIPTOR_PATH=<fsd.textproto>. On this tree the FSD offline builder falls back to the PSD mapper (#52859), so placement is identical to PSD for a system that fits, and identically UNSAT for one that does not.
