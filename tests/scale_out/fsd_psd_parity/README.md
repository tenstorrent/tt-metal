# Multimesh rank bindings — blitz MGDs on SC36

Rank bindings generated by `tools/scaleout/generate_rank_bindings` (CPU-only mock
discovery / PSD route) for two blitz multimesh MGDs, each run on both SC36 subtorus
systems. Every run passed Mapping validation.

## heterogeneous/

`fabric_cpu_only_blitz_quad_galaxy_4x8_4x4_4x2_10stage_ring_mesh_graph_descriptor.textproto`
— a single 10-stage mixed ring (4 distinct mesh shapes): `4x8` (32 chips), `4x4`
(16), `4x4` split across 2 hosts, and `4x2` (8) stages. **128 chips total (4 galaxies).**

| system | hosts (np) | Mapping | bindings |
|--------|-----------|---------|----------|
| SC36_32x4_revAB_subtorus_aisleC | 20 | OK | `quad_galaxy_..._SC36_32x4_revAB_subtorus_aisleC__rank_bindings.yaml` |
| SC36_32x4_revC_subtorus_aisleD  | 36 | OK | `quad_galaxy_..._SC36_32x4_revC_subtorus_aisleD__rank_bindings.yaml`  |

## homogeneous/

`fabric_cpu_only_blitz_superpod_mesh_graph_descriptor.textproto`
— 64 identical `4x2` (RING,LINE = 8-chip) stages in one closed ring.
**512 chips total (16 galaxies).**

| system | hosts (np) | Mapping | bindings |
|--------|-----------|---------|----------|
| SC36_32x4_revAB_subtorus_aisleC | 20 | OK | `blitz_superpod_64stage__SC36_32x4_revAB_subtorus_aisleC__rank_bindings.yaml` |
| SC36_32x4_revC_subtorus_aisleD  | 36 | OK | `blitz_superpod_64stage__SC36_32x4_revC_subtorus_aisleD__rank_bindings.yaml`  |

## How these were generated

```bash
cd $TT_METAL_HOME
# rank_paths.txt lists one per-host mock cluster descriptor per MPI rank, in rank order,
# from the supercluster's *_cluster_desc/*_rank_N.yaml files.
mpirun --allow-run-as-root --oversubscribe -x TT_METAL_HOME -np <hosts> \
  ./rank_wrapper.sh <mapdir> \
  build_Release/tools/scaleout/generate_rank_bindings \
  -m <mgd.textproto> -o <out_dir>
```

`<hosts>` = 20 for `revAB_subtorus_aisleC`, 36 for `revC_subtorus_aisleD` (one MPI rank per
mock host; `rank_wrapper.sh` sets `TT_METAL_MOCK_CLUSTER_DESC_PATH` per rank).
